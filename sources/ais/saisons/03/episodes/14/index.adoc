Comprendre le fonctionnement et la mise en place des services DHCP et NTP sur Linux
// end::intro[]

== Objectifs pédagogiques

// tag::objectifs[]
* Installation, la configuration avancée, et la gestion du service DHCP sur Linux pour une attribution IP efficace sur plusieurs sous-réseaux.
* Voir la configuration NTP, de la sélection des sources de temps, et de la gestion de la synchronisation horaire sur des environnements mixtes.
// end::objectifs[]

== Prérequis formateur

// tag::prerequis[]
* avoir de pré configuré pour les démonstrations 
** une vm linux (Serveur)
** une vm linux (client)
** une vm Windows serveur
** une vm Windows client
* Savoir configurer un serveur DNS
// end::prerequis[]
