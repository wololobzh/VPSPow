// tag::intro[]
Cet épisode est consacré à la haute disponibilité des services informatiques. Nous aborderons les différents types de NAT, les avantages et inconvénients de chacun, ainsi que les bonnes pratiques pour garantir la continuité de service.
// end::intro[]

== Objectifs pédagogiques

// tag::objectifs[]
* Identifier les différents types de NAT
* Maîtriser le concept de NAT Statique
* Comprendre le fonctionnement du NAT Dynamique
* Appliquer le NAT Overload (PAT) et ses spécificités
// end::objectifs[]

== Prérequis formateur

// tag::prerequis[]
* Connaissance du logiciel Packet TRACER
* Savoir configurer Nat sur des routeur 
// end::prerequis[]
