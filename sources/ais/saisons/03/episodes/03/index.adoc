// tag::intro[]
Vlan est un réseau local virtuel qui permet de segmenter un réseau physique en plusieurs réseaux logiques. Les VLANs sont utilisés pour améliorer la sécurité, la performance et la gestion des réseaux.
// end::intro[]

== Objectifs pédagogiques

// tag::objectifs[]
* Comprendre ce qu’est un VLAN et le différentes typologies de vlan  
* Savoir Segmenter les réseaux à l’aide des VLANs (802.1Q) 
* Configurer le routage inter-VLAN .
// end::objectifs[]

== Prérequis formateur

// tag::prerequis[]
* Connaissance du logiciel Packet TRACER
* Comprendre et implémenter des vlans sur un switch Cisco
* savoir mettre en place du routage Inter-Vlan
// end::prerequis[]
