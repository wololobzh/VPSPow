// tag::intro[]
La couche physique est la première couche du modèle OSI. Elle est responsable de la transmission des données entre les équipements. Elle définit les caractéristiques électriques, mécaniques, procédurales et fonctionnelles des interfaces physiques et des supports de transmission. Elle est également responsable de la transmission des bits sur un canal de communication.
// end::intro[]

== Objectifs pédagogiques

// tag::objectifs[]
* Comprendre le rôle de la Couche Physique
* Voir les équipements de Transmission liés à cette couche 
* Techniques Avancées, comprendre le fonctionnement de la Modulation, du Codage et du Multiplexage 
* connaître les différents type de câblages 
* Comprendre ce qu’est le protocole ARP et son utilité
// end::objectifs[]

== Prérequis formateur

// tag::prerequis[]
* Connaissance du logiciel Packet TRACER
* Connaissance sur les différents typologie de câblages
* principe de fonctionnement du protocole ARP  
// end::prerequis[]
