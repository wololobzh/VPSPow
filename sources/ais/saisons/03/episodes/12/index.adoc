// tag::intro[]
Cet épisode est consacré à la résolution de noms de domaine (DNS). Nous aborderons les principes de fonctionnement du DNS, les types de requêtes, et les bonnes pratiques pour garantir la disponibilité et la sécurité du système de résolution de noms.
// end::intro[]

== Objectifs pédagogiques

// tag::objectifs[]
* Comprendre  la structure, les types de requêtes, et les pratiques de gestion DNS pour assurer la précision et l'efficacité du système de résolution de noms.
* Voir les étapes essentielles de l’installation, de la configuration, et du test de BIND sur un système Linux pour assurer une résolution DNS fonctionnelle et stable.
// end::objectifs[]

== Prérequis formateur

// tag::prerequis[]
* avoir de pré-configuré pour les démonstrations 
** une vm linux (Serveur)
** une vm linux (client)
** une vm Windows serveur
** une vm Windows client
* Savoir configurer un serveur DNS
// end::prerequis[]
