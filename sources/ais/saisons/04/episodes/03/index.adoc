== Objectifs pédagogiques

// tag::objectifs[]
* Comprendre les différents scénarios de promotion d’un contrôleur de domaine
* Appréhender la notion de niveaux fonctionnels
* Promouvoir ou Rétrograder un contrôleur de domaine
* Définir ce que sont les rôles FSMO
* Voir les rôles liés à la Forêt AD
* Voir les Rôles liés au domaine AD
* Comprendre comment on  identifie, on transfère et récupère les rôles FSMO entre contrôleur de domaine
* Qu’est que le Catalogue Global d’un Contrôleur de domaine
// end::objectifs[]

== Prérequis formateur

// tag::prerequis[]
* Deux serveurs Windows 2022 avec le rôle ADDS d’installer sur chaque serveur mais sans promotion de domaine effectuée 
// end::prerequis[]
