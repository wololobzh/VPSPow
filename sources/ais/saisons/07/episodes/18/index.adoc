// tag::intro[]
Cette journée permet de découvrir comment déployer des machines virtuelles sur Proxmox avec Terraform et d'interagir avec l'API Proxmox.
// end::intro[]

== Objectifs pédagogiques

// tag::objectifs[]
* Comprendre le processus de déploiement des ressources Terraform
* Savoir utiliser l'API Proxmox pour automatiser des tâches de gestion
* Savoir déployer des machines virtuelles sur Proxmox avec Terraform
// end::objectifs[]

== Prérequis formateur

// tag::prerequis[]
* Instance Proxmox fonctionnelle
* Terraform installé et fonctionnel
* Client HTTP installé (Postman ou Insomnia) pour les démos de l'API Proxmox
// end::prerequis[]
