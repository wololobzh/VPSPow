// tag::intro[]
Cette journée permet de découvrir le fonctionnement des variables dans Terraform pour rendre la configuration plus flexible et documenter la configuration. On explore aussi les modules Terraform pour organiser le code et le rendre plus lisible. On voit comment bien nettoyer des ressources, et enfin, on aborde la gestion des déploiements Terraform. Il s'agit de sujets d'ouverture et de sensibilisation à la sécurité.
// end::intro[]

== Objectifs pédagogiques

// tag::objectifs[]
* Comprendre l'importance des variables dans Terraform
* Connaître les modules Terraform 
* Savoir nettoyer des ressources Terraform
* Comprendre les bonnes pratiques de gestion des déploiements Terraform
// end::objectifs[]

== Prérequis formateur

// tag::prerequis[]
* Terraform installé et fonctionnel
// end::prerequis[]
