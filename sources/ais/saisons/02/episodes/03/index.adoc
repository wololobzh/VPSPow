== Prérequis formateur

// tag::prerequis[]
* Expertise en administration système et réseau.
* Maîtrise de l’environnement Linux (installation et configuration de serveurs).
* Connaissance des bases de données (MariaDB/MySQL).
* Expérience avec les serveurs web (Apache2, PHP-FPM).
* Connaissance fonctionnelle de GLPI (notions d’entités, profils et permissions).
