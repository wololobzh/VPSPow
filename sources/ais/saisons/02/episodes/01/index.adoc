// tag::intro[]
Cet épisode est consacré à la présentation d'ITIL. Nous allons voir les concepts de base d'ITIL, le rôle d'ITIL dans la gestion des services IT et les différences entre les approches projet et service
// end::intro[]

== Objectifs pédagogiques

// tag::objectifs[]
* Comprendre les concepts de base d'ITIL
* Découvrir le rôle d'ITL dans la gestion des services IT
* Savoir différencier les approches projet / service
// end::objectifs[]

== Prérequis formateur

// tag::prerequis[]
* Connaissance approfondie d'ITIL (versions V3 et V4).
* Expérience pratique dans la gestion des services IT et l’application d’ITIL.
* Maîtrise des concepts d'agilité, Lean et DevOps.
* Compétence pédagogique pour simplifier les concepts complexes.
* Capacité à animer des discussions et ateliers interactifs.
* Matériel de support à jour sur ITIL v4 et ses pratiques.
// end::prerequis[]
