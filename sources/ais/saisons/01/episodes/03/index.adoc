// tag::intro[]
Cette journée est axée sur  la remise à niveau en administration/scripting et la remise à niveau réseau. Le premier module couvre les commandes courantes sur Linux et Windows, ainsi que les bases de scripting en Bash, Python, et PowerShell, et une introduction à Git. Le second module est une introduction à l’IA et ses avantages dans l’administration système
// end::intro[]

== Objectifs pédagogiques

// tag::objectifs[]
- **Comprendre et utiliser** les commandes courantes sous Linux et Windows.
- **Acquérir** les bases de scripting en Bash, Python, et PowerShell.
- **Savoir utiliser** Git pour la gestion de version de code.
- **Découvrir** l’intérêt de l’IA dans l’administration système
// end::objectifs[]

== Prérequis formateur

// tag::prerequis[]
- Prévoir une VM Debian et une VM Windows (ou hôte Windows) pour montrer les différentes commandes et faire des démos de scripting
// end::prerequis[]
