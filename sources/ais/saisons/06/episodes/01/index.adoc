// tag::intro[]
Cet épisode est consacré à la découverte de PowerShell, un langage de script développé par Microsoft. Nous verrons comment il est possible de l'utiliser pour automatiser des tâches répétitives et gagner en efficacité. Nous aborderons également les bonnes pratiques pour écrire des scripts de qualité.
// end::intro[]

== Objectifs pédagogiques

// tag::objectifs[]
* notion générique sur le scripting
* comprendre l’algo en langage naturel et pseudo code 
* rappel pour une remise à sur les commandes Powershell de base
// end::objectifs[]

== Prérequis formateur

// tag::prerequis[]
- un environnement Windows pour lancer les commandes Powershell
// end::prerequis[]
