// tag::intro[]
Cet épisode est une introduction à Bash, un langage de script utilisé pour l'automatisation de tâches et la gestion de systèmes Unix/Linux. Nous allons voir comment déclarer et utiliser des variables, manipuler des chaînes et des nombres, et utiliser des boucles pour répéter des tâches.
// end::intro[]

== Objectifs pédagogiques

// tag::objectifs[]
* Qu’est ce que Bash
* Script Bash
* Rappel Commandes Bash
* Déclaration et utilisation
* Variables locales
* Variables globales
* Manipulation de chaînes
* Manipulation de nombres
* Variables système
* Boucle For, While, Until et Select
* utilisation de IF
// end::objectifs[]

== Prérequis formateur

// tag::prerequis[]
* un environnement linux pour pouvoir utiliser Bash
