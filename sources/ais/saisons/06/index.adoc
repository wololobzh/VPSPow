// tag::intro[]
Cette saison est consacrée à l'apprentissage des scripts en Powershell, Python et Bash. Les scripts sont des outils puissants pour automatiser des tâches répétitives. Ils permettent de gagner du temps et de réduire les erreurs humaines. Les scripts sont utilisés dans de nombreux domaines, comme l'administration système, le développement logiciel, la gestion de bases de données, etc.
// end::intro[]
