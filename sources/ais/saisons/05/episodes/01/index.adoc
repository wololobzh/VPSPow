// tag::intro[]
Introduire les participants à Linux et à l’open source, leur apprendre à installer Linux et à utiliser les commandes de base. L'objectif est de fournir une base solide pour que les participants puissent naviguer et utiliser Linux efficacement.
// end::intro[]

== Objectifs pédagogiques

// tag::objectifs[]
* Comprendre les concepts fondamentaux de Linux et du mouvement open source.
* Savoir installer une distribution Linux.
* Apprendre et maîtriser les commandes de base de Linux pour la gestion des fichiers et des systèmes.
// end::objectifs[]

== Prérequis formateur

// tag::prerequis[]
* Préparer le cours en parcourant les modules de cet épisode
* S’entraîner à faire les démonstrations, notamment si l’on risque de ne pas être à l’aise pour les faire en direct
* On peut aussi prendre le parti de découvrir la démonstration en plein cours, mais il ne faut pas que cela impacte trop le rythme de la journée
* Préparer des documents ou des ressources de référence sur les commandes de base de Linux, à partager aux apprenants
// end::prerequis[]
