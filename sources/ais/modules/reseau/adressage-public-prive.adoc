== Rappel

=== IPv4 (Internet Protocol version 4) :

* **Lancé en 1983**, IPv4 utilise des adresses de **32 bits**, permettant environ **4,3 milliards** d’adresses uniques (ex : `192.168.0.1`).
* **Problème** : Avec la croissance massive d'Internet et des appareils connectés, le stock d'adresses IPv4 est épuisé ou presque.
* **Limitation** : Besoin d'optimisations comme le NAT pour prolonger l’utilisation d’IPv4 dans les réseaux privés.

=== IPv6 (Internet Protocol version 6) :

* **Lancé en 1998**, IPv6 a été créé pour résoudre la pénurie d’adresses IP. Il utilise des adresses de **128 bits**, offrant un nombre presque infini d'adresses (340 sextillions d’adresses, ex : `2001:0db8::/32`).
* **Avantage** : Pas besoin de NAT, chaque appareil peut avoir une adresse unique routable sur Internet.
* **Transition** : Coexistence avec IPv4, mais adoption progressive dans les réseaux mondiaux.

== IPv4 adresse IP publique

**Définition** : Une adresse IP publique est une adresse unique attribuée à un appareil pour qu'il puisse être accessible directement depuis Internet.

**Organismes d'attribution** : Les adresses IP publiques sont attribuées par des organisations comme l'IANA (Internet Assigned Numbers Authority) et les RIR (Regional Internet Registry) pour garantir leur unicité à travers le monde.

include::../../../../adoc/libs/slide-notitle.adoc[]

**Plages d'adresses publiques :**

* Les adresses publiques vont de 1.0.0.0 à 223.255.255.255 pour IPv4.
* Routables sur Internet, ces adresses permettent la communication entre réseaux distants.

**Exemples** : Adresses de serveurs web, routeurs, services d'hébergement cloud.

**Coût** : Souvent, l'utilisation d'adresses IP publiques entraîne des coûts additionnels, car leur gestion est rare et précieuse avec IPv4.

== IPv4 Adresse IP privé RFC 1918

La RFC 1918, publiée en 1996, spécifie les plages d'adresses réservées à un usage interne dans les réseaux privés. Ces adresses ne peuvent pas être routées sur Internet.

=== Plages d'adresses définies :

* 10.0.0.0 à 10.255.255.255 (ancienne Classe A - /8) : Utilisée pour les très grands réseaux.
* 172.16.0.0 à 172.31.255.255 (ancienne Classe B - /12) : Utilisée pour les réseaux de taille moyenne.
* 192.168.0.0 à 192.168.255.255 (ancienne Classe C - /16) : Couramment utilisée dans les petits réseaux locaux (ex : réseaux domestiques).

=== Caractéristiques :

* Non routables sur Internet, leur utilisation est strictement interne aux entreprises ou aux foyers.
* Nécessitent un mécanisme (NAT) pour permettre l'accès à Internet.
* Utilisées dans les réseaux LAN (Local Area Network), où plusieurs appareils peuvent se connecter.

== IPv6 Adresse IP publiques (Global Unicast Addresses - GUA)

Routables sur Internet : Attribuées pour les appareils accessibles depuis Internet.

Préfixe : `2000::/3` (ex: `2001:db8::/32`).

include::../../../../adoc/libs/slide-notitle.adoc[]

**Structure** : 128 bits (plus de 340 sextillions d'adresses uniques).

* **Préfixe global** (48 bits) : Une partie de l'adresse est assignée par un registre d'adresses IP, permettant une identification globale.
* **ID de sous-réseau** (16 bits) : Cette partie est utilisée pour identifier les sous-réseaux internes dans une organisation ou un fournisseur d'accès.
* **ID d'interface** (64 bits) : Correspond à une adresse unique pour une interface spécifique d'un périphérique sur un sous-réseau donné.
* **utilisé** : Pour les serveurs, services en ligne, routeurs et tout appareil nécessitant un accès global.

**Avantage clé** : Pas besoin de NAT en IPv6, chaque appareil peut avoir une adresse unique.

include::../../../../adoc/libs/slide-notitle.adoc[]


* **Link-Local Addresses (fe80::/10)** :
** **Non routables hors du lien local.**
** Utilisées pour la communication à l'intérieur d'un même segment réseau ou entre appareils voisins.
** **Exemple** : fe80::1ff:fe23:4567:890a.
* **Unique Local Address (ULA - fc00::/7)** :
** **Non routables sur Internet**, mais utilisables dans des réseaux privés, comme les adresses privées IPv4.
** **Préfixe** : Généralement fd00::/8.
** **Exemple** : fd00:1234::/48.
** **Utilisation** : Parfait pour les réseaux d’entreprise et les réseaux internes qui n'ont pas besoin d'être accessibles globalement.

== IPv6  Différences entre Adresses Publiques et Privées

|===
| Caractéristique      | Adresse Publique                                | Adresse Privée

| Routabilité
| Routable sur Internet
| Non routable sur Internet

| Préfixe
| 2000::/3
| fe80::/10 (Link-Local)
fc00::/7 (ULA)

| Utilisation
| Accès global (serveurs, services)
| Communication interne (réseau local, entreprise)
|===
