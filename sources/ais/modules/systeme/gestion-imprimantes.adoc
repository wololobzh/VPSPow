== Le service d’impression

Terminologie Microsoft, 

un périphérique d’impression correspond au matériel en charge de l’impression (usuellement appelé imprimante).
L’objet imprimante correspond lui à l’élément logique désigné pour l’impression.

include::../../../../adoc/libs/slide-notitle.adoc[]

Généralement une imprimante est liée à un périphérique d’impression mais il est possible d’associer:

* **Plusieurs imprimantes** à un **même périphérique** d’impression
* Une imprimante à plusieurs périphériques (pool)

image::./assets/01-serveur-impression.png[]

== Configuration du partage d'imprimantes SMB

[cols="1,1"]
|===
a| Installation d’imprimante
a|
* Connecter et installer les pilotes de l'imprimante sur le serveur.
* Vérifier que l'imprimante fonctionne 

a| Activer le partage de fichiers et d’imprimantes
a|
* "Panneau de configuration" > "Centre Réseau et partage".
* Activer "Activer le partage de fichiers et d’imprimantes" dans "Modifier les paramètres de partage avancés".

|===

include::../../../../adoc/libs/slide-notitle.adoc[]

[cols="1,1"]
|===
a| Partager l’imprimante
a|
* "Périphériques et imprimantes" dans le "Panneau de configuration".
* Clic droit sur l'imprimante > "Propriétés de l'imprimante".
* Onglet "Partage" 

a| Configurer les permissions
a|
* Onglet "Sécurité" dans les propriétés de l'imprimante.
* Ajouter des utilisateurs ou groupes via les ACL.
* Définir les permissions (Imprimer, Gérer les documents, Gérer l'imprimante).

|===

== Accéder aux imprimantes partagées

=== Via l'Explorateur de fichiers :

* Ouvrir l'Explorateur de fichiers.
* Taper `\\Nom_du_serveur\Nom_de_l'imprimante_partagée` dans la barre d'adresse.
* Suivre les instructions pour installer l'imprimante sur le client.

=== Ajout via le Panneau de configuration :

* Aller dans "Périphériques et imprimantes".
* Cliquer sur "Ajouter une imprimante" > "Ajouter une imprimante réseau, sans fil ou Bluetooth".
* Sélectionner l'imprimante partagée dans la liste ou entrer manuellement le chemin réseau (`\\Nom_du_serveur\Nom_de_l'imprimante_partagée`).

== Sécurité et permissions

=== Gestion des ACL (Access Control Lists) :

* Définir des permissions granulaires pour chaque utilisateur ou groupe.
* Sécuriser l'accès et la gestion des imprimantes partagées.

=== Surveillance et Gestion :

* Utiliser des outils de surveillance pour suivre l'utilisation des imprimantes.
* Configurer des quotas d'impression et des restrictions d'accès.

=== Configuration des Pare-feu :

* Vérifier que les ports 445 (SMB direct) et 139 (NetBIOS) sont ouverts.
* Configurer des règles de pare-feu pour autoriser le trafic SMB uniquement aux adresses IP de confiance.

== Imprimante et PowerShell

=== Pourquoi utiliser PowerShell pour la gestion des imprimantes

* Automatisation des tâches répétitives.
* Configuration rapide et à grande échelle.
* Gestion centralisée des imprimantes sur le réseau.

=== Cmdlets de PowerShell pour la Gestion des Imprimantes

* `Get-Printer`: Récupère la liste des imprimantes installées.
* `Add-Printer`: Ajouter une nouvelle imprimante.
* `Remove-Printer`: Supprime une imprimante existante.
* `Set-Printer`: Modifie les propriétés d'une imprimante.
* `Get-PrintJob`: Récupère la liste des travaux d'impression en cours.
* `Remove-PrintJob`: Supprime un travail d'impression.
