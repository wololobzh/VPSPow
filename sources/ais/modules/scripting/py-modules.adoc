==  Qu'est-ce qu'un Module ?

**Définition** : Un module est un fichier contenant du code Python (fonctions, classes, variables) qui peut être importé et réutilisé dans d'autres programmes Python.

include::../../../../adoc/libs/slide-notitle.adoc[]

**Utilisation** :

* Organiser le code en plusieurs fichiers pour une meilleure gestion.
* Réutiliser du code commun dans plusieurs parties d'un programme ou dans plusieurs projets.

**Exemple :**

```python
# Exemple de module : mymodule.py
def saluer():
    print("Bonjour, tout le monde!")
```

== Module importation

Le module peut être importé de différente façon plus ou moins sélectives

**Syntaxe d'importation classique** : on importe le module dans son intégralité

```python
import mymodule
mymodule.saluer()
```

include::../../../../adoc/libs/slide-notitle.adoc[]

**Importation sélective** : on importe seulement ce qui nous intéresse à l’intérieur du module

```python
from mymodule import saluer
saluer()
```

**Importation avec alias** : on importe le module et on lui attribue un alias pour l’utilisation

```python
import mymodule as mm
mm.saluer()
```

**Bonnes pratiques :**

* Utiliser des noms de modules explicites.
* Grouper les importations en haut des fichiers pour une meilleure lisibilité.

== Modules standard et personnalisés

**Modules standard** : Fournis avec la distribution Python (exemple : math, sys, os).

```python
import math
print(math.sqrt(16)) # sqrt donne la racine carrée
```

include::../../../../adoc/libs/slide-notitle.adoc[]

**Modules personnalisés** : Créés par les développeurs ou vos propres modules pour des besoins spécifiques.

* Exemple de module personnalisé : `utilities.py`.
* Utiliser des conventions de nommage claires et organiser les modules dans des dossiers logiques.

== Qu'est-ce qu'une Classe ?

**Définition** : Une classe est un plan pour créer des objets définis par un ensemble d'attributs et de méthodes.

Une classe est un **plan pour créer des objets** (également nommée instances). Elle définit un ensemble d'attributs (variables) et de méthodes (fonctions) que les objets créés à partir de la classe auront.

**Utilisation** :

* Modéliser des entités complexes en regroupant données et comportements.
* Faciliter la réutilisation et la modularité du code.

include::../../../../adoc/libs/slide-notitle.adoc[]

**Il existe 2 grands types de classe**

**Sans Constructeur** : Une classe sans constructeur n'a pas de méthode spéciale pour initialiser ses attributs lors de la création d'une instance.

**Avec Constructeur** : Une classe avec constructeur utilise une méthode spéciale pour initialiser ses attributs lors de la création d'une instance

== Construction d'une Classe sans Constructeur

**Définition** : Une classe sans constructeur n'a pas de méthode spéciale pour initialiser ses attributs lors de la création d'une instance.

**Exemple de classe sans constructeur :**

```python
class Personne:
    pass

personne1 = Personne()
personne1.nom = "Alice"
personne1.age = 30

print(personne1.nom)  # Alice
print(personne1.age)  # 30
```

=== Avantages et Inconvénients des Classes sans Constructeur

**Avantages :**

* **Simplicité** : Utile pour des objets très simples ou temporaires.
* **Flexibilité** : Les attributs peuvent être ajoutés ou modifiés dynamiquement.
* **Rapidité** : Pas besoin de définir un constructeur pour des cas très basiques.

include::../../../../adoc/libs/slide-notitle.adoc[]

**Inconvénients** :

* **Risque d'erreurs** : Possibilité d'oublier d'initialiser certains attributs, ce qui peut causer des erreurs.
* **Manque de Structure** : Moins organisé, peut rendre le code difficile à maintenir et à comprendre.
* **Pas de contrôle d'initialisation** : Impossible d'assurer que l'objet est dans un état valide dès sa création.

=== Cas d'Utilisation des Classes sans Constructeur

**Prototypes Rapides** : Utile lors de la phase de prototypage où la structure de l'objet peut changer fréquemment.

**Objets Temporaires** : Pour des objets à vie courte où la formalisation d'un constructeur n'est pas nécessaire.

**Exemple** :

```python
class Config:
    pass

config = Config()
config.debug = True
config.verbose = False

print(config.debug)   # True
print(config.verbose) # False
```

== Construction d'une Classe avec Constructeur

**Définition** : Une classe avec constructeur utilise une méthode spéciale pour initialiser ses attributs lors de la création d'une instance.

**Exemple** :

```python
class Personne:
    def __init__(self, nom, age):
        self.nom = nom
        self.age = age

personne1 = Personne("Alice", 30)

print(personne1.nom)  # Alice
print(personne1.age)  # 30
```

=== Explication du Constructeur

**Méthode `__init__` **

* **Définition** : Méthode spéciale en Python, appelée automatiquement lors de la création d'une nouvelle instance de la classe.
* **Utilisation** : Initialiser les attributs de l'objet avec les valeurs fournies.

include::../../../../adoc/libs/slide-notitle.adoc[]

**Exemple** :

```python
def __init__(self, nom, age):
    self.nom = nom
    self.age = age
```

`self` :

* **Définition** : Référence à l'instance actuelle de la classe, utilisée pour accéder aux attributs et méthodes de l'objet.
* **Utilisation** : Permet de différencier les attributs de l'objet des variables locales.

**Exemple** :

```python
self.nom = nom  # self.nom fait référence à l'attribut de l'objet, nom est le paramètre de la méthode
```

== Qu'est-ce qu'une Méthode ?

**Définition** : Une méthode est une fonction définie à l'intérieur d'une classe qui opère sur les instances de cette classe.

**Utilisation** :

* Manipuler les attributs des objets de manière contrôlée.
* Encapsuler des comportements spécifiques à l'intérieur des objets.

include::../../../../adoc/libs/slide-notitle.adoc[]

**Exemple** :

```python
class Personne:
    def saluer(self):
        print(f"Bonjour, je m'appelle {self.nom} et j'ai {self.age} ans.")
```

**Explication Ligne par Ligne :**

* `class Personne:` : Définit une nouvelle classe nommée Personne.
* `def saluer(self):` : Définit une méthode saluer pour la classe Personne. La méthode prend un argument self, qui est une référence à l'instance actuelle de la classe.
* `print(f"Bonjour, je m'appelle {self.nom} et j'ai {self.age} ans.")` : Affiche un message saluant l'utilisateur en utilisant les attributs nom et age de l'instance actuelle de la classe (self).

include::../../../../adoc/libs/slide-notitle.adoc[]

**Utilisation :**

```python
personne1 = Personne()
personne1.nom = "Alice"
personne1.age = 30
personne1.saluer()  # Bonjour, je m'appelle Alice et j'ai 30 ans.
```

**Explication Ligne par Ligne :**

* `personne1 = Personne()` : Crée une nouvelle instance de la classe Personne et l'assigne à la variable personne1.
* `personne1.nom = "Alice"` : Ajoute un attribut nom à l'objet personne1 et lui assigne la valeur "Alice".
* `personne1.age = 30` : Ajoute un attribut age à l'objet personne1 et lui assigne la valeur 30.
* `personne1.saluer()` : Appelle la méthode saluer sur l'instance personne1, ce qui affiche le message de salutation.

== Méthodes d'initialisation et de représentation :

* `__init__` : Méthode appelée lors de la création d'une nouvelle instance.
* `__str__` : Méthode utilisée pour retourner une représentation lisible d'un objet.

include::../../../../adoc/libs/slide-notitle.adoc[]

```python
class Personne:
    def __init__(self, nom, age):
        self.nom = nom
        self.age = age

    def __str__(self):
        return f"{self.nom}, {self.age} ans"
```

**Explication Ligne par Ligne :**

* `class Personne:` : Définit une nouvelle classe nommée Personne.
* `def __init__(self, nom, age):` : Définit une méthode spéciale appelée __init__. Cette méthode est un constructeur utilisé pour initialiser les attributs de l'objet.
* `self.nom = nom` : Assigne la valeur du paramètre nom à l'attribut nom de l'instance actuelle de la classe (self).

include::../../../../adoc/libs/slide-notitle.adoc[]

```python
class Personne:
    def __init__(self, nom, age):
        self.nom = nom
        self.age = age

    def __str__(self):
        return f"{self.nom}, {self.age} ans"
```

* `self.age = age` : Assigne la valeur du paramètre age à l'attribut age de l'instance actuelle de la classe (self).
* `def __str__(self):` : Définit une méthode spéciale appelée __str__ qui retourne une représentation lisible de l'objet.
* `return f"{self.nom}, {self.age} ans"` : Retourne une chaîne de caractères formatée contenant les attributs nom et age.

include::../../../../adoc/libs/slide-notitle.adoc[]

**Utilisation** :

```python
personne1 = Personne("Alice", 30)
print(personne1)  # Alice, 30 ans
```

**Explication Ligne par Ligne :**

* `personne1 = Personne("Alice", 30)` : Crée une nouvelle instance de la classe Personne avec les paramètres nom et age initialisés à "Alice" et 30 respectivement, et assigne cette instance à la variable personne1.
* `print(personne1)` : Appelle la méthode spéciale `__str__` sur l'instance personne1, ce qui retourne la chaîne de caractères "Alice, 30 ans" et l'affiche.

* **Qu'est-ce qu'un module ?**

Un module en Python est simplement un fichier contenant du code Python. Un module peut définir des fonctions, des classes et des variables, et peut aussi inclure du code exécutable.

**Exemple** : Créons un fichier nommé `mon_module.py` :

```python
# mon_module.py

def saluer(nom):
    return f"Bonjour, {nom} !"

class Calculatrice:
    def addition(self, x, y):
        return x + y
```

* **Importation de modules**

Les modules peuvent être importés dans d'autres fichiers Python à l'aide du mot-clé `import`.

**Exemple** : Créons un autre fichier nommé `main.py` qui importe et utilise `mon_module.py` :

```python
# main.py

# Importation du module
import mon_module

# Utilisation de la fonction saluer
message = mon_module.saluer("Alice")
print(message)  # Affiche : Bonjour, Alice !

# Utilisation de la classe Calculatrice
calculatrice = mon_module.Calculatrice()
resultat = calculatrice.addition(10, 5)
print(resultat)  # Affiche : 15
```

* **Modules standard et personnalisés**

Python inclut de nombreux modules standard comme math, os, sys, etc. qui fournissent des fonctionnalités courantes.

**Exemple avec le module standard `math` :**

```python
import math

print(math.sqrt(16))  # Affiche : 4.0
```

Les modules personnalisés sont ceux que vous créez vous-même, comme `mon_module.py` ci-dessus.

* **Qu'est-ce qu'une classe ?**

Une classe est une structure qui permet de définir des objets en regroupant des données (attributs) et des comportements (méthodes). Une classe est un modèle pour créer des objets.

**Exemple de classe simple :**

```python
class Chien:
    # Attribut de classe
    espece = "Canis lupus familiaris"

    # Méthode
    def aboyer(self):
        return "Woof!"
```

* **Classe sans constructeur**

Une classe sans constructeur n'a pas de méthode spéciale __init__. Elle peut avoir des méthodes et des attributs définis au niveau de la classe ou de l'objet.

**Exemple :**

```python
class Chat:
    def miauler(self):
        return "Miaou!"
```

**Utilisation :**

```python
mon_chat = Chat()
print(mon_chat.miauler())  # Affiche : Miaou!
```

* **Classe avec constructeur**

Une classe avec un constructeur définit une méthode __init__, qui initialise l'objet avec des valeurs spécifiques lors de sa création.

**Exemple** :

```python
class Personne:
    def __init__(self, nom, age):
        self.nom = nom
        self.age = age

    def se_presenter(self):
        return f"Je m'appelle {self.nom} et j'ai {self.age} ans."
```

**Utilisation :**

```python
personne = Personne("Alice", 30)
print(personne.se_presenter())  # Affiche : Je m'appelle Alice et j'ai 30 ans.
```

* **Qu'est-ce qu'une méthode ?**

Une méthode est une fonction définie à l'intérieur d'une classe, qui agit généralement sur les instances de cette classe.

**Exemple :**

```python
class Voiture:
    def demarrer(self):
        return "La voiture démarre."
```

* **Méthodes spéciales**

Les méthodes spéciales sont des méthodes prédéfinies en Python, qui commencent et se terminent par deux underscores (`__`). Par exemple, `__init__` est une méthode spéciale qui initialise un objet.

**Autres exemples de méthodes spéciales :**

* `__str__`: Pour définir la représentation en chaîne de caractères d'un objet.
* `__repr__`: Pour définir la représentation non ambiguë d'un objet.

**Exemple :**

```python
class Livre:
    def __init__(self, titre, auteur):
        self.titre = titre
        self.auteur = auteur

    def __str__(self):
        return f"'{self.titre}' par {self.auteur}"

# Utilisation :
livre = Livre("1984", "George Orwell")
print(livre)  # Affiche : '1984' par George Orwell
```

== Conclusion
// tag::conclusion[]
**Modules :**

* Permettent de structurer le code en plusieurs fichiers
* Facilitent la réutilisation et l'importation de fonctions, classes et variables
* Supportent l'importation sélective et l'utilisation d'alias

**Classes :**

* Modèles pour créer des objets avec des attributs et des méthodes
* Encapsulation des données et des comportements
* Supportent l'héritage pour réutiliser et étendre des fonctionnalités

include::../../../../adoc/libs/slide-notitle.adoc[]

**Méthodes :**

* Fonctions définies à l'intérieur des classes
* Interagissent avec les attributs des objets via self
* Incluent des méthodes spéciales comme __init__ (constructeur) et __str__ (représentation)

// end::conclusion[]
