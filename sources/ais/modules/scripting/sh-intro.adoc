== Qu'est-ce que Bash ?

**Définition :**

Bash (Bourne Again Shell) est un interpréteur de commandes, l'un des plus utilisés dans les systèmes Unix/Linux. Il permet d'exécuter des commandes, de créer des scripts pour automatiser des tâches et d'interagir avec le système.

**Historique :**

Développé par Brian Fox en 1989 pour le projet GNU, Bash est une amélioration du Bourne Shell (sh) avec des fonctionnalités supplémentaires telles que l'historique des commandes, les commandes composées, et plus encore.

include::../../../../adoc/libs/slide-notitle.adoc[]

**Fonctionnalités :**

* Support des scripts et des commandes interactives.
* Historique des commandes, auto-complétion, et édition de lignes.
* Structures de contrôle avancées (if, loops, etc.).

== Script bash

**Définition**

* Un script Bash est un fichier texte contenant une série de commandes Bash. 
* Lorsqu'il est exécuté, chaque ligne de commande est interprétée et exécutée par Bash, permettant ainsi d'automatiser des tâches. 
* Les scripts Bash commencent généralement par une ligne spéciale appelée shebang qui spécifie l'interpréteur à utiliser.

include::../../../../adoc/libs/slide-notitle.adoc[]

**Exemple**

```bash
#!/bin/bash
echo "Bienvenue dans le monde du scripting Bash!"
```

* `#!/bin/bash` : Cette ligne est le shebang. Elle indique au système que ce script doit être exécuté avec l'interpréteur Bash.
* `echo "Bienvenue dans le monde du scripting Bash!"` : La commande echo affiche le texte entre guillemets sur la console.

include::../../../../adoc/libs/slide-notitle.adoc[]

**Création du fichier script :**

* Écrire les commandes dans un fichier texte, généralement avec une extension `.sh`.
* Exemple : `mon_script.sh`.

**Rendre le fichier exécutable :**

* Modifier les permissions du fichier pour permettre son exécution.
* Commande : `chmod +x mon_script.sh`.

include::../../../../adoc/libs/slide-notitle.adoc[]

**Exécuter le script :**

* Lancer le script depuis le terminal.
** Commande : `./mon_script.sh`.

**Exemple**

```bash
chmod +x mon_script.sh
./mon_script.sh
```

**Explication :**

* `chmod +x mon_script.sh` : Rendre le script exécutable.
* `./mon_script.sh` : Exécuter le script.

== Rappel commandes Bash

Avant de plonger dans l'écriture de scripts, il est essentiel de maîtriser les commandes de base utilisées dans Bash. 

=== Navigation dans le système de fichiers :

* `pwd` : Affiche le répertoire de travail actuel.
* `cd` : Change le répertoire de travail.
** Exemple : `cd /chemin/vers/dossier`
* `ls` : Liste les fichiers et répertoires dans le répertoire courant.
** Exemple : `ls -l` (liste détaillée)

=== Manipulation des fichiers et répertoires :

* `cp` : Copie des fichiers ou des répertoires.
** Exemple : `cp fichier1 fichier2`
* `mv` : Déplace ou renomme des fichiers ou des répertoires.
** Exemple : `mv ancien_nom nouveau_nom`
* `rm` : Supprime des fichiers ou des répertoires.
** Exemple : `rm fichier`
** `rm -r dossier` : Supprime un répertoire et son contenu.

include::../../../../adoc/libs/slide-notitle.adoc[]

* mkdir : Crée un nouveau répertoire.
** Exemple : `mkdir nouveau_dossier`
* rmdir : Supprime un répertoire vide.
** Exemple : `rmdir dossier_vide`

=== Affichage et gestion des fichiers :

* `cat` : Affiche le contenu d'un fichier.
** Exemple : `cat fichier`
* `less` : Affiche le contenu d'un fichier page par page.
** Exemple : `less fichier`
* `head` : Affiche les premières lignes d'un fichier.
** Exemple : `head -n 10 fichier`
* `tail` : Affiche les dernières lignes d'un fichier.
** Exemple : `tail -n 10 fichier`

=== Informations sur le système et les processus :

* `echo` : Affiche un message ou une valeur.
** Exemple : `echo "Hello, world!"`
* `ps` : Affiche les processus en cours d'exécution.
** Exemple : `ps aux`
* `kill` : Termine un processus.
** Exemple : `kill 1234` (où 1234 est l'ID du processus)

== Démonstration

[NOTE.speaker]
--
**Objectif** : Revoir les commandes Bash essentielles avec des exemples concrets.

* **Commandes de Navigation**

** `pwd` (Print Working Directory) : Affiche le répertoire de travail actuel.

```bash
$ pwd
/home/user/projet
```

** Vous travaillez actuellement dans le répertoire /home/user/projet.

* `cd` (Change Directory) : Change de répertoire.

```bash
$ cd /var/log
```

Vous êtes maintenant dans le répertoire /var/log.

Retourner au répertoire parent.

```bash
$ cd ..
```

Vous revenez au répertoire parent du répertoire actuel.

Aller directement au répertoire personnel.

```bash
$ cd ~
```

Vous êtes maintenant dans votre répertoire personnel (/home/user).

* **Gestion des Fichiers et Répertoires**

** `ls` (List) : Liste les fichiers et répertoires dans le répertoire actuel.
Lister tous les fichiers et répertoires.

```bash
$ ls
fichier1.txt  répertoire1  script.sh
```

Lister avec des détails supplémentaires (taille, permissions, etc.).

```bash
$ ls -l
-rw-r--r-- 1 user user 1024 Aug 12 12:00 fichier1.txt
drwxr-xr-x 2 user user 4096 Aug 12 12:00 répertoire1
-rwxr-xr-x 1 user user 2048 Aug 12 12:00 script.sh
```

Lister les fichiers cachés (ceux dont le nom commence par un point).

```bash
$ ls -a
.  ..  .bashrc  fichier1.txt  répertoire1  script.sh
```

** `cp` (Copy) : Copie des fichiers ou des répertoires.

Copier un fichier.

```bash
$ cp fichier1.txt fichier1_backup.txt
```

Le fichier `fichier1.txt` est copié sous le nom `fichier1_backup.txt`.

Copier un répertoire entier.

```bash
$ cp -r répertoire1 répertoire1_backup
```

Le répertoire `répertoire1` et tout son contenu sont copiés sous le nom `répertoire1_backup`.

** `mv` (Move) : Déplace ou renomme des fichiers ou des répertoires.

Renommer un fichier.

```bash
$ mv fichier1.txt fichier2.txt
```

Le fichier `fichier1.txt` est renommé en `fichier2.txt`.

Déplacer un fichier dans un autre répertoire.

```bash
$ mv fichier2.txt /home/user/archives/
```

Le fichier fichier2.txt est déplacé dans le répertoire /home/user/archives/.

** `rm` (Remove) : Supprime des fichiers ou des répertoires.

Supprimer un fichier.

```bash
$ rm fichier2.txt
```

Le fichier `fichier2.txt` est supprimé.

Supprimer un répertoire et tout son contenu.

```bash
$ rm -r répertoire1_backup
```

Le répertoire `répertoire1_backup` et tout son contenu sont supprimés.

* **Gestion des Processus**

** `ps` (Process Status) : Affiche les processus en cours d'exécution.

Voir les processus de l'utilisateur courant.

```bash
$ ps
  PID TTY          TIME CMD
 1234 pts/0    00:00:01 bash
 5678 pts/0    00:00:00 ps
```

Voir tous les processus en cours sur le système.

```bash
$ ps aux
USER       PID %CPU %MEM    VSZ   RSS TTY      STAT START   TIME COMMAND
root         1  0.0  0.1  22528  1144 ?        Ss   Aug12   0:00 /sbin/init
user      1234  0.0  0.0  17320   872 pts/0    Ss   12:00   0:01 bash
user      5678  0.0  0.0  15076   884 pts/0    R+   12:05   0:00 ps aux
```

** `kill` : Termine un processus.

Terminer un processus spécifique en utilisant son PID.

```bash
$ kill 1234
```

Le processus avec le PID 1234 (par exemple, un script bloqué) est terminé.

* **Redirection et Pipes**

** `>` (Redirection de sortie) : Redirige la sortie d'une commande vers un fichier.

Sauvegarder la sortie de `ls` dans un fichier.

```bash
$ ls -l > listing.txt
```

Le résultat de `ls -l` est enregistré dans le fichier listing.txt.

** | (Pipe) : Redirige la sortie d'une commande en entrée d'une autre.

Filtrer la sortie de ls pour ne montrer que les fichiers `.txt`.

```bash
$ ls -l | grep ".txt"
-rw-r--r-- 1 user user 1024 Aug 12 12:00 fichier1.txt
```

** `>>` (Append) : Ajoute la sortie d'une commande à la fin d'un fichier existant.

Ajouter une nouvelle liste de fichiers à `listing.txt`.

```bash
$ ls -a >> listing.txt
```

* **Autres commandes utiles**

** `cat` : Affiche le contenu d'un fichier.

Voir le contenu d'un fichier texte.

```bash
$ cat fichier1.txt
Bonjour, ceci est un fichier texte.
```

** `echo` : Affiche un texte ou une variable.

Afficher un message simple.

```bash
$ echo "Hello, World!"
Hello, World!
```

Afficher la valeur d'une variable.

```bash
$ MESSAGE="Bienvenue au cours Bash"
$ echo $MESSAGE
Bienvenue au cours Bash
```

* **Démonstration Pratique**

**Objectif** : Mettre en application les commandes de base dans un script Bash simple.

Création d'un script de sauvegarde :

Script :

```bash
#!/bin/bash
# Script de sauvegarde

echo "Début de la sauvegarde..."

SRC_DIR="/home/user/projet"
DEST_DIR="/home/user/sauvegarde"
BACKUP_FILE="backup_$(date +%Y%m%d%H%M%S).tar.gz"

# Création de la sauvegarde
tar -czf $DEST_DIR/$BACKUP_FILE $SRC_DIR

echo "Sauvegarde terminée : $DEST_DIR/$BACKUP_FILE"
```

**Explication :**

* Le script commence par afficher un message.
* Les variables `SRC_DIR` et `DEST_DIR` définissent respectivement le répertoire à sauvegarder et l'emplacement de la sauvegarde.
* La commande `tar -czf` crée un fichier compressé `.tar.gz` du répertoire source.
* Le fichier de sauvegarde est horodaté pour le rendre unique.

**Exécution :**

* Rendez le script exécutable avec `chmod +x backup.sh`.
* Exécutez le script avec `./backup.sh` et montrez le résultat.
