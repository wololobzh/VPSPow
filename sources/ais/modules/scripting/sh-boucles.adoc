== Boucle `for`

La boucle for en Bash est utilisée pour parcourir une liste d'éléments et exécuter un ensemble de commandes pour chaque élément. 

Elle est particulièrement utile pour traiter des collections de données, telles que des fichiers ou des arguments de commande.

=== Syntaxe et exemple

```sh
for i in {1..5}; do
    echo "Numéro : $i"
done
```

**Explication**

* `for i in {1..5}; do` : La boucle commence avec la variable `i` prenant successivement les valeurs de 1 à 5.
* `echo "Numéro : $i"` : À chaque itération, affiche la valeur actuelle de `i`.
* `done` : Indique la fin de la boucle.

== Boucle `while`

La boucle while exécute un ensemble de commandes tant qu'une condition spécifiée est vraie. 

Elle est utile pour les tâches où le nombre d'itérations n'est pas connu à l'avance, comme la lecture de données depuis un fichier ou l'attente d'un événement.

=== Syntaxe et exemple

```sh
count=1
while [ $count -le 5 ]; do
    echo "Count : $count"
    ((count++))
done
```

**Explication**

* `while [ $count -le 5 ]; do` : La condition [ $count -le 5 ] est vérifiée avant chaque itération ; la boucle continue tant que cette condition est vraie.
* `echo "Count : $count"` : Affiche la valeur actuelle de count.
* `((count++))` : Incrémente la valeur de count de 1.
* `done` : Indique la fin de la boucle.

== Boucle `until`

La boucle until est similaire à la boucle while, mais elle continue d'exécuter des commandes jusqu'à ce qu'une condition devienne vraie. 

Elle est souvent utilisée lorsque vous souhaitez exécuter des commandes au moins une fois et ensuite vérifier la condition.

=== Syntaxe et exemple

```sh
count=1
until [ $count -gt 5 ]; do
    echo "Count : $count"
    ((count++))
done
```

**Explication**

* `until [ $count -gt 5 ]; do` : La boucle continue jusqu'à ce que la condition `[ $count -gt 5 ]` devienne vraie.
* `echo "Count : $count"` : Affiche la valeur actuelle de count.
* `((count++))` : Incrémente la valeur de count de 1.
* `done` : Indique la fin de la boucle.

== Boucle `select`

La boucle select est une structure de contrôle spécifique à Bash qui facilite la création de menus interactifs dans les scripts. Elle permet à l'utilisateur de sélectionner une option parmi une liste d'options.

=== Syntaxe et exemple

```sh
select fruit in Pomme Orange Banane Quitter; do
    case $fruit in
        Pomme) echo "Vous avez choisi Pomme";;
        Orange) echo "Vous avez choisi Orange";;
        Banane) echo "Vous avez choisi Banane";;
        Quitter) break;;
        *) echo "Choix invalide";;
    esac
done
```

**Explication**

* `select fruit in Pomme Orange Banane Quitter; do` : Affiche un menu pour sélectionner une option. La variable fruit prend la valeur de l'option sélectionnée.
* `case $fruit in ... esac` : Gère chaque choix avec une action correspondante.
* `break` : Quitte la boucle select lorsque "Quitter" est sélectionné.

== Utilisation du `if`

La commande `if` est utilisée pour exécuter des instructions conditionnelles.

Utilisée dans des boucles, elle permet d'exécuter des commandes uniquement si une certaine condition est remplie. Cela est particulièrement utile pour filtrer des données ou contrôler le flux de l'exécution.

=== Exemple avec une boucle `for`

```sh
for i in {1..10}; do
    if [ $((i % 2)) -eq 0 ]; then
        echo "$i est un nombre pair"
    else
        echo "$i est un nombre impair"
    fi
done
```

[NOTE.speaker]
--
**Explication**

* `for i in {1..10}; do` : Itère sur les nombres de 1 à 10.
* `if [ $((i % 2)) -eq 0 ];` then : Vérifie si le reste de la division de i par 2 est égal à 0. Si oui, i est pair.
* `echo "$i est un nombre pair"` : Affiche que le nombre est pair.
* `else` : Si la condition if n'est pas remplie, cette partie est exécutée.
* `echo "$i est un nombre impair"` : Affiche que le nombre est impair.
* `fi` : Fin de la condition if.
--

=== Exemple avec une boucle `while`

```sh
count=1
while [ $count -le 5 ]; do
    if [ $count -eq 3 ]; then
        echo "Le nombre est trois"
    else
        echo "Le nombre est $count"
    fi
    ((count++))
done
```

[NOTE.speaker]
--
**Explication**

* `while [ $count -le 5 ]; do` : Continue d'exécuter la boucle tant que `count` est inférieur ou égal à 5.
* `if [ $count -eq 3 ]; then` : Vérifie si `count` est égal à 3.
* `echo "Le nombre est trois"` : Affiche un message spécial si `count` est 3.
* `else` : Si `count` n'est pas 3, cette partie est exécutée.
* `echo "Le nombre est $count"` : Affiche le nombre courant.
* `((count++))` : Incrémente `count`.
* `done` : Fin de la boucle while.
--

== Démonstration

**Les boucles et conditions en bash**

[NOTE.speaker]
--
* **Boucle `for`**

La boucle for est idéale pour parcourir une série d'éléments, comme une liste de fichiers ou de nombres.

**Exemple** : Parcourir une liste de noms de fichiers dans un répertoire

```sh
#!/bin/bash

# Liste tous les fichiers dans le répertoire courant
for fichier in *
do
    echo "Traitement de $fichier"
done
```

**Explication :**

* Le caractère `*` représente tous les fichiers du répertoire courant.
* La boucle `for` parcourt chaque fichier et exécute la commande `echo` pour afficher son nom.

* **Boucle `while`**

La boucle while continue tant qu'une condition est vraie.

**Exemple** : Compter jusqu'à 5

```sh
#!/bin/bash

compteur=1

while [ $compteur -le 5 ]
do
    echo "Compteur: $compteur"
    compteur=$((compteur + 1))
done
```

**Explication :**

* La boucle continue tant que la variable `compteur` est inférieure ou égale à 5.
* Chaque itération incrémente compteur de 1.

* **Boucle `until`**

La boucle until est similaire à la boucle while, mais elle continue jusqu'à ce que la condition devienne vraie.

**Exemple** : Compter jusqu'à 5 en utilisant until

```sh
#!/bin/bash

compteur=1

until [ $compteur -gt 5 ]
do
    echo "Compteur: $compteur"
    compteur=$((compteur + 1))
done
```

**Explication :**

* Contrairement à `while`, `until` continue tant que compteur est inférieur ou égal à 5. La boucle se termine lorsque la condition devient vraie (c’est-à-dire lorsque compteur devient supérieur à 5).

* **Boucle `select`**

La boucle select est utilisée pour créer des menus interactifs.

**Exemple** : Menu interactif pour choisir une option

```sh
#!/bin/bash

PS3="Choisissez une option : "
options=("Option 1" "Option 2" "Quitter")
select opt in "${options[@]}"
do
    case $opt in
        "Option 1")
            echo "Vous avez choisi l'Option 1"
            ;;
        "Option 2")
            echo "Vous avez choisi l'Option 2"
            ;;
        "Quitter")
            break
            ;;
        *)
            echo "Choix invalide"
            ;;
    esac
done
```

**Explication** :

* `select` génère un menu basé sur les éléments de la liste options.
* L'utilisateur est invité à choisir une option, et le script réagit en conséquence grâce à une structure `case`.

* **Utilisation de `if` dans un script**

Le bloc if est utilisé pour tester des conditions.

**Exemple** : Vérifier si un fichier existe

```sh
#!/bin/bash

fichier="exemple.txt"

if [ -f "$fichier" ]; then
    echo "Le fichier $fichier existe."
else
    echo "Le fichier $fichier n'existe pas."
fi
```

**Explication :**

* La condition `[ -f "$fichier" ]` vérifie si le fichier `exemple.txt` existe.
* Si c'est le cas, le script affiche un message confirmant l'existence du fichier ; sinon, il affiche un message indiquant que le fichier n'existe pas.
