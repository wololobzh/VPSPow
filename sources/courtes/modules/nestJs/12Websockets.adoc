== Que sont les Websockets ?

Les Websockets sont un protocole permettant la communication en temps réels entre un client et un serveur.

Le protocole Websockets a été conçu pour être compatible avec le protocole http, en fonctionnant sur les ports 80 (http) et 443 (https).

=== Principe de fonctionnement des Websockets

Au moment où un client tente de contacter un serveur websockets, le protocole http est utilisé, et lorsque le serveur répond, il se produit ce qu'on appelle une handshake (signal d'authentification  servant à coordonner les deux parties ).

Si cette handshake est réalisé avec succès, le header https://en.wikipedia.org/wiki/HTTP/1.1_Upgrade_header[Upgrade] permettra de passer du protocole HTTP au protocole Websockets.

Ce header est aussi utilisé quand on se connecte à un site Web, c'est lui qui permet de mettre en place la connexion HTTPS quand on s'est connecté en HTTP (si le serveur est bien configuré).

[background-color="var(--r-oclock-color)"]
=== Choix de la technologie

Pour mettre en place les websockets, on a le choix entre deux des implémentations les plus populaires de ce protocole : socket.io ou la librairie ws.

On a choisi d'intégrer socket.io à NestJS, car c'est une librairie très populaire et surtout, parce que les choses sont rendues plus simples avec cette librairie, on aura moins de code à faire.

== Concepts : les gateways

Pour comprendre comment intégrer les websockets à NestJS, il faut comprendre ce que sont les gateways.

Gateway signifie littéralement passerelle. Dans NestJS, les *_gateways_* sont des classes décorées avec `@WebSocketGateway()`.

Les données transitent par ces classes, elles écoutent des évènements, reçoivent et transmettent des données.

On peut aussi les injecter dans d'autres classes ou leur injecter des classes.

En ce sens, elles sont traitées comme des providers.

[background-color="var(--r-demonstration)"]
== Mise en place

Avec la CLI, on peut générer une gateway, le module movie sera mis à jour en conséquence (on vérifiera quand même ) :

[source,bash]
----
nest g gateway movie --no-spec
----

On lit le code de ce nouveau fichier, il y a déjà du code boilerplate, dont deux décorateurs :

* `@WebSocketGateway()` Ce décorateur déclare la classe en tant que gateway, ce qui rend possible la gestion de connexion et d'évènements  WebSockets.

* `@SubscribeMessage('message')` Ce décorateur  indique que la méthode `handleMessage(client: any, data: any)` gèrera des évènements dont le nom est 'message'.

[background-color="var(--r-demonstration)"]
=== Mise en place du serveur

On va modifier cette classe pour la dynamiser et la rendre plus intéressante :

[source,typescript]
----
import {
  SubscribeMessage,
  WebSocketGateway,
  MessageBody,
  WebSocketServer,
} from '@nestjs/websockets';
import { Server } from 'socket.io';

@WebSocketGateway({
  cors: {
    origin: '*',
  },
})
export class MovieGateway {
  @WebSocketServer()
  server: Server;
  @SubscribeMessage('ping')
  handleMessage(@MessageBody() data: string): object {
    return {
      event: 'pong',
      data: `Hello ! We received ${data}`,
    };
}
----

=== Le client

[source,javascript]
----
const { io } = require('socket.io-client');
function callServer() {
  const ioClient = io('http://localhost:3000', {
    autoConnect: false,
   // TODO : expliquer ça
    transports: ['websocket', 'polling'],
  });
  // On se connecte au serveur
  ioClient.connect();
  // On émet un évènement, et on envoie des données
  ioClient.emit('ping', 'Hello world!');
  // On reçoit un message depuis le serveur
  ioClient.on('pong', (data) => {
    console.log('RECEIVED', data);
  });
  // est-on connecté ?
  ioClient.on('connect', () => {
    console.log('connected');
  });
}
callServer();
----

== Bonus : Un service Websockets

[background-color="var(--r-demonstration)"]
=== Bonus : Souscription à un évènement

Voici le service `socket`, il recevra les connexions des clients et les enregistrera pour pouvoir leur envoyer des messages.

On ajoute une méthode emitEvent qui enverra les messages aux clients.

[source,typescript]
----
// socket/socket.service.ts
import { Injectable } from '@nestjs/common';
import { Socket } from 'socket.io';
@Injectable()
export class SocketService {
  private connectedClients: Map<string, Socket> = new Map();
  handleConnection(socket: Socket): void {
    // Id du client qui se connecte pour recevoir des messages
    const clientId = socket.id;
    this.connectedClients.set(clientId, socket);

    socket.on('disconnect', () => {
      this.connectedClients.delete(clientId);
    });
  }
  emitEvent(event: string, data: any) {
      // Chaque client est un socket, on envoie un message à chacun
    this.connectedClients.forEach((client) => {
      client.emit(event, data);
    });
  }
}
----

=== Bonus : Souscription à un évènement

On implémente le gateway avec pour gérer les connexions, on se souvient que le gateway est la passerelle entre le serveur Websockets et NestJS :

[source,typescript]
----
import {
  WebSocketGateway,
  OnGatewayConnection,
  WebSocketServer,
} from '@nestjs/websockets';
import { Socket } from 'socket.io';
import { SocketService } from './socket.service';

@WebSocketGateway()
export class SocketGateway implements OnGatewayConnection {
  @WebSocketServer()
  private server: Socket;

  constructor(private readonly socketService: SocketService) {}

  handleConnection(socket: Socket): void {
    this.socketService.handleConnection(socket);
  }

  emitEvent(event: string, data: any): void {
    this.socketService.emitEvent(event, data);
  }
}
----

=== Bonus : Souscription à un évènement

On peut à présent dire à notre provider d'envoyer un évènement websockets dans la méthode `create` de `movie.provider` :

[source,typescript]
----
// ...
import { SocketService } from '../socket/socket.service';

@Resolver((of) => MovieType)
export class MovieResolver {
  constructor(
    // ...
    // On injecte notre service WebSockets
    private readonly socketService: SocketService,
  ) {}
  @Mutation((returns) => MovieType)
  async create(@Args('data') data: MovieInput) {
    const movie = await this.movieService.create(data);
    // On émet l'évènement avec les données
    this.socketService.emitEvent('movieAdded', movie);

    return movie;
  }
}
----

1. Créer un gateway pour les produits :
+
```typescript
@WebSocketGateway({
  cors: {
    origin: '*',
  },
})
export class ProductGateway {
  @WebSocketServer()
  server: Server;

  notifyPriceChange(productId: number, oldPrice: number, newPrice: number) {
    this.server.emit('priceChanged', {
      productId,
      oldPrice,
      newPrice,
      timestamp: new Date()
    });
  }
}
```

2. Modifier le service des produits :
+
```typescript
@Injectable()
export class ProductService {
  constructor(private productGateway: ProductGateway) {}

  async updatePrice(id: number, newPrice: number) {
    const product = await this.findOne(id);
    const oldPrice = product.price;
    
    await this.prisma.product.update({
      where: { id },
      data: { price: newPrice }
    });

    this.productGateway.notifyPriceChange(id, oldPrice, newPrice);
  }
}
```

3. Client WebSocket simple :
+
```javascript
const socket = io('http://localhost:3000');

socket.on('priceChanged', (data) => {
  console.log(`Prix modifié pour le produit ${data.productId}`);
  console.log(`Ancien prix: ${data.oldPrice}€`);
  console.log(`Nouveau prix: ${data.newPrice}€`);
});
```
