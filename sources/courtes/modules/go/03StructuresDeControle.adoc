== Structure if

Les if en Go ont quelques particularités :

* Pas de parenthèses obligatoires
* Accolades obligatoires
* Possibilité d'initialisation

[source,go]
----
// Simple if
if x > 0 {
    return y
}

// If avec initialisation
if err := operation(); err != nil {
    return err
}
----

[NOTE.speaker]
--
Les accolades sont toujours obligatoires, même pour une seule instruction.
L'initialisation permet de limiter la portée des variables.
Le style Go évite les else inutiles après un return.
--

== Boucles for

Go n'a qu'une seule structure de boucle : for

* Boucle classique style C
* Boucle condition (while)
* Boucle infinie
* Boucle range

[source,go]
----
// Style C
for i := 0; i < 10; i++ {
    // ...
}

// Style while
for condition {
    // ...
}

// Boucle infinie
for {
    // ...
}

// Range
for index, value := range slice {
    // ...
}
----

[NOTE.speaker]
--
for est très flexible en Go.
range est particulièrement utile pour les collections.
Pas de while ou do-while comme en C.
L'identifiant blanc _ permet d'ignorer des valeurs.
--

== Switch

Le switch en Go est plus flexible qu'en C :

* Pas limité aux constantes
* Pas de fall-through automatique
* Peut être utilisé sans expression
* Type switch pour les interfaces

=== Switch

[source,go]
----
// Switch classique
switch valeur {
case 1:
    // ...
case 2, 3, 4:
    // ...
default:
    // ...
}

// Switch sans expression
switch {
case condition1:
    // ...
case condition2:
    // ...
}

// Type switch
switch v := interface{}.(type) {
case int:
    // v est un int
case string:
    // v est une string
}
----

[NOTE.speaker]
--
Le switch est très utilisé en Go.
Remplace souvent les chaînes if-else.
Le type switch est unique à Go.
Pas de break nécessaire.
--

```go
package main

import "fmt"

func decribeType(v interface{}) {
    switch x := v.(type) {
    case nil:
        fmt.Println("x est nil")
    case int:
        fmt.Printf("x est un entier: %d\n", x)
    case bool:
        fmt.Printf("x est un booléen: %v\n", x)
    case string:
        fmt.Printf("x est une chaîne: %q\n", x)
    default:
        fmt.Printf("x est de type: %T\n", x)
    }
}

func main() {
    decribeType(42)
    decribeType("hello")
    decribeType(true)
    decribeType(3.14)
}
```
