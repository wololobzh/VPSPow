== Types de Base

Go propose plusieurs types de base :

* Nombres entiers : `int`, `int8`, `int16`, `int32`, `int64`, `uint8`, etc.
* Nombres flottants : `float32`, `float64`
* Booléens : `bool`
* Chaînes : `string`
* Complexes : `complex64`, `complex128`

[source,go]
----
var (
    age int = 25
    pi float64 = 3.14159
    estValide bool = true
    message string = "Hello, Go!"
)
----

[NOTE.speaker]
--
int est dépendant de l'architecture (32 ou 64 bits).
Les chaînes sont immuables et encodées en UTF-8.
Les conversions entre types numériques doivent être explicites.
Les valeurs zéro sont 0, 0.0, false, "" respectivement.
--

== Arrays et Slices

Arrays :

* Taille fixe
* Partie du type
* Passés par copie

Slices :

* Taille dynamique
* Référence à un array
* Plus flexibles et plus utilisés

=== Arrays et Slices

[source,go]
----
// Array
var nombres [5]int = [5]int{1, 2, 3, 4, 5}

// Slice
nombres := []int{1, 2, 3}
nombres = append(nombres, 4, 5)
----

[NOTE.speaker]
--
Les arrays sont rarement utilisés directement.
Les slices sont des vues sur des arrays.
append peut réallouer l'array sous-jacent.
make permet de préallouer la capacité.
--

== Maps

Les maps sont des collections clé-valeur :

* Clés doivent être comparables
* Accès et modification O(1)
* Ordre d'itération non garanti

[source,go]
----
// Déclaration et initialisation
scores := map[string]int{
    "Alice": 100,
    "Bob":   85,
}

// Accès et vérification
score, exists := scores["Alice"]
----

[NOTE.speaker]
--
make peut être utilisé pour créer une map.
L'accès retourne la valeur zéro si la clé n'existe pas.
Le deuxième retour indique si la clé existe.
delete supprime une entrée.
--

// tag::demo[]
== Démonstration Maps

[NOTE.speaker]
--

+
```go
package main

import "fmt"

func main() {
    // Création
    utilisateurs := make(map[string]int)

    // Ajout d'entrées
    utilisateurs["Alice"] = 25
    utilisateurs["Bob"] = 30

    // Vérification d'existence
    age, present := utilisateurs["Charlie"]
    if !present {
        fmt.Println("Charlie n'existe pas")
    }

    // Suppression
    delete(utilisateurs, "Bob")

    // Itération
    for nom, age := range utilisateurs {
        fmt.Printf("%s a %d ans\n", nom, age)
    }
}
```

== Structures

Les structures permettent de grouper des données :

* Types personnalisés
* Champs nommés
* Méthodes associables

[source,go]
----
type Personne struct {
    Nom    string
    Age    int
    Actif  bool
}

p := Personne{
    Nom: "Alice",
    Age: 30,
    Actif: true,
}
----

[NOTE.speaker]
--
Les champs exportés commencent par une majuscule.
L'initialisation peut être ordonnée ou nommée.
Les champs non initialisés prennent leur valeur zéro.
Les structures peuvent être imbriquées.
--
