== Introduction à Gin

Gin est un framework web rapide pour Go :

* Performance élevée
* Middleware support
* Routing flexible
* Validation intégrée

=== Introduction à Gin

[source,go]
----
// Installation
go get -u github.com/gin-gonic/gin

// Serveur de base
package main

import "github.com/gin-gonic/gin"

func main() {
    r := gin.Default()
    r.GET("/ping", func(c *gin.Context) {
        c.JSON(200, gin.H{
            "message": "pong",
        })
    })
    r.Run(":8080")
}
----

[NOTE.speaker]
--
Gin est un des frameworks web les plus populaires en Go.
gin.Default() inclut déjà des middlewares de base.
Le routeur est très performant.
Les handlers reçoivent un gin.Context.
--

2. Dans main.go :
+
```go
package main

import (
    "github.com/gin-gonic/gin"
    "myapi/handlers"
    "myapi/middleware"
)

func main() {
    r := gin.Default()
    
    // Middleware global
    r.Use(middleware.Logger())
    
    // Routes
    api := r.Group("/api")
    {
        users := api.Group("/users")
        {
            users.GET("/", handlers.GetUsers)
            users.POST("/", handlers.CreateUser)
            users.GET("/:id", handlers.GetUser)
        }
    }
    
    r.Run(":8080")
}
```

== Routes et Handlers

Organisation des routes avec Gin :

[source,go]
----
// Groupes de routes
api := r.Group("/api/v1")
{
    users := api.Group("/users")
    {
        users.GET("/", handlers.ListUsers)
        users.POST("/", handlers.CreateUser)
        users.GET("/:id", handlers.GetUser)
        users.PUT("/:id", handlers.UpdateUser)
        users.DELETE("/:id", handlers.DeleteUser)
    }
}
----

[NOTE.speaker]
--
Les groupes permettent d'organiser les routes.
Les paramètres d'URL sont accessibles via c.Param().
Les querystrings via c.Query().
Les données POST via c.PostForm() ou c.BindJSON().
--

== Démonstration Handlers

[NOTE.speaker]
--
1. Créer handlers/user.go :
+
```go
package handlers

import (
    "github.com/gin-gonic/gin"
    "net/http"
)

type User struct {
    ID   string `json:"id"`
    Name string `json:"name" binding:"required"`
    Age  int    `json:"age" binding:"required,gte=0"`
}

func CreateUser(c *gin.Context) {
    var user User
    if err := c.ShouldBindJSON(&user); err != nil {
        c.JSON(http.StatusBadRequest, gin.H{
            "error": err.Error(),
        })
        return
    }
    
    // Simuler sauvegarde
    user.ID = "123" // En pratique, généré par la BD
    
    c.JSON(http.StatusCreated, user)
}

func GetUser(c *gin.Context) {
    id := c.Param("id")
    // Simuler récupération depuis BD
    user := User{
        ID: id,
        Name: "John Doe",
        Age: 30,
    }
    c.JSON(http.StatusOK, user)
}
```

== Middlewares

Les middlewares permettent d'intercepter les requêtes :

[source,go]
----
func Logger() gin.HandlerFunc {
    return func(c *gin.Context) {
        start := time.Now()
        
        // Passer au prochain handler
        c.Next()
        
        // Après la réponse
        duration := time.Since(start)
        fmt.Printf("Request took %v\n", duration)
    }
}

// Utilisation
r.Use(Logger())
----

[NOTE.speaker]
--
Les middlewares peuvent être globaux ou par route.
c.Next() permet de continuer la chaîne.
c.Abort() arrête le traitement.
Utiles pour auth, logging, CORS, etc.
--

== Opérations CRUD

Implementation des opérations CRUD :

* CREATE - POST
* READ - GET
* UPDATE - PUT/PATCH
* DELETE - DELETE

[source,go]
----
// Création
c.JSON(http.StatusCreated, gin.H{"id": id})

// Lecture
c.JSON(http.StatusOK, item)

// Mise à jour
c.JSON(http.StatusOK, updated)

// Suppression
c.Status(http.StatusNoContent)
----

[NOTE.speaker]
--
Utiliser les bons codes HTTP.
Valider les entrées.
Gérer les erreurs proprement.
Retourner des réponses cohérentes.
