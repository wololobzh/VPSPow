== Introduction au package net/http

=== Comprendre les requêtes HTTP en Go

Le package `net/http` fournit des fonctionnalités pour effectuer des requêtes HTTP et créer des serveurs HTTP.

[source,go]
----
import "net/http"

resp, err := http.Get("https://api.example.com/data")
if err != nil {
    // Gestion de l'erreur
}
defer resp.Body.Close()
----

=== Effectuer des requêtes GET, POST, PUT, DELETE

.Requête GET
[source,go]
----
resp, err := http.Get("https://api.example.com/data")
----

.Requête POST
[source,go]
----
data := []byte(`{"name": "John", "age": 30}`)
resp, err := http.Post("https://api.example.com/users", "application/json", bytes.NewBuffer(data))
----

.Requête PUT et DELETE
[source,go]
----
client := &http.Client{}

// PUT
req, err := http.NewRequest(http.MethodPut, "https://api.example.com/users/1", bytes.NewBuffer(data))
resp, err := client.Do(req)

// DELETE
req, err := http.NewRequest(http.MethodDelete, "https://api.example.com/users/1", nil)
resp, err := client.Do(req)
----

== Interagir avec une API REST

=== Envoi et réception de données JSON

Le package `encoding/json` est utilisé pour encoder et décoder des données JSON.

[source,go]
----
import "encoding/json"

type User struct {
    Name string `json:"name"`
    Age  int    `json:"age"`
}

user := User{Name: "Alice", Age: 25}

// Encoder en JSON
jsonData, err := json.Marshal(user)

// Décoder du JSON
var decodedUser User
err = json.Unmarshal(jsonData, &decodedUser)
----

=== Utilisation du package encoding/json

.Décoder la réponse JSON d'une API
[source,go]
----
resp, err := http.Get("https://api.example.com/users/1")
if err != nil {
    // Gestion de l'erreur
}
defer resp.Body.Close()

var user User
err = json.NewDecoder(resp.Body).Decode(&user)
if err != nil {
    // Gestion de l'erreur
}
fmt.Printf("User: %+v\n", user)
----

== Démonstration

Requête à une API météo

[NOTE.speaker]
--
Nous allons créer un programme qui fait une requête GET à une API météo et affiche les résultats.

1. Créer un fichier `weather_api.go`
2. Implémenter une fonction pour faire une requête à l'API OpenWeatherMap
3. Décoder la réponse JSON et afficher les informations météo

.weather_api.go
```go
package main

import (
    "encoding/json"
    "fmt"
    "net/http"
    "os"
)

type WeatherData struct {
    Main struct {
        Temp float64 `json:"temp"`
    } `json:"main"`
    Weather []struct {
        Description string `json:"description"`
    } `json:"weather"`
}

func main() {
    apiKey := "YOUR_API_KEY" // Remplacez par votre clé API
    city := "Paris"
    url := fmt.Sprintf("http://api.openweathermap.org/data/2.5/weather?q=%s&appid=%s&units=metric", city, apiKey)

    resp, err := http.Get(url)
    if err != nil {
        fmt.Println("Erreur lors de la requête:", err)
        os.Exit(1)
    }
    defer resp.Body.Close()

    var data WeatherData
    if err := json.NewDecoder(resp.Body).Decode(&data); err != nil {
        fmt.Println("Erreur lors du décodage JSON:", err)
        os.Exit(1)
    }

    fmt.Printf("Température à %s: %.1f°C\n", city, data.Main.Temp)
    if len(data.Weather) > 0 {
        fmt.Printf("Conditions: %s\n", data.Weather[0].Description)
    }
}
```

Expliquez comment la structure `WeatherData` est utilisée pour correspondre à la structure JSON de la réponse de l'API. Montrez comment les champs JSON sont mappés aux champs de la structure Go.
--

== Exercice 1 : Requête à une API externe

Objectif : Créer un programme Go qui fait une requête GET à une API publique et affiche les résultats.

1. Choisissez une API publique (par exemple, https://jsonplaceholder.typicode.com/)
2. Créez un fichier `api_client.go`
3. Implémentez une fonction qui fait une requête GET à l'API choisie
4. Décodez la réponse JSON dans une structure Go appropriée
5. Affichez les résultats dans la console

[TIP]
Utilisez `json.Unmarshal()` ou `json.NewDecoder()` pour décoder la réponse JSON.
