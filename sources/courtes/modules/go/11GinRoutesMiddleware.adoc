== Middlewares d'Authentification

Création d'un système d'authentification complet :

[source,go]
----
type Claims struct {
    UserID string `json:"user_id"`
    Role   string `json:"role"`
    jwt.StandardClaims
}

func AuthMiddleware() gin.HandlerFunc {
    return func(c *gin.Context) {
        token := c.GetHeader("Authorization")
        if token == "" {
            c.AbortWithStatusJSON(401, gin.H{
                "error": "authorization required",
            })
            return
        }

        claims, err := validateToken(token)
        if err != nil {
            c.AbortWithStatusJSON(401, gin.H{
                "error": "invalid token",
            })
            return
        }

        // Stocker les informations dans le contexte
        c.Set("userID", claims.UserID)
        c.Set("role", claims.Role)
        
        c.Next()
    }
}
----

[NOTE.speaker]
--
L'authentification est souvent le premier middleware.
Les JWT sont couramment utilisés pour l'auth.
Les informations utilisateur sont stockées dans le contexte.
La validation du token doit être robuste.
--

== Démonstration Auth Middleware

[NOTE.speaker]

1. Créer middleware/auth.go :

```go
package middleware

import (
    "github.com/gin-gonic/gin"
    "github.com/dgrijalva/jwt-go"
    "net/http"
    "strings"
)

func AuthRequired(roles ...string) gin.HandlerFunc {
    return func(c *gin.Context) {
        auth := c.GetHeader("Authorization")
        if !strings.HasPrefix(auth, "Bearer ") {
            c.AbortWithStatusJSON(http.StatusUnauthorized, gin.H{
                "error": "invalid token format",
            })
            return
        }

        tokenString := strings.TrimPrefix(auth, "Bearer ")
        claims := &Claims{}

        token, err := jwt.ParseWithClaims(tokenString, claims, func(token *jwt.Token) (interface{}, error) {
            return []byte("your-secret-key"), nil
        })

        if err != nil || !token.Valid {
            c.AbortWithStatusJSON(http.StatusUnauthorized, gin.H{
                "error": "invalid token",
            })
            return
        }

        if len(roles) > 0 {
            hasRole := false
            for _, role := range roles {
                if claims.Role == role {
                    hasRole = true
                    break
                }
            }
            if !hasRole {
                c.AbortWithStatusJSON(http.StatusForbidden, gin.H{
                    "error": "insufficient permissions",
                })
                return
            }
        }

        c.Set("user", claims)
        c.Next()
    }
}
```

== Logging et Monitoring

Middleware pour le logging et monitoring :

[source,go]
----
func Logger() gin.HandlerFunc {
    return func(c *gin.Context) {
        start := time.Now()
        path := c.Request.URL.Path
        
        // Continuer le traitement
        c.Next()
        
        // Après la réponse
        latency := time.Since(start)
        status := c.Writer.Status()
        
        log.Printf("[%d] %s %s - %v", 
            status, c.Request.Method, path, latency)
    }
}

func Metrics() gin.HandlerFunc {
    return func(c *gin.Context) {
        start := time.Now()
        
        c.Next()
        
        duration := time.Since(start)
        // Enregistrer les métriques (ex: Prometheus)
        metrics.RequestDuration.Observe(duration.Seconds())
    }
}
----

[NOTE.speaker]
--
Le logging doit être structuré et utile.
Les métriques sont importantes pour le monitoring.
Attention à la performance des middlewares.
Considérer l'utilisation d'outils comme Prometheus.

Gestion avancée des routes et paramètres :

[source,go]

type SearchParams struct {
    Query    string   `form:"q"`
    Tags     []string `form:"tags"`
    Page     int      `form:"page" binding:"gte=1"`
    PageSize int      `form:"page_size" binding:"required,gte=1,lte=100"`
}

func SearchHandler(c *gin.Context) {
    var params SearchParams
    if err := c.ShouldBindQuery(&params); err != nil {
        c.JSON(400, gin.H{"error": err.Error()})
        return
    }
    
    // Utilisation des paramètres validés
    results := performSearch(params)
    c.JSON(200, results)
}
----

[NOTE.speaker]
--
La validation des paramètres est cruciale.
Les structures permettent une validation déclarative.
Les tags de binding offrent une grande flexibilité.
La documentation des paramètres est importante.

```go
package handlers

import (
    "github.com/gin-gonic/gin"
    "github.com/gin-gonic/gin/binding"
    "net/http"
)

type ProductFilter struct {
    Category    string    `form:"category"`
    MinPrice    *float64  `form:"min_price" binding:"omitempty,gte=0"`
    MaxPrice    *float64  `form:"max_price" binding:"omitempty,gtefield=MinPrice"`
    SortBy      string    `form:"sort_by" binding:"omitempty,oneof=price name date"`
    SortOrder   string    `form:"sort_order" binding:"omitempty,oneof=asc desc"`
}

func ListProducts(c *gin.Context) {
    var filter ProductFilter
    if err := c.ShouldBindWith(&filter, binding.Query); err != nil {
        c.JSON(http.StatusBadRequest, gin.H{
            "error": err.Error(),
        })
        return
    }

    // Simulation de recherche
    products := findProducts(filter)
    c.JSON(http.StatusOK, products)
}

func UploadProductImage(c *gin.Context) {
    productID := c.Param("id")
    
    file, err := c.FormFile("image")
    if err != nil {
        c.JSON(http.StatusBadRequest, gin.H{
            "error": "image required",
        })
        return
    }

    // Validation du type de fichier
    if !isValidImageType(file.Header.Get("Content-Type")) {
        c.JSON(http.StatusBadRequest, gin.H{
            "error": "invalid image type",
        })
        return
    }

    // Sauvegarde du fichier
    filename := fmt.Sprintf("products/%s/%s", productID, file.Filename)
    if err := c.SaveUploadedFile(file, filename); err != nil {
        c.JSON(http.StatusInternalServerError, gin.H{
            "error": "failed to save image",
        })
        return
    }

    c.JSON(http.StatusOK, gin.H{
        "filename": filename,
    })
}
```

== Gestion d'Erreurs Globale

Middleware de gestion d'erreurs centralisée :

[source,go]
----
type AppError struct {
    Code    int    `json:"code"`
    Message string `json:"message"`
}

func ErrorHandler() gin.HandlerFunc {
    return func(c *gin.Context) {
        c.Next()

        // Collecter les erreurs
        if len(c.Errors) > 0 {
            err := c.Errors.Last()
            
            if appErr, ok := err.Err.(*AppError); ok {
                c.JSON(appErr.Code, appErr)
                return
            }
            
            // Erreur par défaut
            c.JSON(500, gin.H{
                "error": "internal server error",
            })
        }
    }
}
----

[NOTE.speaker]
--
La gestion centralisée des erreurs est importante.
Permet un format cohérent des erreurs.
Peut inclure du logging et monitoring.
Ne pas exposer les détails sensibles en production.
--
