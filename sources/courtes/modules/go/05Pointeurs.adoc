== Introduction aux pointeurs

Un pointeur est une variable qui stocke l'adresse mémoire d'une autre variable :

* Déclaré avec `*T` où T est le type
* Référencé avec `&` pour obtenir l'adresse
* Peut avoir la valeur `nil`

[source,go]
----
var x int = 42
var p *int = &x  // p pointe vers x
----

[NOTE.speaker]
--
Un pointeur permet d'accéder et de modifier indirectement une valeur.
L'opérateur & donne l'adresse d'une variable.
L'opérateur * permet d'accéder à la valeur pointée.
nil représente un pointeur qui ne pointe vers rien.
--

== Utilisation des pointeurs avec les fonctions

Les pointeurs permettent de modifier les variables passées en paramètre :

[source,go]
----
func modifierValeur(x *int) {
    *x = 100
}

x := 42
modifierValeur(&x)  // x vaut maintenant 100
----

[NOTE.speaker]
--
Sans pointeur, Go passe les arguments par valeur (copie).
Avec un pointeur, on peut modifier la variable originale.
Utile pour éviter de copier de grandes structures de données.
--

== Allocation mémoire

Go propose deux fonctions pour l'allocation mémoire :

* `new(T)` : alloue la mémoire pour un type T
* `make(T, args)` : initialise les slices, maps et channels

[source,go]
----
p := new(int)     // Alloue un int
*p = 42           // Assigne une valeur

s := make([]int, 3)  // Crée un slice de 3 éléments
----

[NOTE.speaker]
--
new() retourne un pointeur vers une valeur zéro du type.
make() est utilisé uniquement pour les slices, maps et channels.
make() initialise la structure interne alors que new() ne fait qu'allouer.
--

== Pointeurs et structures

Les pointeurs sont couramment utilisés avec les structures :

[source,go]
----
type Personne struct {
    Nom string
    Age int
}

p := &Personne{Nom: "Alice", Age: 30}
fmt.Println(p.Nom)  // Accès simplifié
----

[NOTE.speaker]
--
Go permet d'accéder aux champs d'une structure via un pointeur sans déréférencement explicite.
Les méthodes avec récepteur pointeur peuvent modifier la structure.
Les constructeurs retournent souvent des pointeurs vers des structures.
--

--

+
```go
package main

import "fmt"

type Rectangle struct {
    Largeur float64
    Hauteur float64
}

func (r *Rectangle) Double() {
    r.Largeur *= 2
    r.Hauteur *= 2
}

func main() {
    rect := &Rectangle{Largeur: 10, Hauteur: 5}
    
    fmt.Printf("Avant: %+v\n", rect)
    rect.Double()
    fmt.Printf("Après: %+v\n", rect)
}
```
3. Expliquer l'utilisation du récepteur pointeur
4. Montrer comment la méthode modifie la structure
