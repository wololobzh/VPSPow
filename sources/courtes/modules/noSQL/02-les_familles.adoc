== Introduction

// tag::introduction[]
Les bases de données NoSQL se divisent en plusieurs familles, chacune ayant ses propres caractéristiques et cas d'utilisation. Dans ce module, nous explorerons les principales familles de bases de données NoSQL : les bases de données documentaires, les bases de données clé-valeur, les bases de données en colonnes larges et les bases de données graphiques. Nous discuterons des avantages et des inconvénients de chaque type, ainsi que des scénarios dans lesquels ils sont le plus appropriés.
// end::introduction[]

== Les familles de bases de données NoSQL

* Bases de données documentaires
* Bases de données clé-valeur
* Base de données orientée graphes

== Bases de données documentaires

* Stockent les données sous forme de documents (généralement JSON ou BSON).
* Exemples : MongoDB, CouchDB.
* Cas d'utilisation : applications web, gestion de contenu.

== Bases de données clé-valeur

* Stockent les données sous forme de paires clé-valeur.
* Exemples : Redis, DynamoDB.

== Base de données orientée graphes

* Conçues pour stocker et naviguer dans des relations complexes entre les données.
* Exemples : Neo4J

== Pour les applications web

MongoDB
