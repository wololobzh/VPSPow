== Introduction au NoSQL

Les bases de données NoSQL (Not Only SQL) sont conçues pour gérer des volumes massifs de données non structurées ou semi-structurées. Contrairement aux bases de données relationnelles traditionnelles, elles offrent une flexibilité accrue et une scalabilité horizontale.
