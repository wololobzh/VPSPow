// tag::intro[]
Cette formation de 4 jours permet d’apprendre à utiliser Go pour développer des applications backend robustes et bien structurées. En explorant les fondamentaux du langage Go, les participants découvriront l'architecture backend avec le framework Gin, les bases du TDD (Test-Driven Development), et les techniques avancées pour créer des API performantes. L'objectif final est de concevoir un bot Discord en Go capable de communiquer avec une API développée pendant le cours.
// end::intro[]

== Objectifs pédagogiques

// tag::objectifs[]
- Maîtriser les bases du langage Go et l'installation de l'environnement de développement
- Comprendre et appliquer le Test-Driven Development (TDD) avec la bibliothèque de tests standard de Go
- Créer une API RESTful avec le framework Gin
- Intégrer une base de données avec GORM pour gérer les données en Go
- Développer un bot Discord en Go capable de communiquer avec une API
- Mettre en place des tests pour assurer la fiabilité et la maintenabilité du code
// end::objectifs[]

== Notions

// tag::notions[]
- Installation et configuration de Go
- Syntaxe et structures de base de Go
- Test-Driven Development avec la bibliothèque de tests standard
- Concurrence en Go (goroutines et channels)
- Création d'une API RESTful avec Gin
- Gestion des middlewares dans Gin
- Intégration de bases de données avec GORM
- Développement de bots Discord avec discordgo
- Communication entre services via API
- Écriture de tests unitaires et d'intégration pour valider le code
// end::notions[]

== Prérequis formateur
