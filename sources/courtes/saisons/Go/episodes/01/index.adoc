// tag::intro[]
Cette première journée de formation vous permettra de découvrir le langage Go et ses fondamentaux. Vous apprendrez les bases de la syntaxe, la manipulation des différents types de données, la gestion des structures de contrôle, et la création de fonctions. Cette journée pose les fondations essentielles pour devenir un développeur Go efficace et productif.
// end::intro[]

== Objectifs pédagogiques

// tag::objectifs[]
* Comprendre l'écosystème Go et son approche de la programmation
* Maîtriser les types de données fondamentaux et composés
* Manipuler les structures de contrôle (if, for, switch)
* Créer et utiliser des fonctions efficacement
* Appliquer les bonnes pratiques de développement Go
* Organiser son code de manière idiomatique
* Développer des programmes Go maintenables et performants
// end::objectifs[]

== Prérequis formateur

// tag::prerequis[]
* Maîtrise approfondie du langage Go et de son écosystème
* Expérience significative dans le développement Go
* Connaissance des conventions et bonnes pratiques Go
* Maîtrise des outils de développement (go mod, go fmt, etc.)
* Compréhension des concepts de programmation structurée
* Capacité à expliquer les concepts de base de manière claire
* Expérience dans l'enseignement de langages de programmation
// end::prerequis[]
