// tag::intro[]
Cette journée de formation est dédiée à la création d'APIs web avec le framework Gin en Go. Vous découvrirez comment concevoir et implémenter des APIs RESTful performantes et bien structurées. De la mise en place des routes de base à l'implémentation de middlewares avancés, vous apprendrez les meilleures pratiques pour développer des applications web robustes avec Gin.
// end::intro[]

== Objectifs pédagogiques

// tag::objectifs[]
* Comprendre les principes fondamentaux des APIs RESTful
* Maîtriser l'installation et la configuration de Gin
* Implémenter des routes HTTP basiques et avancées
* Créer et utiliser des middlewares personnalisés
* Gérer les requêtes et les réponses HTTP efficacement
* Structurer une application web avec Gin
* Sécuriser les endpoints d'une API
// end::objectifs[]

== Prérequis formateur

// tag::prerequis[]
* Expertise approfondie du framework Gin
* Maîtrise des principes REST et des protocoles HTTP
* Expérience significative dans le développement d'APIs
* Connaissance des bonnes pratiques de sécurité web
* Compréhension des patterns de conception web
* Maîtrise des outils de test d'API (Postman, curl)
* Expérience dans la gestion des erreurs HTTP
// end::prerequis[]
