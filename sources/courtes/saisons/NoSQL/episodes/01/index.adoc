// tag::intro[]
Cette première journée de formation vous permettra de découvrir le noSQL et ses concepts fondamentaux. Vous apprendrez les différences entre les bases de données relationnelles et NoSQL, ainsi que les différents types de bases NoSQL (documentaires, clé-valeur, colonnes larges, graphes). La formation couvrira également les cas d'utilisation appropriés pour chaque type de base de données NoSQL. Des exercices pratiques vous permettront de vous familiariser avec l'installation, la configuration et les opérations de base sur des bases de données NoSQL populaires telles que MongoDB et Cassandra.
// end::intro[]

== Objectifs pédagogiques

// tag::objectifs[]
* Comprendre NoSQL et son positionnement face au SQL.
* Installer MongoDB + MongoDB Compass.
* Manipuler ses premières bases et collections.
* Savoir rechercher, filtrer, limiter, projeter des données.
* Modifier et supprimer des documents.
// end::objectifs[]

== Prérequis formateur

// tag::prerequis[]
* Avoir une bonne connaissance des bases de données NoSQL et de leurs types.
* Maîtriser les concepts fondamentaux des bases de données NoSQL.
// end::prerequis[]
