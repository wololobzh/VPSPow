// tag::intro[]
Cette journée de formation permet de maîtriser l’utilisation de GraphQL avec NestJS pour créer des API flexibles et performantes. Vous apprendrez à configurer et à exploiter GraphQL au sein d’une application NestJS, en optimisant les requêtes et en structurant vos données pour une gestion efficace.
// end::intro[]

// == Objectifs pédagogiques
// tag::objectifs[]
* Comprendre les concepts de base de GraphQL
* Configurer une API GraphQL dans un projet NestJS
* Créer des schémas, types et résolveurs en GraphQL
* Gérer les requêtes et mutations GraphQL avec NestJS
* Optimiser les performances des requêtes GraphQL
* Intégrer des fonctionnalités avancées comme la pagination et les filtres
* Assurer la sécurité des API GraphQL
// end::objectifs[]

== Prérequis formateur
// tag::prerequis[]
* Maîtrise avancée de NestJS
* Expérience pratique avec GraphQL et la création d’API GraphQL
* Connaissance approfondie des concepts de schémas, types et résolveurs en GraphQL
* Compétences en optimisation de requêtes et gestion des performances GraphQL
* Connaissance des pratiques de sécurité pour les API GraphQL
* Expérience avec des fonctionnalités avancées de GraphQL (pagination, filtrage, etc.)
* Compétences pédagogiques
// end::prerequis[]
