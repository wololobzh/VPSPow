// tag::intro[]
Cette journée de formation permet de maîtriser l’utilisation des DTO (Data Transfer Objects), la dynamisation des données et la gestion des associations avec NestJS. Vous apprendrez à structurer et valider les échanges de données, à dynamiser vos applications avec des fonctionnalités avancées et à gérer efficacement les relations entre entités.
// end::intro[]

== Objectifs pédagogiques

// tag::objectifs[]
* Comprendre le rôle et les avantages des DTO (Data Transfer Objects) dans NestJS
* Créer et valider des DTO pour structurer les échanges de données
* Appliquer les pratiques de dynamisation des données pour rendre les applications plus flexibles
* Gérer les relations et associations entre entités dans NestJS
* Mettre en place des associations avancées (one-to-one, one-to-many, many-to-many) entre entités
* Optimiser la validation et la transformation des données échangées
* Assurer la maintenabilité et la modularité des applications via les DTO et les associations
// end::objectifs[]

== Prérequis formateur

// tag::prerequis[]
* Maîtrise avancée de NestJS
* Expérience avec les DTO et les pratiques de validation de données
* Connaissance approfondie des relations entre entités (one-to-one, one-to-many, many-to-many)
* Expérience pratique dans la dynamisation des données et la gestion des échanges de données
* Compétences en structuration et modularité des applications NestJS
* Connaissance des meilleures pratiques pour la validation et transformation des données
* Compétences pédagogiques
// end::prerequis[]
