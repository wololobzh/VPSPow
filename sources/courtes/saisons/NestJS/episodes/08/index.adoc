// tag::intro[]
Cette journée de formation permet de maîtriser l’utilisation de NestJS dans un environnement de développement piloté par les tests (TDD). Vous apprendrez à structurer et écrire des tests efficaces pour vos applications en NestJS, garantissant ainsi une qualité de code optimale et des fonctionnalités solides.
// end::intro[]

// == Objectifs pédagogiques
// tag::objectifs[]
* Comprendre les fondamentaux de TDD
* Savoir mettre en place un environnement de test dans NestJS
* Appliquer la méthodologie TDD dans un projet NestJS
* Écrire des tests unitaires et d'intégration
* Garantir la qualité et la robustesse du code
* Diagnostiquer et résoudre les erreurs efficacement
// end::objectifs[]

== Prérequis formateur
// tag::prerequis[]
* Maîtrise avancée de NestJS
* Expérience pratique avec le Test-Driven Development (TDD)
* Connaissance approfondie des outils de test (comme Jest) dans l'écosystème NestJS
* Compréhension du cycle « Red-Green-Refactor » propre au TDD
* Expérience en écriture de tests unitaires et d’intégration
* Connaissance des pratiques de développement maintenable et modulaire
* Compétences pédagogiques
// end::prerequis[]
