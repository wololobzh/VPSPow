// tag::intro[]
Cette journée de formation permet de maîtriser la création d’API RESTful avec NestJS pour développer des services backend robustes et maintenables. Vous apprendrez à structurer et organiser des endpoints, à gérer les requêtes et les réponses HTTP, ainsi qu'à intégrer des pratiques de validation et de gestion d'erreurs.
// end::intro[]

// == Objectifs pédagogiques
// tag::objectifs[]
* Comprendre comment le client et le serveur communiquent
* Connaître ce qu’est un serveur web
* Savoir ce qu’est le protocole HTTP
* Comprendre la place et le rôle d’un moteur JS.
* Connaître le concept de runtime
* Connaître et utiliser les modules utilisateurs
* Connaître et utiliser les modules natifs
// end::objectifs[]

== Prérquis formateur
// tag::prerequis[]
* Maîtrise avancée de NestJS
* Expérience pratique avec la création d’API RESTful
* Connaissance approfondie des méthodes HTTP et des principes REST
* Compétences en structuration et organisation des endpoints dans NestJS
* Expérience en gestion des erreurs et validation des données pour les API REST
* Connaissance des pratiques de sécurité pour les API REST (authentification, autorisation, etc.)
* Compétences pédagogiques
// end::prerequis[]
