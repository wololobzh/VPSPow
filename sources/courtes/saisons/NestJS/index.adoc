// tag::intro[]
Cette formation permet d’apprendre à utiliser NestJS pour créer des applications back-end solides et bien structurées. En 8 jours, vous découvrirez les fondamentaux de ce framework Node.js : gestion des modules, création d’API REST, et utilisation de l’injection de dépendances pour écrire un code clair et maintenable.
// end::intro[]

== Objectifs pédagogiques

// tag::objectifs[]
- Comprendre les bases de NestJS et l'installation du framework
- Organiser le code en modules et composants
- Créer et gérer des contrôleurs et services
- Construire une API REST avec NestJS
- Maîtriser l'injection de dépendances
- Utiliser TypeORM pour la gestion des bases de données
- Implémenter la validation des données
- Effectuer des tests unitaires pour assurer la qualité du code
// end::objectifs[]

== Notions

// tag::notions[]
- Installation et configuration de NestJS
- Architecture modulaire
- Contrôleurs et services
- Injection de dépendances
- Création d'API REST
- Middlewares et guards
- Pipes et interceptors
- Gestion des erreurs
- Bases de données avec TypeORM
- Validation des données
- Authentification et autorisation
- Tests unitaires et tests d'intégration
// end::notions[]

== Prérequis formateur
