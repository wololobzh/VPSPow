// tag::intro[]
Bienvenue dans cette formation dédiée à ElectronJS, le framework incontournable pour développer des applications de bureau multiplateformes avec des technologies web. Au cours de cette formation, vous découvrirez les fondamentaux d'ElectronJS, son architecture, et comment créer des applications performantes et attrayantes.
// end::intro[]

== Objectifs pédagogiques

// tag::objectifs[]
* Comprendre les bases d'ElectronJS et son architecture
* Savoir initialiser un projet ElectronJS
* Maîtriser les concepts clés pour développer des applications de bureau
* Être capable de créer une application simple avec ElectronJS
* Découvrir les bonnes pratiques de développement avec ElectronJS
* Apprendre à déboguer et tester des applications ElectronJS
* Explorer les possibilités d'intégration avec d'autres technologies web
// end::objectifs[]

== Prérequis formateur

// tag::prerequis[]
* Connaissances de base en JavaScript, HTML et CSS
* Familiarité avec les concepts de développement web
* Expérience préalable avec Node.js est un plus
* Ordinateurs avec Node.js et npm installés
// end::prerequis[]
