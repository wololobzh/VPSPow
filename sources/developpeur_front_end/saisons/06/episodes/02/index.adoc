// tag::intro[]
Découverte des mécanismes de réactivité dans Svelte et de la gestion des événements utilisateur. Cet épisode explore comment créer des interfaces dynamiques qui réagissent aux actions de l'utilisateur et comment gérer les formulaires de manière efficace avec Svelte 5.
// end::intro[]

== Objectifs pédagogiques

// tag::objectifs[]
* *Comprendre* le concept de réactivité dans Svelte
* *Appliquer* la gestion d'état avec $state
* *Utiliser* les événements pour interagir avec l'utilisateur
* *Créer* des formulaires interactifs
* *Analyser* le comportement des états réactifs
// end::objectifs[]

== Prérequis formateur

// tag::prerequis[]
* Connaissance des bases de JavaScript
* Compréhension des événements du DOM
// end::prerequis[]
