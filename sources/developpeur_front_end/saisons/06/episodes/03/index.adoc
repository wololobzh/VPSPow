// tag::intro[]
Introduction à la manipulation d'API avec `fetch` et à la gestion des requêtes asynchrones en JavaScript. Cette journée explore les concepts fondamentaux des API, les types d'API (REST, GraphQL, etc.) et la manipulation des requêtes HTTP pour échanger des données entre applications. On y voit également le concept d'asynchronisme en JS.
// end::intro[]

== Objectifs pédagogiques

// tag::objectifs[]
* *Comprendre* le concept d'asynchronisme
* *Comprendre* le concept d'API
* *Utiliser* `fetch` pour effectuer des requêtes HTTP
// end::objectifs[]

== Prérequis formateur

// tag::prerequis[]
* Préparer un client HTTP
* Connaître le fonctionnement de JSON Server
// end::prerequis[]
