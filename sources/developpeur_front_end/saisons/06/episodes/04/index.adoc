// tag::intro[]
Découverte et intégration d'un CMS headless (PocketBase) avec Svelte, suivie d'une introduction aux tests unitaires. Cette journée permet de créer une application complète en connectant un backend simple à notre interface Svelte, tout en apprenant à sécuriser notre code grâce aux tests automatisés.
// end::intro[]

== Objectifs pédagogiques

// tag::objectifs[]
* *Comprendre* le concept de CMS headless
* *Installer* et *configurer* PocketBase
* *Créer* des collections de données
* *Comprendre* et *mettre en place* des tests unitaires
// end::objectifs[]

== Prérequis formateur

// tag::prerequis[]
* PocketBase installé localement
* Expérience avec les tests unitaires
* Connaissance de Vitest ou Jest
// end::prerequis[]
