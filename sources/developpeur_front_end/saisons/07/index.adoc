// tag::intro[]
La saison "Projet" est l'aboutissement du parcours Prépa O’clock. Les apprenants mettent en pratique leurs connaissances acquises en HTML, CSS et React pour concevoir et réaliser une application web complète. Ce projet leur permet de consolider leurs compétences et de produire un livrable concret.
// end::intro[]

== Objectifs pédagogiques

// tag::objectifs[]
* Appliquer les connaissances acquises pour concevoir une application web complète
* Travailler sur toutes les étapes du développement d’un projet : conception, développement, débogage, et livraison
* Apprendre à collaborer efficacement en équipe
* Produire un livrable valorisable dans un portfolio professionnel
// end::objectifs[]

== Notions

// tag::notions[]
* Organisation et gestion d’un projet web
* Création d’une structure de projet complète avec React
* Intégration des éléments HTML et CSS pour styliser l’application
* Utilisation de composants dynamiques et gestion des états
* Résolution de problèmes et débogage
* Présentation et valorisation du projet réalisé
// end::notions[]

== Prérequis formateur

// tag::prerequis[]
* Expérience dans la conduite et l’encadrement de projets front-end
* Maîtrise des langages et outils utilisés dans la saison (HTML, CSS, React)
* Capacité à accompagner les apprenants dans la résolution de problèmes techniques
* Aptitude à évaluer et à valoriser les livrables produits
* Sens de l’organisation pour guider efficacement les équipes
// end::prerequis[]

== Résumé

// tag::resume[]
Cette saison offre aux apprenants l’opportunité de mobiliser l’ensemble de leurs acquis à travers un projet concret. Ils apprennent à gérer un projet de bout en bout, tout en consolidant leur maîtrise des outils front-end. Ce livrable pourra enrichir leur portfolio et servir de tremplin pour la suite de leur formation.
// end::resume[]
