Plongée dans le développement frontend moderne avec HTML et CSS, enrichie par l'utilisation d'outils d'IA comme GitHub Copilot. Cette journée pose les fondations essentielles pour créer des interfaces web tout en exploitant les technologies actuelles pour optimiser le processus de développement.

== Objectifs pédagogiques

// tag::objectifs[]
* *Comprendre* la différence entre HTML et CSS
* *Appliquer* HTML pour structurer une page web
* *Appliquer* les concepts fondamentaux du CSS pour styliser des pages
* *Utiliser* GitHub Copilot pour accélérer le développement
* *Évaluer* la pertinence des suggestions d'IA dans le code
// end::objectifs[]

Piqûre de rappel sur la LDC, bien insister sur les chemins (utiliser l’analogie de l’adresse du voisin, GPS ou instructions) :

* Si on est chez soi, et on veut aller chez le coiffeur, au bout de la rue, bon bah, on sort de chez soi, on tourne à droite et c'est tout droit
* Si on est à 300km de chez soi, et qu'on veut aller chez notre coiffeur, si on tourne à droite et on va au bout de la rue, on rentrera surement chez un inconnu et on va se faire engueuler ! C'est donc un chemin relatif, l'origine est importante
* Si on veut utiliser un chemin absolu, on est sûr que ça va marcher peu importe où on se trouve. L'origine est fixe, le chemin toujours le même. Comme si on prenait un GPS, peu importe où on se trouve, avec le GPS, on est sûr d'arriver à bon port

Parler de la tabulation qui auto-complète les chemins / commandes, des Ctrl+Shift+V et Ctrl+Shift+C, et de la flèche du haut dans le terminal

On git clone côté formateur en expliquant rapidement, on rentre pas dans les détails, c'est plus tard dans la journée

On donne le lien liveshare, attention à ceux qui livecode, la compréhension prime sur la maîtrise !
