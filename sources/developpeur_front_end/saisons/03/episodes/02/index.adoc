// tag::intro[]
Cet épisode traite des techniques pour améliorer la lisibilité d'un site, de l'exploration des balises de formulaire à l'aide de la documentation, du choix du type d'input adapté aux données, et de la personnalisation des styles pour les balises input[type=text] et textarea.
// end::intro[]

== Objectifs pédagogiques
// tag::objectifs[]
* Améliorer la lisibilité d'un site
* Rechercher les différentes balises de formulaire avec l'aide de la documentation
* Choisir le bon type d'input en fonction de la donnée
* Styliser les balises input[type=text] et textarea
// end::objectifs[]
