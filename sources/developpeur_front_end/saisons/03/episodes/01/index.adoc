// tag::intro[]
C'est le premier atelier en Pair-Programming pour les apprenants : prenez le temps de bien leur expliquer le fonctionnement et les attentes.
// end::intro[]

== Objectifs pédagogiques

// tag::objectifs[]
🌱 Connaître

* Découvrir les outils (Discord, groupes, Git, environnement).

🧠 Comprendre

* Assimiler le Pair-Programming :
**A (code) / B (guide).

🔧 Appliquer

* S'entraîner sur les layouts en binôme.

🤝 Analyser

* Repérer les blocages et aider activement.

🚀 Créer

* Partager astuces et bonnes pratiques en groupe.
// end::objectifs[]

== Prérequis formateur

// tag::prerequis[]
Problèmes possibles :

* Salon de discussion non créé (Skynet bien configuré ?)
* Pas d'accès au tableur des groupes (connecté au Drive avec l’adresse oclock.school ?)
* Live Share lent (l’hôte a-t-il bien accepté la connexion ?)
* Problème de clonage (clé SSH à régénérer ?)
// end::prerequis[]
