// tag::intro[]
Cet épisode traite de l’utilisation efficace des tableaux HTML et des principes clés du design web responsif. Quand et comment construire un tableau HTML, l’importance du choix des unités pour améliorer l’adaptabilité d’un site, ainsi que l’utilisation des media queries pour garantir une expérience utilisateur optimale sur tous les appareils.
// end::intro[]

== Objectifs pédagogiques

// tag::objectifs[]
* Savoir quand utiliser un tableau HTML
* Construire un tableau HTML
* Connaitre les enjeux du design web responsif
* Faire le bon choix des unités pour améliorer l'adaptabilité d'un site
* Utiliser des media queries
// end::objectifs[]
