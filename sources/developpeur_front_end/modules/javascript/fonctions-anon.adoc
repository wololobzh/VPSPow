== Fonctions anonymes

* Une fonction anonyme est une fonction sans nom
* Elle est souvent utilisée lorsqu'on a besoin d'une fonction temporaire

=== Syntaxe des fonctions anonymes

* une fonction anonyme est souvent utilisée comme valeur d'une variable ou passée en argument à une autre fonction

```js
const afficherMessage = function() {
  console.log("Ceci est une fonction anonyme !");
};
afficherMessage();
```

=== Caractéristiques des fonctions anonymes

* les fonctions anonymes sont utiles pour créer des fonctions rapides et jetables
* elles sont souvent utilisées pour les événements et les callbacks

=== Fonction anonyme comme rappel (callback)

```js
setTimeout(function() {
  console.log("Ce message apparaît après une seconde.");
}, 1000);
```

=== Fonction anonymes dans les méthodes de tableau

```js
const nombres = [1, 2, 3];
const doubles = nombres.map(function(nombre) {
  return nombre * 2;
});
console.log(doubles); // Affiche [2, 4, 6]
```

=== Avantages des fonctions anonymes

* elles simplifient les code quand vous n'aurez pas besoin de réutiliser la fonction
* elles permettent de garder le code plus lisible

== Expressions de fonction

* Les expressions de fonction sont des fonctions stockées dans des variables
* Elles peuvent être nommées ou anonymes

```js
const afficherMessage = function() {
  console.log("Ceci est une expression de fonction !");
};
afficherMessage();
```

=== Différence avec les déclarations de fonction

* Les déclarations de fonction sont "hissées" en haut du script
* Les expressions de fonctions sont idéales pour créer des fonctions dans des contextes limités
