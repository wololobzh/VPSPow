== Collection clé : valeur

* un objet est une structure de données qui stocker des paires clé-valeur
* chaque clé est une chaîne unique
* chaque valeur peut être de n'importe quel type :
** chaîne de caractères
** nombres
** tableaux
** ou même d'autres objets

=== Utilité des objets

* ils permettent de regrouper des données et comportement liés
* cela permet une meilleure organisation et manipulation des données
* ils servent de conteneurs pour stocker des données complexes de manière structurée

== Syntaxe d'un objet simple

Un objet est défini par des accolades `{}`

```js
let objetExemple = {
  cle1: 'valeur1',
  cle2: 'valeur2'
};
```

* `cle1` et `cle2` sont des clés
* `'valeur1'` et `'valeur2'` sont des valeurs qui peuvent être de n'importe quel type
* l'objet `objetExemple` contient deux paires clé-valeur, et regroupe ainsi les données sous une seule entité

// tag::demo[]

== Démonstration

Création d'un objet simple

[NOTE.speaker]
====
```js
// Création de l'objet étudiant
let etudiant = {
  nom: 'Dupont',
  age: 22,
  cours: ['Mathématiques', 'Physique', 'Informatique']
};

// Accéder aux propriétés de l'objet
console.log('Nom :', etudiant.nom);        // Affiche "Nom : Dupont"
console.log('Âge :', etudiant.age);        // Affiche "Âge : 22"
console.log('Cours :', etudiant.cours);    // Affiche "Cours : Mathématiques,Physique,Informatique"
```

**Explication :**

* L'objet `etudiant` est défini avec trois propriétés : `nom`, `age`, et `cours`.
* `nom` est une chaîne, `age` est un nombre, et `cours` est un tableau de chaînes représentant les cours suivis par l'étudiant.
* Les propriétés de l'objet sont accessibles par la notation par point (`etudiant.nom`) ou par crochets (`etudiant['nom']`).
====

== Valeurs possibles

* **Chaînes** : `'texte'`, `"texte"`
* **Nombres** : `42`, `3.14`
* **Booléens** : `true`, `false`
* **Tableaux** : `[1, 2, 3]`
* **Objets** : `{cle: 'valeur'}`
* **Fonctions** : `function() {}`

== Démonstration

Un objet un peu plus complexe

[NOTE.speaker]
====
```js
// Création de l'objet étudiant avec des méthodes
let etudiant = {
  nom: 'Dupont',
  age: 22,
  cours: ['Mathématiques', 'Physique', 'Informatique'],
  
  // Méthode pour afficher les informations de l'étudiant
  afficherInfos: function() {
    console.log(`Nom : ${this.nom}`);
    console.log(`Âge : ${this.age}`);
    console.log(`Cours : ${this.cours.join(', ')}`);
  }
};

// Appeler la méthode pour afficher les informations de l'étudiant
etudiant.afficherInfos();
// Affiche :
// Nom : Dupont
// Âge : 22
// Cours : Mathématiques, Physique, Informatique
```

**Explication :**

* L'objet `etudiant` contient une méthode `afficherInfos` qui affiche les informations de l'étudiant.
* La méthode utilise `this` pour accéder aux propriétés de l'objet.
* La méthode est appelée en utilisant la notation par point (`etudiant.afficherInfos()`).
====

== `window` est un objet

* `window` est un objet global dans les navigateurs
* il contient toutes les variables globales, fonctions, et objets
* il est accessible partout dans le code JavaScript
* `window` est essentiel car il sert de point d'entrée pour interagir avec le navigateur

=== Propriétés courantes

* `window.document` : Représente le document DOM chargé dans la fenêtre.
* `window.innerWidth` et `window.innerHeight` : Renvoient la largeur et la hauteur de la zone de contenu de la fenêtre.
* `window.location` : Contient des informations sur l'URL actuelle.

=== Méthodes courantes

* `window.alert(message)` : Affiche une boîte de dialogue d'alerte avec un message.
* `window.prompt(message, default)` : Affiche une boîte de dialogue qui demande à l'utilisateur de saisir une entrée.
* `window.open(url, name, specs)` : Ouvre une nouvelle fenêtre du navigateur avec l'URL spécifiée.

// tag::demo[]

== Démonstration

Utilisation de `window`

[NOTE.speaker]
====
```js
// Accéder à la largeur et hauteur de la fenêtre
console.log('Largeur de la fenêtre :', window.innerWidth);
console.log('Hauteur de la fenêtre :', window.innerHeight);

// Afficher l'URL actuelle
console.log('URL actuelle :', window.location.href);

// Modifier l'URL (redirection vers une autre page)
// window.location.href = 'https://www.example.com';
```

**Explication :**

* `window.innerWidth` et `window.innerHeight` renvoient la largeur et la hauteur de la zone de contenu de la fenêtre.
* `window.location.href` contient l'URL actuelle de la page.
* `window.location.href = 'https://www.example.com';` redirige l'utilisateur vers une autre page.
====

== Objet => isolation

* l'encapsulation permet de regrouper des données et comportements liés
* cela permet de cacher les détails d'implémentation et de protéger les données
* les objets permettent de créer des instances isolées avec des propriétés et méthodes spécifiques

=== Importance de l'encapsulation

* **Protection des données** : les propriétés de l'objet ne sont pas accessibles directement
* **Modularité** : les objets permettent de diviser le code en parties plus petites et plus gérables
* **Réutilisabilité** : les objets peuvent être réutilisés dans d'autres parties du code

=== Exemple

```js
// Création de l'objet compteur
let compteur = {
  valeur: 0, // Valeur initiale du compteur

  // Méthode pour incrémenter le compteur
  incrementer: function() {
    this.valeur++;
  },

  // Méthode pour décrémenter le compteur
  decrementer: function() {
    this.valeur--;
  },

  // Méthode pour afficher la valeur actuelle du compteur
  afficherValeur: function() {
    console.log(`Valeur actuelle du compteur : ${this.valeur}`);
  }
};

// Utilisation des méthodes du compteur
compteur.incrementer();
compteur.afficherValeur(); // Affiche "Valeur actuelle du compteur : 1"
compteur.decrementer();
compteur.afficherValeur(); // Affiche "Valeur actuelle du compteur : 0"
```

[NOTE.speaker]
====

**Explication :**

* L'objet `compteur` contient une propriété `valeur` et des méthodes pour incrémenter, décrémenter, et afficher la valeur du compteur.
* Les méthodes utilisent `this` pour accéder à la propriété `valeur` de l'objet.
* Les méthodes sont appelées en utilisant la notation par point (`compteur.incrementer()`).
* Les méthodes permettent de manipuler la valeur du compteur de manière contrôlée.
* L'encapsulation permet de protéger la valeur du compteur et de ne pas la modifier directement.

== L'IA pour assister à la création d'objets

* l'IA peut automatiser la création d'objets complexes
* elle peut aider à structurer et organiser les données efficacement
* l'IA peut générer des objets à partir de modèles ou de spécifications
* cela fait économiser du temps et réduit les erreurs humaines

=== Comparaison avec et sans IA

[cols="1,1"]
|===

| **Sans IA** | **Avec IA**

a|
* Création manuelle des objets
* Risque d'erreurs humaines
* Temps de développement plus long
* Besoin de compétences techniques
a|
* Création automatisée des objets
* Réduction des erreurs
* Gain de temps
* Accessible à tous
|===

== Démonstration

Création d'objets avec et sans IA

[NOTE.speaker]
====

* Exemple d'objet complexe à écrire à la main :

```js
let atlas = {
  'Europe': {
    'France' : {
      population: 67795000,
      densite: 100,
      monnaie: 'Euro',
      iso: ['FRA', 'FR']
    },
    'Allemagne': {
      population: 83190556,
      densite: 233,
      monnaie: 'Euro',
      iso: ['DEU', 'DE']
    }
  }
};
```

* Générer le même type d'objet complexe par une IA via un prompt tel que : "Génère un objet comportant plusieurs pays. Chaque pays doit contenir le nom du pays, sa population, sa densité, sa monnaie, et ses codes ISO."

* **Bilan** : c'est plus rapide, moins sujet à erreurs, et accessible à tous.
