== Découvrir la console navigateur

- La console du navigateur est un outil puissant pour les développeurs.
- Elle vous permet de tester du code JavaScript en temps réel et de déboguer vos applications.
- Prenez quelques minutes pour explorer la console dans votre navigateur. Tapez `console.log('Hello, world!')` et voyez ce qui se passe !

== Manipuler quelques premières commandes

- Essayez de manipuler quelques commandes de base dans la console.
- Par exemple, créez une variable avec `let`, modifiez sa valeur et observez les résultats.
- Utilisez le dépôt de démonstration pour voir comment ces commandes s'intègrent dans un projet plus large.

== Réflexion sur l'impact de l'IA

- L'intelligence artificielle transforme la façon dont nous automatisons les tâches répétitives.
- Réfléchissez à la manière dont l'IA change le rôle du développeur. Par exemple, moins de temps passé sur des tâches répétitives signifie plus de temps pour la créativité et l'innovation.
- Discutons ensemble : Comment voyez-vous l'avenir du développement avec l'IA en jeu ?
// end::deroulement[]
