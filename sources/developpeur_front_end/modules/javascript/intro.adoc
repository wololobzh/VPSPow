== C'est quoi le JavaScript ?

=== JavaScript

[quote]
____
ou JS ou ES ou ECMAScript... STOP
____

- *Aucun lien avec Java !*
- JavaScript est un nom marketing
- Créé en 1995 par Netscape

=== JS, un langage

Le JavaScript (_JS_) est un langage de programmation polyvalent, utilisable :

- Côté client (front-end : dans le navigateur)
- Côté serveur (back-end)

=== Pour faire quoi ?

=== Côté client

- HTML = structure / le fond
- CSS = design / la forme
- JS = interactions / dynamisme

=== Côté serveur

Nous aborderons cela plus tard ;)

=== Et concrètement ?

- Créer des interfaces dynamiques comme ces slides
- Accéder à la webcam pour capturer des sourires
- Envoyer des messages de chat en temps réel
- En résumé, créer des expériences interactives et engageantes !

=== Non mais sérieusement…

- Effectuer des actions sans recharger la page
  - Par exemple : supprimer un produit du panier
- Animer les éléments de la page
  - Par exemple : créer un carrousel d'images
- Valider le contenu d'un formulaire en direct
  - Par exemple : afficher un message d'erreur ou de succès instantanément
