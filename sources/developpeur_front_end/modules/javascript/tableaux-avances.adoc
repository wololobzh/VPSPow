== Manipulations avancées

Voyons les méthodes `map`, `filter` et `reduce` qui permettent de manipuler les tableaux de manière avancée.

=== `map`

**Description** : La méthode map crée un nouveau tableau en appliquant une fonction à chaque élément du tableau d'origine.

**Syntaxe** : array.map(callback(currentValue, index, array), thisArg)

**Exemple** :

```js
const numbers = [1, 2, 3, 4];
const doubles = numbers.map(num => num * 2);
console.log(doubles); // [2, 4, 6, 8]
```

=== `filter`

**Description** : La méthode filter crée un nouveau tableau avec tous les éléments qui passent le test implémenté par la fonction fournie.

**Syntaxe** : array.filter(callback(element, index, array), thisArg)

**Exemple** :

```js
const numbers = [1, 2, 3, 4];
const evenNumbers = numbers.filter(num => num % 2 === 0);
console.log(evenNumbers); // [2, 4]
```

=== `reduce`

**Description** : La méthode reduce applique une fonction à un accumulateur et à chaque valeur du tableau (de gauche à droite) pour le réduire à une seule valeur.

**Syntaxe** : array.reduce(callback(accumulator, currentValue, index, array), initialValue)

**Exemple** :

```js
const numbers = [1, 2, 3, 4];
const sum = numbers.reduce((accumulator, currentValue) => accumulator + currentValue, 0);
console.log(sum); // 10
```

== Tableaux multidimensionnels

* Un tableau multidimensionnel est un tableau dont les éléments sont eux-mêmes des tableaux.
* Ils sont souvent utilisés pour stocker des matrices ou des grilles de données

=== Création 

```js
const matrix = [
  [1, 2, 3],
  [4, 5, 6],
  [7, 8, 9]
];
```

=== Accès aux éléments

```js
console.log(matrix[0][1]); // 2
```

=== Modification

```js
matrix[1][2] = 10;
console.log(matrix[1][2]); // 10
```

== Recherche 

* `indexOf` : trouve la première occurrence d'un élément dans un tableau

```js
const fruits = ['pomme', 'banane', 'cerise'];
console.log(fruits.indexOf('banane')); // 1
```

include::../../../../adoc/libs/slide-notitle.adoc[]

* `find` : renvoie la première valeur d'un tableau qui satisfait une condition

```js
const numbers = [5, 12, 8, 130, 44];
const found = numbers.find(element => element > 10);
console.log(found); // 12
```

== Tri : `sort`

`sort` trie les éléments d'un tableau localement et renvoie le tableau trié.

```js
const fruits = ['banane', 'cerise', 'pomme'];
fruits.sort();
console.log(fruits); // ['banane', 'cerise', 'pomme']
```

include::../../../../adoc/libs/slide-notitle.adoc[]

On peut personnaliser le tri en passant une fonction de comparaison.

```js
const numbers = [4, 2, 5, 1, 3];
numbers.sort((a, b) => a - b);
console.log(numbers); // [1, 2, 3, 4, 5]
```

== Démonstration

Utilisation de l'IA pour rechercher / trier un jeu de données complexe

[NOTE.speaker]
====

* Considérons un jeu de données multidimensionnel légèrement complexe à lire et manipuler pour un humain :

```js
const data = [
  [1, 2, 3],
  [4, 5, 6],
  [7, 8, 9]
];
```

* Demandons à l'IA de créer une fonction qui trie par ordre croissant. Voici un résultat possible :

```js
const data = [
  [1, 2, 3],
  [4, 5, 6],
  [7, 8, 9]
];

const sortedData = data.sort((a, b) => a[0] - b[0]);
console.log(sortedData);
```

* Demandons à l'IA de créer une fonction qui cherche tous les nombres pairs. Voici un résultat possible :

```js
const data = [
  [1, 2, 3],
  [4, 5, 6],
  [7, 8, 9]
];

const evenNumbers = data.flat().filter(num => num % 2 === 0);
console.log(evenNumbers);
```
