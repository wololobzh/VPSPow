== Introduction à l'intégration

* PocketBase expose une API REST automatique
* Accessible via des requêtes HTTP standards
* Pas besoin de bibliothèque spécifique
* Documentation auto-générée sur `/api/collections/[collection]/records`

[NOTE.speaker]
====
* PocketBase génère automatiquement une API REST pour chaque collection
* L'API suit les standards HTTP (GET, POST, PUT, DELETE)
* La documentation est accessible directement depuis l'interface d'administration
* Les endpoints sont prévisibles et suivent une structure cohérente
====

== Configuration de la connexion

* Définir l'URL de base de l'API
* Gérer les en-têtes de requête
* Structurer les appels API

[source,javascript]
----
const API_URL = 'http://localhost:8090/api/collections';
----

[NOTE.speaker]
====
* L'URL de base doit être configurée en fonction de l'environnement
* Les en-têtes doivent inclure le type de contenu (Content-Type: application/json)
* Il est recommandé de centraliser la configuration dans un fichier séparé
====

== Récupération des données

* Utilisation de `fetch` pour les requêtes HTTP
* Gestion des promesses avec `async/await`
* Traitement de la réponse JSON

[source,javascript]
----
async function getPosts() {
  const response = await fetch(`${API_URL}/posts/records`);
  const data = await response.json();
  return data.items;
}
----

[NOTE.speaker]
====
* La fonction fetch est native dans les navigateurs modernes
* async/await permet une syntaxe plus claire que les promesses chaînées
* La réponse de PocketBase inclut toujours un tableau items pour les collections
====

== Démonstration

**Création d'une liste de posts avec PocketBase**

[NOTE.speaker]
====
1. Créer un nouveau fichier Posts.svelte
2. Ajouter le code de base pour la récupération des posts :
+
[source,svelte]
----
<script>
  let posts = [];
  let loading = true;
  let error = null;

  async function loadPosts() {
    try {
      const response = await fetch('http://localhost:8090/api/collections/posts/records');
      const data = await response.json();
      posts = data.items;
    } catch (e) {
      error = e.message;
    } finally {
      loading = false;
    }
  }

  loadPosts();
</script>

{#if loading}
  <p>Chargement...</p>
{:else if error}
  <p>Erreur : {error}</p>
{:else}
  {#each posts as post}
    <article>
      <h2>{post.title}</h2>
      <p>{post.content}</p>
    </article>
  {/each}
{/if}
----

3. Expliquer les différents états (loading, error, success)
4. Montrer le résultat dans le navigateur

== Gestion des états

* État de chargement initial
* Gestion des erreurs
* Affichage conditionnel

[source,svelte]
----
{#if loading}
  <p>Chargement...</p>
{:else if error}
  <p>Erreur : {error}</p>
{/if}
----

[NOTE.speaker]
====
* L'état de chargement permet d'informer l'utilisateur
* Les erreurs doivent être capturées et affichées de manière claire
* Les blocs conditionnels permettent de gérer différents états d'affichage
====

== Affichage des données

* Utilisation de la directive `#each`
* Structuration du HTML
* Gestion des cas vides

[source,svelte]
----
{#each posts as post}
  <article>
    <h2>{post.title}</h2>
    <p>{post.content}</p>
  </article>
{:else}
  <p>Aucun post disponible</p>
{/each}
----

[NOTE.speaker]
====
* La directive #each permet d'itérer sur un tableau de données
* Le bloc else s'affiche quand le tableau est vide
* Chaque élément peut être stylisé individuellement
====
