== Introduction aux formulaires dans Svelte

=== Pourquoi utiliser `bind:value` ?

* Simplifie la gestion des données entre le DOM et l'état de l'application.
* Évite la répétition de code avec `oninput` ou `onchange`.

[NOTE.speaker]
====
Expliquer que Svelte permet de synchroniser automatiquement les données entre le composant et le DOM, ce qui réduit le code boilerplate.
====

=== Différence entre liaison unidirectionnelle et bidirectionnelle

* **Unidirectionnelle** : Les données vont du composant vers le DOM.
* **Bidirectionnelle** : Les données sont synchronisées dans les deux sens (composant ↔ DOM).

[NOTE.speaker]
====
Montrer un exemple simple de liaison unidirectionnelle (sans `bind:value`) pour comparer avec la liaison bidirectionnelle.
====

// tag::demo[]
=== Démonstration 1 : Liaison d'un champ texte

```svelte
<script>
    let name = "";
</script>

<input bind:value={name} placeholder="Entrez votre nom" />
<p>Bonjour, {name} !</p>
```

[NOTE.speaker]
====
* Montrer comment `bind:value` synchronise la variable `name` avec la valeur du champ texte.
* Expliquer que chaque modification dans le champ texte met à jour la variable `name` en temps réel.
====
// end::demo[]

== Gestion des champs numériques

=== Liaison avec `type="number"` et `type="range"`

* `type="number"` : Pour les champs numériques.
* `type="range"` : Pour les curseurs.

[NOTE.speaker]
====
Expliquer que Svelte gère automatiquement la conversion entre les chaînes de caractères et les nombres pour ces types de champs.
====

// tag::demo[]
=== Démonstration 2 : Liaison de champs numériques et curseurs

```svelte
<script>
    let a = 5;
    let b = 3;
</script>

<label>
    <input type="number" bind:value={a} min="0" max="10" />
    <input type="range" bind:value={a} min="0" max="10" />
</label>

<label>
    <input type="number" bind:value={b} min="0" max="10" />
    <input type="range" bind:value={b} min="0" max="10" />
</label>
```

[NOTE.speaker]
====
* Montrer comment les valeurs des champs numériques et des curseurs sont synchronisées.
* Expliquer que la modification d'un champ entraîne la mise à jour de l'autre.
====
// end::demo[]

== Gestion des cases à cocher

=== Utilisation de `bind:checked`

* Pour les cases à cocher (`type="checkbox"`), on utilise `bind:checked` au lieu de `bind:value`.

[NOTE.speaker]
====
Expliquer que `bind:checked` lie l'état de la case à cocher (cochée ou non) à une variable booléenne.
====

// tag::demo[]
=== Démonstration 3 : Liaison d'une case à cocher

```svelte
<script>
    let yes = false;
</script>

<label>
    <input type="checkbox" bind:checked={yes} />
    Acceptez-vous les conditions ?
</label>

<p>{yes ? "Vous avez accepté." : "Vous n'avez pas encore accepté."}</p>
```

[NOTE.speaker]
====
* Montrer comment l'état de la case à cocher met à jour la variable `yes`.
* Expliquer que la valeur de `yes` est un booléen (`true` ou `false`).
====
// end::demo[]

== Gestion des sélecteurs (dropdown)

=== Liaison avec `<select>` et `bind:value`

* Pour les sélecteurs, on utilise `bind:value` pour lier la valeur sélectionnée à une variable.

[NOTE.speaker]
====
Expliquer que la valeur sélectionnée dans le `<select>` est automatiquement synchronisée avec la variable.
====

// tag::demo[]
=== Démonstration 4 : Liaison d'un sélecteur simple

```svelte
<script>
    let selected = "option1";
</script>

<select bind:value={selected}>
    <option value="option1">Option 1</option>
    <option value="option2">Option 2</option>
    <option value="option3">Option 3</option>
</select>

<p>Vous avez sélectionné : {selected}</p>
```

[NOTE.speaker]
====
* Montrer comment la valeur sélectionnée est mise à jour dans la variable `selected`.
* Expliquer que la valeur de `selected` correspond à l'attribut `value` de l'option choisie.
====
// end::demo[]

== Gestion des groupes de boutons radio et cases à cocher

=== Utilisation de `bind:group`

* Pour les groupes de boutons radio, `bind:group` lie la valeur sélectionnée à une variable.
* Pour les cases à cocher multiples, `bind:group` lie les valeurs sélectionnées à un tableau.

[NOTE.speaker]
====
Expliquer que `bind:group` est utile pour gérer plusieurs éléments interactifs liés à une même variable.
====

// tag::demo[]
=== Démonstration 5 : Liaison d'un groupe de boutons radio

```svelte
<script>
    let scoops = 1;
</script>

<label>
    <input type="radio" name="scoops" value={1} bind:group={scoops} />
    1 scoop
</label>
<label>
    <input type="radio" name="scoops" value={2} bind:group={scoops} />
    2 scoops
</label>

<p>Vous avez choisi {scoops} scoop(s).</p>
```

[NOTE.speaker]
====
* Montrer comment la valeur de `scoops` est mise à jour en fonction du bouton radio sélectionné.
* Expliquer que `bind:group` est utilisé pour gérer des groupes d'éléments interactifs.
====
// end::demo[]

== Gestion des sélecteurs multiples

=== Liaison avec `<select multiple>`

* Pour les sélecteurs multiples, `bind:value` lie les valeurs sélectionnées à un tableau.

[NOTE.speaker]
====
Expliquer que l'utilisateur peut sélectionner plusieurs options en maintenant la touche `Ctrl` (ou `Cmd` sur Mac) enfoncée.
====

// tag::demo[]
=== Démonstration 6 : Liaison d'un sélecteur multiple

```svelte
<script>
    let flavours = [];
</script>

<select multiple bind:value={flavours}>
    <option>Vanille</option>
    <option>Chocolat</option>
    <option>Fraise</option>
</select>

<p>Vous avez choisi : {flavours.join(", ")}</p>
```

[NOTE.speaker]
====
* Montrer comment les valeurs sélectionnées sont stockées dans un tableau.
* Expliquer que chaque option sélectionnée est ajoutée au tableau `flavours`.
====
// end::demo[]

== Gestion des zones de texte (textarea)

=== Utilisation de `bind:value`

* Pour les `<textarea>`, on utilise `bind:value` pour lier le contenu à une variable.

[NOTE.speaker]
====
Expliquer que `bind:value` fonctionne de la même manière que pour les champs texte.
====

// tag::demo[]
=== Démonstration 7 : Liaison d'une zone de texte

```svelte
<script>
    let value = "";
</script>

<textarea bind:value={value} placeholder="Écrivez quelque chose..."></textarea>
<p>Vous avez écrit : {value}</p>
```

[NOTE.speaker]
====
* Montrer comment le contenu de la zone de texte est synchronisé avec la variable `value`.
* Expliquer que chaque modification dans la zone de texte met à jour la variable en temps réel.
====
