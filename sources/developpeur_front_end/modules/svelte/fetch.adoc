== Introduction à `fetch`

* c'est une fonction JavaScript pour effectuer des requêtes HTTP
* remplace `XMLHttpRequest` qui est l'ancienne méthode (on peut le croiser dans du code legacy)
* `fetch` est plus simple à utiliser et plus puissant
* `fetch` est basé sur des promesses

== Syntaxe

```js

// Exemple en .then/.catch
fetch("https://jsonplaceholder.typicode.com/posts")
  .then(response => response.json()) // Convertit la réponse en JSON
  .then(data => console.log(data))   // Affiche les données
  .catch(error => console.error("Erreur :", error));

// Exemple en async/await
async function fetchPosts() {
  try {
    const response = await fetch("https://jsonplaceholder.typicode.com/posts");
    const data = await response.json();
    console.log(data);
  } catch (error) {
    console.error("Erreur :", error);
  }
}
```

== Requêtes `GET` avec `fetch`

* Il suffit de passer l'URL de l'API en argument de `fetch`

```js
// Requête GET
fetch("https://jsonplaceholder.typicode.com/posts")
  .then(response => response.json())
  .then(data => console.log(data))
  .catch(error => console.error("Erreur :", error));
```

[NOTE.speaker]
====
**Comprendre la réponse HTTP (`Response` Object)**

* `response.ok` → Vérifie si la requête a réussi (statut 200-299).
* `response.status` → Code HTTP (ex: 200, 404, 500).
* `response.json()` → Convertit en JSON (ou `response.text()` pour du texte brut).
====

== Requêtes `POST`, `PUT` et `DELETE` avec `fetch`

* Ajouter un objet de configuration en 2e argument de `fetch`
** `method` : type de requête (GET, POST, PUT, DELETE)
** `headers` : type de contenu (JSON, XML, etc.)
** `body` : données à envoyer (JSON.stringify pour du JSON)

=== Envoyer des données avec `POST`

```js
fetch("https://jsonplaceholder.typicode.com/posts", {
  method: "POST", // Type de requête (POST ici)
  headers: { "Content-Type": "application/json" }, // Type de contenu (JSON ici)
  body: JSON.stringify({ title: "Nouveau Post", body: "Contenu du post", userId: 1 })
})
  .then(response => response.json())
  .then(data => console.log("Post ajouté :", data));
```

=== Modifier des données avec `PUT`

```js
fetch("https://jsonplaceholder.typicode.com/posts/1", {
  method: "PUT",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ title: "Post modifié", body: "Contenu mis à jour", userId: 1 })
})
  .then(response => response.json())
  .then(data => console.log("Post mis à jour :", data));
```

=== Supprimer des données avec `DELETE`

```js
fetch("https://jsonplaceholder.typicode.com/posts/1", { method: "DELETE" })
  .then(() => console.log("Post supprimé"));
```

== Gestion des erreurs

* Utiliser les blocs `try/catch` pour gérer les erreurs
* Utiliser `response.ok` pour vérifier si la requête a réussi
* Afficher un message d'erreur en cas de problème

```js
async function fetchWithErrorHandling() {
  try {
    const response = await fetch("https://jsonplaceholder.typicode.com/invalid-url");
    if (!response.ok) throw new Error(`Erreur HTTP: ${response.status}`);
    const data = await response.json();
    console.log(data);
  } catch (error) {
    console.error("Erreur attrapée :", error);
  }
}
fetchWithErrorHandling();
```


== `fetch` dans Svelte

* `fetch` est souvent utilisé dans les applications Svelte pour récupérer des données

```js
// src/App.svelte
<script>
  let posts = $state([]);

  fetch("https://jsonplaceholder.typicode.com/posts")
    .then(response => response.json())
    .then(data => posts = data)
    .catch(error => console.error("Erreur :", error));
</script>

{#each posts as post}
  <div>{post.title}</div>
{/each}
```
