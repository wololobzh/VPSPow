== Introduction aux événements DOM

=== Syntaxe de base

* Utilisation de la directive `on:` suivie du nom de l'événement
* Format: `on<eventname>={handler}`
* Version courte si le nom correspond: `{oneventname}`

[NOTE.speaker]
====
* La syntaxe est très intuitive dans Svelte
* Montrer que c'est similaire aux événements natifs du DOM
* Insister sur la simplicité de la syntaxe par rapport à d'autres frameworks
====

=== Événements courants

* `onclick` - Clic souris
* `onkeydown` - Touche pressée
* `onsubmit` - Soumission formulaire
* `onpointermove` - Mouvement pointeur
* `oninput` - Saisie dans un champ

[NOTE.speaker]
====
* Ces événements sont les plus utilisés au quotidien
* Ils correspondent aux événements natifs du DOM
* Svelte ne fait qu'ajouter une couche de simplification
====

== Gestion des événements

=== Handlers inline vs externes

* **Handlers externes** : définis dans le bloc `<script>`
* **Handlers inline** : directement dans l'attribut
* Avantages/inconvénients de chaque approche

[NOTE.speaker]
====
* Les handlers externes sont plus maintenables et réutilisables
* Les handlers inline sont pratiques pour les cas simples
* Recommander d'utiliser des handlers externes pour du code complexe
====

=== L'objet Event

* Contient toutes les informations sur l'événement
* Propriétés principales:
** `event.target` - élément source
** `event.currentTarget` - élément courant
** `event.preventDefault()` - empêche le comportement par défaut

[NOTE.speaker]
====
* L'objet event est automatiquement passé aux handlers
* Il contient de nombreuses informations utiles
* Important pour la gestion fine des événements
====

== Phases des événements

=== Phase de Bubbling

* L'événement "remonte" de l'élément cible vers ses parents
* Comportement par défaut
* Permet la délégation d'événements

[NOTE.speaker]
====
* Analogie : comme une bulle qui remonte à la surface de l'eau
* Chaque élément parent peut "attraper" l'événement
* Utile pour gérer plusieurs éléments similaires
====

=== Phase de Capture

* L'événement "descend" des parents vers l'élément cible
* Activée avec le modificateur `capture`
* Moins courante mais utile dans certains cas

[NOTE.speaker]
====
* Analogie : comme l'eau qui coule du haut vers le bas
* Permet d'intercepter les événements avant qu'ils n'atteignent leur cible
* Utile pour des cas spécifiques de contrôle
====

== Événements composants

=== Passage d'événements

* Les événements peuvent être passés comme props
* Utilisation des props pour définir les handlers
* Propagation à travers les composants

[NOTE.speaker]
====
* Les événements sont des props comme les autres
* Permet de créer des composants réutilisables
* Facilite la communication entre composants
====

=== Event forwarding

* Transmission des événements vers le parent
* Utilisation du spread operator `{...$$props}`
* Simplification du code

[NOTE.speaker]
====
* Le forwarding permet de remonter les événements
* Très utile pour les composants wrapper
* Évite de redéfinir tous les handlers
====

== Exercice

Voici un compteur simple. Modifiez-le pour :

[cols="1,1"]
|===
a|
1. Ajouter un bouton de réinitialisation (reset)
2. Changer la couleur du texte en rouge si le compteur est négatif
3. Désactiver le bouton "-" quand le compteur est à 0
4. Bonus : Ajouter un événement au clavier pour incrémenter avec "+" et décrémenter avec "-"
a|
Code de base :
```svelte
<script>
  let count = $state(0);
</script>

<div class="counter">
  <button onclick={() => count--}>-</button>
  <span>{count}</span>
  <button onclick={() => count++}>+</button>
</div>

<style>
  .counter {
    display: flex;
    gap: 1rem;
    align-items: center;
  }
  
  span {
    min-width: 2rem;
    text-align: center;
  }
</style>
```
|===

[NOTE.speaker]
====
Solution attendue :
```svelte
<script>
  let count = $state(0);
  
  function handleKeydown(event) {
    if (event.key === '+') count++;
    if (event.key === '-' && count > 0) count--;
  }
</script>

<svelte:window onkeydown={handleKeydown}/>

<div class="counter">
  <button 
    onclick={() => count--}
    disabled={count === 0}
  >-</button>
  
  <span style:color={count < 0 ? 'red' : 'inherit'}>
    {count}
  </span>
  
  <button onclick={() => count++}>+</button>
  
  <button onclick={() => count = 0}>Reset</button>
</div>

<style>
  .counter {
    display: flex;
    gap: 1rem;
    align-items: center;
  }
  
  span {
    min-width: 2rem;
    text-align: center;
  }
  
  button:disabled {
    opacity: 0.5;
    cursor: not-allowed;
  }
</style>
```

Points à vérifier :
* Ajout correct du bouton reset
* Gestion de la couleur conditionnelle
* Désactivation du bouton avec disabled
* Gestion des événements clavier
====
