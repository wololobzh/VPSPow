== Qu'est-ce que le Titre Professionnel DWWM ?

Le Titre Professionnel Développeur Web et Web Mobile (DWWM) est une certification professionnelle de niveau 5 (équivalent Bac+2). 

Il valide les compétences nécessaires pour :

- Concevoir, développer et maintenir des sites web et des applications web.
- Collaborer avec des professionnels du numérique pour des projets complets.

[NOTE.speaker]
====
Le titre DWWM est reconnu par l’État et correspond aux besoins des entreprises en matière de développement web. Il ouvre des perspectives variées, que ce soit en tant que salarié dans une agence web ou comme freelance.
====

== Les principaux métiers accessibles après le titre DWWM

Avec ce titre, vous pouvez exercer les métiers suivants :

- Développeur web.
- Développeur front-end.
- Développeur back-end.
- Intégrateur web.
- Webmaster technique.

[NOTE.speaker]
====
Ces métiers permettent de travailler sur des projets variés, allant des sites institutionnels aux plateformes complexes, en passant par les applications mobiles et les boutiques en ligne.
====

== Les blocs de compétences du Titre DWWM

Le titre DWWM est composé de deux **Certificats de Compétences Professionnelles (CCP)**. Chaque CCP regroupe plusieurs compétences spécifiques.

=== CCP1 : Développer la partie front-end d’une application web ou web mobile

Ce bloc se concentre sur l’intégration et le développement côté client :

- Réaliser l’intégration de maquettes en respectant les standards HTML et CSS.
- Ajouter de l’interactivité aux pages web à l’aide de JavaScript.
- Créer des interfaces ergonomiques et accessibles.
- Dynamiser les interfaces utilisateur avec des frameworks ou librairies (ex : React, Angular).

=== CCP2 : Développer la partie back-end d’une application web ou web mobile

Ce bloc porte sur le développement côté serveur :

- Créer des bases de données relationnelles ou non-relationnelles.
- Développer des API pour permettre les échanges entre le front-end et le back-end.
- Implémenter des systèmes d'authentification et de sécurité.
- Déployer des applications web sur un serveur.

[NOTE.speaker]
====
Ces deux blocs de compétences couvrent l’ensemble des aspects nécessaires pour construire des applications web modernes, de la conception à la mise en production.
====

== Attendus pour valider le Titre DWWM

Pour obtenir le Titre DWWM, il est attendu des candidats qu’ils soient capables de :

- Analyser les besoins d’un client pour définir les fonctionnalités à développer.
- Créer des interfaces utilisateur fonctionnelles, accessibles et esthétiques.
- Développer des fonctionnalités serveur robustes et sécurisées.
- Documenter le code et les projets pour assurer la maintenabilité.
- Présenter un projet web complet devant un jury.

[NOTE.speaker]
====
L’évaluation finale repose sur un projet fil rouge. Vous devrez démontrer vos compétences en répondant à une problématique réelle, en intégrant les aspects front-end et back-end, tout en suivant les bonnes pratiques du développement.
====

== Organisation de la formation DWWM

La formation pour préparer ce titre dure généralement entre 6 et 12 mois, avec une alternance de cours théoriques, d’ateliers pratiques et de projets.

Le parcours inclut :

- Des modules techniques (HTML, CSS, JavaScript, bases de données, frameworks).
- Des projets réels pour appliquer les compétences.
- Une préparation intensive pour l’examen final.

[NOTE.speaker]
====
La formation est conçue pour favoriser l’apprentissage par la pratique. En plus des cours, vous aurez l’occasion de travailler sur des projets proches des situations réelles, afin d’être immédiatement opérationnel après l’obtention du titre.
====

== Opportunités après le Titre DWWM

Ce titre offre des opportunités professionnelles variées :

- Intégrer une entreprise dans des secteurs comme l’e-commerce, la communication ou la tech.
- Travailler en freelance pour des clients divers.
- Continuer vos études pour approfondir vos compétences (ex : CDA ou DevOps).

[NOTE.speaker]
====
Le secteur du numérique est en constante évolution, et les développeurs web sont parmi les profils les plus recherchés sur le marché du travail. Le titre DWWM est un excellent tremplin pour votre carrière.
====
