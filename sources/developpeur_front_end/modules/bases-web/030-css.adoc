== Introduction

* CSS signifie "Cascading Style Sheets".
* Permet de contrôler l'apparence des pages HTML
** couleurs
** polices
** mise en page
* Est appliqué via des fichiers `.css` ou dans des balises `<style>`.
* Sépare le contenu de la forme.

[NOTE.speaker]
====
Le CSS (Cascading Style Sheets) est un langage utilisé pour styliser et mettre en forme le contenu HTML.

Insistez sur la séparation du contenu (HTML) et du style (CSS). Montrez rapidement un fichier HTML simple et un fichier CSS associé.
====

== Inclure du CSS

- **Interne** : via une balise `<style>` dans le `<head>`.
- **Externe** : via un fichier `.css` lié avec `<link>`.
- **Inline** : directement dans une balise HTML via l’attribut `style`.

=== Externe (recommandé)

```html
<!DOCTYPE html>
<html lang="fr">
<head>
  <title>Exemple CSS</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <h1>Titre</h1>
</body>
</html>
```

[NOTE.speaker]
====
L'utilisation d'une feuille externe est recommandé pour des raisons de modularité et de lisibilité.
====

=== Interne (alternative)

```html
<!DOCTYPE html>
<html lang="fr">
<head>
  <title>Exemple CSS</title>
  <style>
    h1 {
      color: blue;
    }
  </style>
</head>
<body>
  <h1>Titre</h1>
</body>
</html>
```

[NOTE.speaker]
====
Cette façon de faire est moins recommandée car elle mélange le contenu et la forme. Elle ne permet pas non plus de réutiliser les styles entre les pages.
====

=== Inline (à éviter)

```html
<h1 style="color=red">Titre</h1>
```

[NOTE.speaker]
==== 
Cette méthode est à éviter car elle mélange le contenu et la forme. Elle rend le code HTML difficile à lire et à maintenir.
====

Initialisation d'une page pour la styliser.

[NOTE.speaker]
====
. Créer une page HTML simple : `index.html`

```html
<!DOCTYPE html>
<html lang="fr">
<head>
  <meta charset="UTF-8">
  <title>Ma première page</title>
</head>
<body>
  <h1>Titre</h1>
  <p>Un paragraphe</p>
  <img src="https://placehold.co/600x400" alt="placeholder">
</body>

```

[start=2]

```css
h1 {
  color: #f0f;
}
```

[start=4]

. Lier le fichier CSS à la page HTML avec une balise `<link>` dans le `<head>`

```html
<link rel="stylesheet" href="style.css">
```

[start=6]
. Rafraîchir la page pour constater le changement de couleur du titre

== Anatomie d'une règle CSS

```css
selecteur {
  /* Commentaire */
  property1: value;
  property2: value;
}
```

[NOTE.speaker]
====
* Sélecteurs : C'est le nom de l'élément HTML situé au début de l'ensemble de règles. Il permet de sélectionner les éléments sur lesquels appliquer le style souhaité (en l'occurence, les éléments p). Pour mettre en forme un élément différent, il suffit de changer le sélecteur.
* Déclaration : C'est une règle (pair clé valeur) qui détermine les propriétés de l'élément que l'on veut mettre en forme.
* Propriétés : Les différentes façons dont on peut mettre en forme un élément HTML (dans ce cas, color est une propriété des éléments p). En CSS, vous choisissez les différentes propriétés que vous voulez utiliser dans une règle CSS.
* Valeur de la propriété : À droite de la propriété, après les deux points, on a la valeur de la propriété. Celle-ci permet de choisir une mise en forme parmi d'autres pour une propriété donnée (par exemple, il y a d'autres couleurs que red pour la propriété color).
====

=== Sélecteurs CSS de base

Les sélecteurs permettent de cibler les éléments à styliser :

* **Type** : cible un élément HTML (`h1`, `p`).
* **Classe** : cible une classe spécifique (`.ma-classe`).
* **ID** : cible un élément avec un ID spécifique (`#mon-id`).

.Exemples de sélecteurs CSS
```css
h1 {
  color: red;
}
.ma-classe {
  background-color: yellow;
}
#mon-id {
  font-size: 20px;
}
```

[NOTE.speaker]
==== 
Les IDs sont uniques tandis que les classes peuvent être réutilisées. Il faut préférer les classes pour une meilleure maintenabilité et des styles génériques.
====

* link:https://developer.mozilla.org/fr/search?q=font-weight[font-weight,window=_blank]

[NOTE.speaker]
====
*Font-family* : Définit la police de caractères utilisée pour le texte.

*text-decoration* : Définit la décoration du texte.

*text-align* : Définit l'alignement du texte.

*text-transform* : Définit la casse du texte.

*color* :  Définit la couleur du texte.

*background-color* : Définit la couleur de fond d'un élément.

*font-size* : Définit la taille de la police de caractères.
====

Bonus : Intégrer une image :

```html
<!DOCTYPE html>
<html lang="fr">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Exemple d'intégration d'image</title>
</head>
<body>
    <h1>Bienvenue sur ma page</h1>
    <p>Voici une image intégrée en HTML :</p>

    <img src="chemin/vers/image.jpg" alt="Description de l'image" width="400" height="300">

    <p>L'attribut <code>alt</code> fournit une description alternative pour les lecteurs d'écran et en cas d'erreur de chargement.</p>
</body>
</html>
```

*Explications des attributs :*

1. src : Définit le chemin de l'image (peut être relatif ou absolu).
+
Exemple : src="images/photo.jpg" ou src="https://example.com/image.jpg".

2. alt : Fournit une description alternative de l'image, utile pour l'accessibilité et le SEO.

3. width et height (optionnels) : Permettent de définir les dimensions de l'image en pixels.

4. Le contenu entre les balises <p> et <h1> est utilisé pour accompagner et expliquer l'image.

Avec ce modèle, il suffit de remplacer les valeurs pour personnaliser selon vos besoins.
