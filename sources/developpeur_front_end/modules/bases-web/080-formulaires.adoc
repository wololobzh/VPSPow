== Introduction

Un formulaire permet à un internaute de saisir et soumettre des informations via une page web.

== Les bases des formulaires

=== La balise `form`

La balise `form` est obligatoire pour englober tout le contenu d’un formulaire. Elle peut inclure des attributs comme `action` et `method` (ces attributs seront abordés plus tard).

Exemple :
```html
<form>
  <!-- Contenu du formulaire -->
</form>
```

[NOTE.speaker]
====
La balise `form` représente l’équivalent d’une enveloppe pour collecter et envoyer les données. On peut imaginer un courrier où l'enveloppe est essentielle pour contenir les informations.
====

=== La balise `input`

La balise `input` permet à l’utilisateur de saisir des informations. Elle peut être utilisée pour des champs texte, des cases à cocher, ou des boutons radio, entre autres.

Exemple :
```html
<label for="email">Email</label>
<input type="email" id="email" name="email">
```

Types courants :

* `text` : Champ texte classique.
* `checkbox` : Case à cocher.
* `radio` : Bouton radio (à combiner avec `name` pour grouper les choix).
* `email` : Champ pour saisir une adresse email (avec validation automatique).

== Créer un formulaire simple

Intégrons ces concepts dans un formulaire simple.

```html
<form>
  <fieldset>
    <legend>Contactez-nous</legend>

    <label for="name">Nom :</label>
    <input type="text" id="name" name="name">

    <label for="email">Email :</label>
    <input type="email" id="email" name="email">

    <label>
      <input type="checkbox" name="newsletter"> S'inscrire à la newsletter
    </label>

    <button type="submit">Envoyer</button>
  </fieldset>
</form>
```

[NOTE.speaker]
====
Un formulaire peut être organisé avec des balises comme `fieldset` (pour regrouper des champs liés) et `legend` (pour ajouter un titre).
====

=== Types avancés et stylisation

Ajoutons d'autres champs pour explorer davantage.

```html
<form>
  <fieldset>
    <legend>Préférences</legend>

    <label for="gender">Genre :</label>
    <input type="radio" id="male" name="gender" value="male"> Homme
    <input type="radio" id="female" name="gender" value="female"> Femme

    <label for="country">Pays :</label>
    <select id="country" name="country">
      <option value="france">France</option>
      <option value="canada">Canada</option>
    </select>

    <label for="comments">Commentaires :</label>
    <textarea id="comments" name="comments"></textarea>

    <button type="submit">Valider</button>
  </fieldset>
</form>
```

[NOTE.speaker]
====
Ce formulaire inclut des boutons radio, un menu déroulant (`select`) et une zone de texte (`textarea`).
====

== Différence entre `button`, `input[type=submit]` et `a`

* `button` : Utilisé pour des boutons interactifs pouvant contenir du HTML.
* `input[type=submit]` : Soumet directement le formulaire.
* `a` : Utilisé pour créer des liens, pas pour des actions sur un formulaire.

== Stylisation avec CSS

Les formulaires peuvent être stylisés pour améliorer leur apparence.

```css
/* Exemple de style */
input[type="text"], textarea {
  border: 1px solid #ccc;
  padding: 8px;
  width: 100%;
}

button {
  background-color: #007BFF;
  color: white;
  border: none;
  padding: 10px 20px;
  cursor: pointer;
}
```

== Découverte du pseudo-élément `::placeholder`

Le pseudo-élément `::placeholder` permet de styliser les textes d’indication dans les champs.

```css
input::placeholder {
  color: #999;
  font-style: italic;
}
```
