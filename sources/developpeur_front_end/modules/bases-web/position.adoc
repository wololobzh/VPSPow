== Introduction aux positions

La propriété `position` permet de contrôler précisément le placement des éléments :

.Cas d'usage courants :
* Barre de navigation fixe
* Badges et étiquettes sur des produits
* Boutons flottants
* Éléments superposés

[NOTE.speaker]
--
Le positionnement CSS est crucial pour créer des interfaces.
Par défaut, les éléments suivent le flux normal du document.
La propriété position nous permet de modifier ce comportement.
Chaque type de position a ses propres caractéristiques et cas d'usage.
--

== Les différentes positions

=== Position Static

* Valeur par défaut
* Suit le flux normal du document
* Ignore les propriétés `top`, `right`, `bottom`, `left`
* Ignore `z-index`

[NOTE.speaker]
--
Static est le comportement par défaut de tous les éléments.
Les éléments block s'empilent verticalement.
Les éléments inline se placent côte à côte.
Aucun positionnement spécial n'est possible avec static.
--

=== Position Relative

* L'élément garde sa place dans le flux
* Se décale par rapport à sa position initiale
* Devient un point de référence pour les éléments `absolute`
* Accepte `top`, `right`, `bottom`, `left` et `z-index`

[NOTE.speaker]
--
Relative est souvent utilisé pour de petits ajustements de position.
L'espace original de l'élément est préservé.
Utile comme conteneur pour les éléments en position absolute.
Le décalage se fait par rapport à la position d'origine.
--

Position Relative

[source,html]
----
<div class="card">
  <button class="card__button">Ajouter au panier</button>
</div>
----

[source,css]
----
.card {
  border: 1px solid #ddd;
  padding: 20px;
}

.card__button {
  position: relative;
  top: 10px;
  right: -20px;
}
----

[NOTE.speaker]
--
1. Créer une carte simple avec un bouton
2. Ajouter position: relative au bouton
3. Utiliser top pour décaler vers le bas
4. Utiliser right avec une valeur négative pour décaler vers la droite
5. Montrer que l'espace original du bouton est préservé
--
// end::demo[]

=== Position Fixed

* Sort du flux normal
* Se positionne par rapport à la fenêtre
* Reste fixe pendant le défilement
* Taille basée sur le contenu
* Accepte `top`, `right`, `bottom`, `left` et `z-index`

[NOTE.speaker]
--
Fixed est parfait pour les éléments qui doivent rester visibles lors du défilement.
L'élément ne prend plus de place dans le flux.
Souvent utilisé pour les headers fixes et les boutons flottants.
La taille doit souvent être explicitement définie.
--

Position Fixed

[source,html]
----
<header class="header">
  <nav class="nav">Menu</nav>
</header>
<main class="content">
  Contenu de la page...
</main>
----

[source,css]
----
.header {
  position: fixed;
  top: 0;
  left: 0;
  right: 0;
  background: red;
  color: white;
  padding: 1rem;
}

.content {
  margin-top: 60px;
}
----

[NOTE.speaker]
--
1. Créer un header simple avec une navigation
2. Appliquer position: fixed au header
3. Utiliser top, left et right pour le positionner
4. Ajouter une marge au contenu pour compenser l'espace
5. Montrer le comportement au scroll
--

=== Position Absolute

* Sort du flux normal
* Se positionne par rapport au parent positionné le plus proche
* Taille basée sur le contenu
* Accepte `top`, `right`, `bottom`, `left` et `z-index`

[NOTE.speaker]
--
Absolute est idéal pour positionner des éléments par rapport à leurs conteneurs.
Le parent doit avoir une position non-static.
Souvent utilisé pour les badges, tooltips et menus déroulants.
La référence est le premier ancêtre positionné.
--

--

=== Position Sticky

* Reste dans le flux jusqu'à atteindre un seuil
* Se comporte ensuite comme fixed
* Nécessite un "sticky container"
* Accepte `top`, `right`, `bottom`, `left` et `z-index`

[NOTE.speaker]
--
Sticky est un hybride entre relative et fixed.
L'élément reste normal jusqu'à ce que le seuil soit atteint.
Utile pour les en-têtes de section et les menus.
Le conteneur définit les limites du comportement sticky.
--

== Propriétés de positionnement

=== Les offsets (top, right, bottom, left)

* Définissent la distance depuis le point de référence
* Acceptent toutes les unités CSS (px, %, rem, etc.)
* Si `right` est défini, `left` est ignoré
* Si `bottom` est défini, `top` est ignoré

[NOTE.speaker]
--
Les offsets déterminent où l'élément sera placé.
Le point de référence dépend du type de position.
Les valeurs peuvent être positives ou négatives.
Il est préférable de n'utiliser que deux offsets à la fois.
--

=== Z-index

* Contrôle la superposition des éléments
* Valeur numérique sans unité
* Plus la valeur est grande, plus l'élément est au premier plan
* Ne fonctionne que sur les éléments positionnés

[NOTE.speaker]
--
Z-index gère l'ordre d'empilement des éléments.
La valeur par défaut est auto (0).
Les éléments avec un z-index plus élevé passent devant.
Crée un nouveau contexte d'empilement.
--

Z-index

[source,html]
----
<div class="modal-overlay"></div>
<div class="modal">
  <h2>Modal</h2>
  <p>Contenu de la modal</p>
</div>
----

[source,css]
----
.modal-overlay {
  position: fixed;
  top: 0;
  left: 0;
  right: 0;
  bottom: 0;
  background: rgba(0,0,0,0.5);
  z-index: 100;
}

.modal {
  position: fixed;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
  background: white;
  padding: 20px;
  z-index: 101;
}
----

[NOTE.speaker]
--
1. Créer une modal avec un overlay
2. Positionner l'overlay en fixed pour couvrir tout l'écran
3. Positionner la modal en fixed au centre
4. Utiliser z-index pour mettre la modal au-dessus de l'overlay
5. Montrer comment les éléments se superposent
--

== Positionnement moderne avec CSS Grid

* Alternative aux positions pour certains cas d'usage
* Système de mise en page en 2 dimensions
* Plus flexible et maintenable
* Remplace avantageusement certains usages de position absolute

.Cas d'usage à privilégier avec Grid :
* Mise en page complète
* Alignements complexes
* Superpositions d'éléments
* Responsive design

[NOTE.speaker]
--
* CSS Grid offre une approche plus structurée que le positionnement classique
* Particulièrement adapté pour les interfaces complexes
* Permet de gérer facilement les espacements et alignements
* Réduit le besoin d'utiliser des positions absolute/relative
* Sera abordé en détail dans un prochain module
--
