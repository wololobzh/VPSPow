=== Terminal : Comprendre l'interface

Le terminal est une **interface utilisateur textuelle**, uniquement manipulable au clavier. 

Exemple rapide :
```bash
pwd
```

⚠️ Important : Le séparateur de fichiers est `/` et non `\`.

[NOTE.speaker]
====
* Définissez ce qu'est une **IHM (Interface Homme-Machine)**.
* Expliquez que le terminal ne fonctionne qu’avec des commandes textuelles.
* **pwd** signifie _Print Working Directory_, qui affiche le répertoire actuel.
====

=== Terminal : Le contexte des commandes

Les commandes du terminal dépendent toujours du **contexte** :

* 📂 **Dans quel dossier êtes-vous ?** (`pwd`)
* 👤 **Avec quel utilisateur exécutez-vous les commandes ?**

🔎 Exemple avec les commandes :
```bash
pwd
ls
```

📖 **Analogie** : 

* En France, on parle **français**.
* En Angleterre, on parle **anglais**.
* La langue dépend du **contexte** (le pays).
  
Pareil pour les commandes terminal :

* `ls` dans `/var/www` affichera les fichiers de ce dossier.
* `ls` dans `/var/www/html` affichera un résultat différent.

[NOTE.speaker]
====
Le contexte est crucial dans l'exécution des commandes terminal. Une même commande peut produire différents résultats selon le répertoire courant.
====

=== Terminal : Structure des commandes

Exemple de commande :

```bash
cd /var/www/html
```

Décomposition :

1. **`cd`** : la commande
2. **` `** : espace pour séparer les arguments
3. **`/var/www/html`** : l'argument, ici le chemin du répertoire cible

💡 **Astuce** : Utilisez la touche **Tabulation** pour compléter automatiquement les noms de dossiers ou fichiers.

[NOTE.speaker]
====
* **`cd`** signifie _change directory_ (changer de répertoire).
* Une commande peut avoir plusieurs arguments.
====

=== Dossier de dév

Créer un répertoire de développement sur le Bureau :

```bash
mkdir html
```

Ensuite, créez un sous-dossier par saison :

```bash
mkdir S01
mkdir S02
```

[NOTE.speaker]
====
Utilisez `pwd` pour vérifier dans quel dossier vous vous trouvez.
====
