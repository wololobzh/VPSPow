== KeyCloak - Single Sign-On

* Système d'authentification centralisé (SSO)
* Un compte unique pour tous les outils O'clock
* Similaire à la connexion Google ou Facebook
* Spécifique à l'écosystème O'clock

[NOTE.speaker]
====
KeyCloak est notre système de connexion unique.
Il permet d'accéder à tous les outils O'clock avec un seul compte.
C'est plus sécurisé et plus pratique qu'avoir plusieurs comptes.
====

== Configuration du compte

* Email de bienvenue avec les identifiants
* Format identifiant : `prenom.nom@oclock.school`
* Mot de passe initial : `azertyuiop1234`
* Changement obligatoire à la première connexion

[NOTE.speaker]
====
Les identifiants sont envoyés par email le matin du premier jour.
Le changement de mot de passe est une mesure de sécurité obligatoire.
Le format de l'email est standardisé pour tous les apprenants.
====

== Messagerie O'clock

* Adresse email : `prenom.nom@oclock.school`
* Accès : https://mail.oclock.school/
* Authentification via KeyCloak
* Conservation des emails limitée à 90 jours

[NOTE.speaker]
====
La messagerie est accessible via le navigateur web.
La limite de 90 jours pour la conservation des emails est importante à noter.
Il faut sauvegarder les emails importants avant cette échéance.
====
