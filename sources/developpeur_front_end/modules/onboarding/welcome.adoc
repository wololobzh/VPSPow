== DWWM - Deux CCP à valider

CCP = Certificat de Compétence Professionnelle

== CCP Front

CCP - Développer la partie front-end d’une application web ou web mobile sécurisée

* Installer et configurer son environnement de travail en fonction du projet web ou web mobile
* Maquetter des interfaces utilisateur web ou web mobile
* Réaliser des interfaces utilisateur statiques web ou web mobile
* Développer la partie dynamique des interfaces utilisateur web ou web mobile

== CCP Back

CCP - Développer la partie back-end d’une application web ou web mobile sécurisée

* Mettre en place une base de données relationnelle
* Développer des composants d’accès aux données SQL et NoSQL
* Développer des composants métier côté serveur
* Documenter le déploiement d’une application dynamique web ou web mobile

On en parle un peu plus tard !
