// tag::intro[]
La formation "Développeur Front End" vise à développer les compétences nécessaires pour obtenir le CCP "Développer la partie front-end d’une application web ou web mobile sécurisée", sous-esemble du titre professionnel de niveau 5 "Développeur web et web mobile".
// end::intro[]

== Objectifs

// tag::objectifs[]
.Compétences pro
. Installer et configurer son environnement de travail en fonction du projet web ou web mobile
. Maquetter des interfaces utilisateur web ou web mobile
. Réaliser des interfaces utilisateur statiques web ou web mobile
. Développer la partie dynamique des interfaces utilisateur web ou web mobile
// end::objectifs[]
