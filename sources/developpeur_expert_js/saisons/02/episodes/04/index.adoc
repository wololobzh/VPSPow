// tag::intro[]
Dernière étapes Ops pour un CDA, préparer la mise en production de l'application. Les apprenants découvriront les grandes lignes de la mise en production d'une application complète, sans l'appliquer. Ils fabriqueront les images Docker et simuleront la mise en production avec docker compose.
// end::intro[]

== Objectifs pédagogiques

// tag::objectifs[]
- **Comprendre** les concepts de mise en production (Ops)
- **Créer** des images Docker pour le front et le back
- **Appliquer** les commandes Docker hub
- **Simuler** la mise en production avec Docker Compose
// end::objectifs[]

== Prérequis formateur

// tag::prerequis[]
* Bonnes connaissances de Docker et Docker Compose
// end::prerequis[]
