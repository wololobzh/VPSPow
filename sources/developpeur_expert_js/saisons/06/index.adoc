// tag::intro[]
Les apprenants se plongent dans les frameworks modernes de JavaScript, avec un accent particulier sur des outils comme React, Angular, ou Vue.js pour le front-end, ainsi que Node.js et NestJS pour le back-end. Cette saison fournit les compétences essentielles pour le développement d'applications robustes et évolutives.
// end::intro[]

== Objectifs pédagogiques

// tag::objectifs[]
* Comprendre les principes de base des frameworks front-end et back-end modernes
* Développer des applications front-end en utilisant React, Angular ou Vue.js
* Créer des APIs et services back-end avec Node.js et NestJS
* Concevoir des applications modulaires, maintenables et évolutives
// end::objectifs[]

== Notions

// tag::notions[]
* Introduction aux frameworks front-end et back-end
* React : composants, état et props
* Angular : modules, services et dépendances
* Vue.js : réactivité et composition
* Node.js : serveur et APIs REST
* NestJS : modules, services et middleware
* Structure d’une application modulaire
* Routage et gestion des formulaires
* Authentification et autorisation avec frameworks
* Optimisation de la performance
// end::notions[]



== Prérequis formateur

// tag::prerequis[]
* Expertise en frameworks front-end (React, Angular, Vue.js)
* Compétences en Node.js et NestJS
* Connaissance des architectures d’applications modulaires
* Maîtrise des pratiques d'optimisation et de performance
// end::prerequis[]

== Résumé

// tag::resume[]
Cette saison permet aux apprenants de se lancer sereinement dans leur formation. On les aide à installer tous les outils, on leur présente quelques notions d'introduction, on les prépare à savoir cloner les challenges et lancer des DevContainer.
// end::resume[]
