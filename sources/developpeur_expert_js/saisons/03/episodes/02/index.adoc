// tag::intro[]
Cette journée est la journée de lancement du projet DevOps. Les apprenants vont mettre en œuvre des pipelines d’intégration continue, optimisent les flux de travail, et assurent le déploiement efficace d’une application.
// end::intro[]

== Objectifs pédagogiques

// tag::objectifs[]
- **Appliquer** les concepts DevOps sur un projet concret
- *Gérer* un workflow de développement en environnement collaboratif
- **Concevoir** une infrastructure DevOps répondant aux besoins d’un projet spécifique
- **Déployer et maintenir** une application en production avec un suivi d’intégrité
// end::objectifs[]

== Prérequis formateur

// tag::prerequis[]
* Bonnes connaissances de Docker et Docker Compose
// end::prerequis[]
