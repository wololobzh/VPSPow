// tag::intro[]
Les connaissances acquises dans la saison précédente sont appliquées dans un projet DevOps concret. Les apprenants mettent en œuvre des pipelines d’intégration continue, optimisent les flux de travail, et assurent le déploiement efficace d’une application.
// end::intro[]

== Objectifs pédagogiques

// tag::objectifs[]
* Appliquer les concepts DevOps sur un projet concret
* Gérer un workflow de développement en environnement collaboratif
* Concevoir une infrastructure DevOps répondant aux besoins d’un projet spécifique
* Déployer et maintenir une application en production avec un suivi d’intégrité
// end::objectifs[]

== Notions

// tag::notions[]
* Planification de projet DevOps
* Mise en place de pipelines CI/CD
* Gestion des environnements de développement
* Déploiement en production
* Gestion des logs
* Surveillance des performances
* Résolution de problèmes en environnement DevOps
// end::notions[]

== Prérequis formateur

// tag::prerequis[]
* Compétences en gestion de projet DevOps
* Expérience en mise en place de pipelines CI/CD
* Expertise en déploiement et surveillance des applications
* Connaissances en résolution de problèmes DevOps
// end::prerequis[]

== Résumé

// tag::resume[]
Cette saison permet aux apprenants de se lancer sereinement dans leur formation. On les aide à installer tous les outils, on leur présente quelques notions d'introduction, on les prépare à savoir cloner les challenges et lancer des DevContainer.
// end::resume[]
