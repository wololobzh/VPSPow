// tag::intro[]
Pour conclure la formation, les apprenants travaillent sur un projet final intégrant l'ensemble des compétences acquises. Ils développent une application complète, depuis l'analyse jusqu'au déploiement, en passant par la conception sécurisée et le développement avec un framework.
// end::intro[]

== Objectifs pédagogiques

// tag::objectifs[]
* Conduire un projet de développement de bout en bout
* Appliquer l'ensemble des compétences acquises pour créer une application complète
* Gérer un projet en respectant les délais, les contraintes de qualité et les attentes du client
* Présenter et justifier les choix techniques et fonctionnels de l'application
// end::objectifs[]

== Notions

// tag::notions[]
* Conception de projet
* Développement itératif et incrémental
* Gestion des fonctionnalités et priorités
* Documentation technique et fonctionnelle
* Testing et validation
* Optimisation de la performance
* Déploiement et monitoring
* Retour d'expérience et amélioration
// end::notions[]

== Prérequis formateur

// tag::prerequis[]
* Expérience en gestion de projet de développement
* Compétences en planification et organisation
* Expertise en documentation technique
* Connaissance en testing, déploiement et monitoring
// end::prerequis[]

== Résumé

// tag::resume[]
Cette saison permet aux apprenants de se lancer sereinement dans leur formation. On les aide à installer tous les outils, on leur présente quelques notions d'introduction, on les prépare à savoir cloner les challenges et lancer des DevContainer.
// end::resume[]
