:title: Comprendre et prévenir les attaques XSS (Stored & Reflected)
:number: 02 
include::../../../../../../adoc/libs/header-episode.adoc[]

// tag::intro[]
Cet épisode permet de comprendre les attaques XSS de types "stored" et "reflected", d'explorer leurs mécanismes d'injection, et d'apprendre à les détecter et les prévenir efficacement dans une application web. Les apprenants découvriront les impacts potentiels de ces failles de sécurité, les techniques d'assainissement des données et les bonnes pratiques pour protéger leurs applications.
// end::intro[]

== Objectifs pédagogiques

// tag::objectifs[]
* Comprendre les principes des attaques XSS de types "stored" et "reflected"
* Identifier les vecteurs d'attaque et les cibles vulnérables dans une application web
* Explorer les méthodes de prévention contre les failles XSS (filtrage, échappement, Content Security Policy)
* Apprendre à tester et détecter les vulnérabilités XSS dans une application
* Mettre en œuvre les meilleures pratiques de sécurité dans le traitement des données utilisateurs
// end::objectifs[]

== Prérequis formateur

// tag::prerequis[]
* Connaissance approfondie des types d’attaques XSS (reflected et stored)
* Maîtrise des techniques d'assainissement et d’échappement des données dans le contexte web
* Expérience dans l’implémentation de politiques de sécurité web (CSP, validation côté serveur)
* Connaissance de base des outils de détection de vulnérabilités (e.g., scanners de sécurité, extensions de navigateur)
* Compétences en pédagogie et en sécurité des applications web
// end::prerequis[]
