:title: Comprendre et prévenir les injections SQL (SQLi)
:number: 04 
include::../../../../../../adoc/libs/header-episode.adoc[]

// tag::intro[]
Cet épisode permet de comprendre les attaques par injection SQL (SQLi), de découvrir leurs mécanismes et les impacts potentiels, ainsi que d’apprendre à les détecter et à les prévenir. Les apprenants verront comment ces failles peuvent compromettre la sécurité des bases de données et quelles pratiques mettre en œuvre pour protéger les applications web contre ce type d’attaque.
// end::intro[]

== Objectifs pédagogiques

// tag::objectifs[]
* Comprendre les bases des attaques par injection SQL et leurs conséquences
* Identifier les différents types d’injections SQL (classique, blind, etc.)
* Apprendre à détecter et corriger les vulnérabilités SQLi dans une application
* Explorer les techniques de prévention des SQLi (requêtes préparées, ORM, validation d’entrée)
* Mettre en place des tests de sécurité pour vérifier la robustesse des applications face aux attaques SQLi
// end::objectifs[]

== Prérequis formateur

// tag::prerequis[]
* Maîtrise des bases de données relationnelles et du langage SQL
* Connaissance des techniques d’injection SQL et de leurs vecteurs d’attaque
* Expérience pratique dans la sécurisation d’applications contre les injections SQL
* Compétences dans l’utilisation des ORM et des requêtes préparées
* Compétences pédagogiques et capacité à expliquer les concepts de sécurité applicative
// end::prerequis[]
