// tag::intro[]
Cet épisode permet aux apprenants de découvrir les bases de la cybersécurité, en mettant un accent particulier sur les failles XSS (Cross-Site Scripting). Ils apprendront à identifier et comprendre les différents types de failles XSS, leurs impacts potentiels et les méthodes pour les prévenir.
// end::intro[]

== Objectifs pédagogiques

// tag::objectifs[]
* Comprendre les concepts fondamentaux de la cybersécurité
* Identifier et expliquer les différentes formes de failles XSS
* Connaître les risques associés aux failles XSS et leurs impacts
* Savoir détecter des failles XSS dans des applications web
* Appliquer les bonnes pratiques pour se protéger des failles XSS
* Développer une approche proactive en matière de sécurité
// end::objectifs[]

== Prérequis formateur

// tag::prerequis[]
* Connaissances de base en développement web (HTML, JavaScript)
* Compréhension des requêtes HTTP et des interactions client-serveur
* Connaissance des concepts de sécurité en développement web
* Compétence dans l’analyse et la sécurisation des applications
* Bonne capacité pédagogique pour vulgariser les concepts de sécurité
// end::prerequis[]
