// tag::intro[]
La cybersécurité est au cœur de cette saison. Les apprenants explorent les principales menaces de sécurité, apprennent à identifier les vulnérabilités, à mettre en place des stratégies de protection, et à sécuriser les données et applications contre les attaques.
// end::intro[]

== Objectifs pédagogiques

// tag::objectifs[]
* Identifier les principales menaces de cybersécurité et les vulnérabilités courantes
* Connaître et appliquer les bonnes pratiques de sécurité dans le développement d’applications
* Mettre en œuvre des stratégies de protection et de sécurisation des données
* Apprendre à surveiller et à gérer la sécurité des systèmes
// end::objectifs[]

== Notions

// tag::notions[]
* Authentification et autorisation
* Gestion des accès
* Cryptage des données
* Sécurité des API
* Tests de pénétration
* Sécurisation des bases de données
* Prévention des attaques XSS, CSRF et injection SQL
* Surveillance et audit de sécurité
* Plan de réponse aux incidents
// end::notions[]

== Prérequis formateur

// tag::prerequis[]
* Maîtrise des principes de sécurité informatique
* Connaissance des bonnes pratiques de sécurité
* Expérience en cryptage et gestion des accès
* Compétences en tests de sécurité et audit
// end::prerequis[]

== Résumé

// tag::resume[]
Cette saison permet aux apprenants de se lancer sereinement dans leur formation. On les aide à installer tous les outils, on leur présente quelques notions d'introduction, on les prépare à savoir cloner les challenges et lancer des DevContainer.
// end::resume[]
