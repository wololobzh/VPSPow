== Objectifs pédagogiques

// tag::objectifs[]
Concevoir des schémas de données complexes en GraphQL
Maîtriser les relations entre entités dans les bases de données graphes
Créer et interroger des relations hiérarchiques et imbriquées
Utiliser des types personnalisés, fragments et alias dans GraphQL
Optimiser les requêtes pour les données complexes 
// end::objectifs[]

== Prérequis formateur

// tag::prerequis[]
Connaissance approfondie de la modélisation de données
Bonne maîtrise de GraphQL et de la structure de schémas
Expérience avec les bases de données relationnelles ou graphes
Compétences pédagogiques 
// end::prerequis[]
