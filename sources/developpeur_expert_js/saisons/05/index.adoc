// tag::intro[]
L'usage de GraphQL est introduit comme un langage d’interrogation pour rendre les requêtes de données plus flexibles et spécifiques. Les apprenants apprennent à structurer et optimiser leurs requêtes pour améliorer la performance des applications.
// end::intro[]

== Objectifs pédagogiques

// tag::objectifs[]
* Comprendre les concepts des bases de données orientées graphes
* Maîtriser l’interrogation de données avec GraphQL
* Concevoir des modèles de données pour des relations complexes
* Optimiser la performance et la scalabilité des applications de données
// end::objectifs[]

== Notions

// tag::notions[]
* Introduction aux bases de données orientées graphes
* Langage de requêtes graphes
* Modélisation de graphes
* Interrogation de données avec GraphQL
* Optimisation des requêtes
* Relations complexes et hiérarchiques
* Indexation pour bases de données graphes
* Performances et scalabilité
// end::notions[]



== Prérequis formateur

// tag::prerequis[]
* Expertise en bases de données orientées graphes
* Connaissance de GraphQL et des requêtes avancées
* Compétences en modélisation de graphes
* Expérience en optimisation de bases de données
// end::prerequis[]
