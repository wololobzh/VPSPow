// tag::intro[]
Cette saison pose les bases de l'analyse et de la conception de projets. Les apprenants apprendront à décomposer un besoin, à structurer et à modéliser les fonctionnalités attendues d’une application, ainsi qu'à choisir les technologies adéquates pour répondre aux objectifs du projet.
// end::intro[]

== Objectifs pédagogiques

// tag::objectifs[]
* Comprendre les concepts de base de l’UML
* Savoir modéliser un système en utilisant les diagrammes UML
* Analyser et formaliser les besoins fonctionnels et techniques d’une application
* Élaborer une architecture technique basée sur une modélisation UML
// end::objectifs[]

== Notions

// tag::notions[]
* Introduction à l'analyse et conception
* Présentation d'UML et de ses objectifs
* Diagrammes de cas d'utilisation
* Identification des acteurs et des cas d'utilisation
* Diagrammes de classes
* Relations entre classes (associations, généralisations, dépendances)
* Attributs et opérations dans les classes
* Diagrammes de séquence
* Interactions entre objets et messages
* Diagrammes de collaboration
* Diagrammes d'activité
* Modélisation des flux et états d'un système
* Diagrammes d'états-transitions
* Gestion des événements et transitions d'états
* Diagrammes de composants
* Décomposition des systèmes en composants
* Diagrammes de déploiement
* Architecture physique et déploiement des composants
* Introduction aux bonnes pratiques de modélisation UML
* Études de cas pratiques et ateliers de modélisation
// end::notions[]

== Prérequis formateur

// tag::prerequis[]
* Maîtrise des concepts UML
* Expérience en analyse fonctionnelle
* Connaissances en modélisation de données
* Compétences en architecture logicielle
// end::prerequis[]

== Résumé

// tag::resume[]
Cette saison permet aux apprenants de se lancer sereinement dans leur formation. On les aide à installer tous les outils, on leur présente quelques notions d'introduction, on les prépare à savoir cloner les challenges et lancer des DevContainer.
// end::resume[]
