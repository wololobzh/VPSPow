// tag::intro[]
Cette journée de formation introduit l'analyse et la conception logicielle, en mettant en lumière l'utilisation des diagrammes de cas d'utilisation UML. Vous découvrirez comment structurer et représenter les exigences fonctionnelles d'un système à travers des acteurs et leurs interactions, facilitant ainsi la communication entre les équipes de développement et les parties prenantes.
// end::intro[]

== Objectifs pédagogiques

// tag::objectifs[]
* Comprendre les principes de base de l'analyse et conception logicielle
* Découvrir les fondamentaux d'UML (Unified Modeling Language)
* Identifier les différents acteurs d'un système et leurs interactions
* Apprendre à créer et interpréter un diagramme de cas d'utilisation
* Utiliser les diagrammes de cas d'utilisation pour modéliser les besoins fonctionnels
* Développer une communication claire autour des exigences système
// end::objectifs[]

== Prérequis formateur

// tag::prerequis[]
* Connaissance de base des concepts de modélisation et d'UML
* Expérience dans l'analyse des exigences fonctionnelles d'un projet
* Compétences pédagogiques pour enseigner les techniques de modélisation
* Bonne compréhension des méthodologies de développement logiciel (agile, cycle en V)
* Maîtrise des outils de création de diagrammes UML (par exemple Lucidchart, Visual Paradigm, ou autres)
// end::prerequis[]
