== Session

https://docs.nestjs.com/security/authentication[Doc]

On a nos users, les notes, les rôles et les permissions, il nous manque l'authentification et les authorisations.

On commence par installer les modules nécessaires à la création de la fonctionnalité d'authentification, en suivant la doc : https://docs.nestjs.com/techniques/session[Les sessions avec NestJS]

* Un module pour gérer des sessions utilisateurs, et un module pour hasher les mots de passe.

[source ,bash]
----
npm i express-session
npm i -D @types/express-session
npm i bcrypt
npm i -D @types/bcrypt
----

== Session : authentification

Avec les sessions en place, on peut attaquer l'authentification, on génère un module complet `auth`, et on suit la https://docs.nestjs.com/security/authentication[doc], en l'adaptant, car la doc propose des raccourcis à fin de démonstration, et on ne fera pas de `jwt`, mais des sessions.

On devra faire attention, il y a plein de détails à ne pas louper.

Dans un terminal, on tape la commande suivante :

`nest g resource auth --no-spec`

== Authentification : la suite

On a un formulaire de création de compte, ainsi qu'un formulaire de connexion, les deux sont déjà configurés pour aller vers les routes `/auth/register` et `auth/login`.

On va pouvoir créer une fonctionnalité d'authentification basée sur les sessions, on garde les choses simples, on se servira des sessions avec `express-session` et les décorateurs de `NestJS`, pas besoin d'ajouter un module du style `passport`.

Voici les étapes à réaliser, dans un ordre qui nous paraît logique :

== Authentification : les étapes

* Créer un utilisateur
* Faire un login (création de session utilisateur et transfert d'infos aux vues)

// src/auth/auth.service.ts
// En haut du fichier
import * as bcrypt from 'bcrypt';
import { UserService } from '../users/user.service';
// ...
async register(
    username: string,
    email: string,
    pass: string
): Promise<any> {
    const user = await this.userService.signUp(email);
    if (user) {
        /**
        * On n'envoie pas de message précis si user existe en BDD
        */
        throw new Error("Un truc horrible s'est produit sur notre serveur");
    }

    const salt = await bcrypt.genSalt(10);
    const hash = await bcrypt.hash(pass, salt);

     await this.userService.register({
        username,
        email,
        pass: hash,
    });

    return true;
}

Login : Vérification des infos du formulaire

[NOTE.speaker]

*Login : Vérification des infos du formulaire*

On fait comme d'habitude avec le DTO, on s'en sert pour valider les infos du formulaire. Voici le code de la méthode `signIn` du contrôleur :

[source ,typescript]
----
// src/auth/auth.controller.ts
// ...
import { SignInDto } from './dto/signIn.dto';
import { AuthService } from './auth.service';
// ...
@HttpCode(HttpStatus.OK)
@Post('login')
@Redirect('/')
async signIn(
    @Body() signInDto: SignInDto,
    @Session() session: Record<string, any>
) {
    const user = await this.authService.signIn(
        signInDto.email,
        signInDto.password
    );
    // On créé la session utilisateur
    session.user = session.user ?? user;
}
----

*Le DTO :*

[source ,typescript]
----
// src/auth/dto/signIn.dto.ts
import { IsEmail, IsNotEmpty } from 'class-validator';

    @IsEmail()
    email: string;

    @IsNotEmpty()
    password: string;

*La méthode `signIn` de `auth.service`:*

[source ,typescript]
----
// src/auth/auth.service.ts
async signIn(email: string, pass: string = 'secret'): Promise<any> {
    const user = await this.userService.signIn(email);
    if (user) {
        const ok = await bcrypt.compare(pass, user?.password);

        if (!ok) {
            throw new UnauthorizedException();
        }
        const { password, ...result } = user;
        // On efface le mot de passe pour être sûr que l'on ne fera pas de bêtises.
        delete result.dataValues.password;

        return result.dataValues;
    }
    // Toujours pas de message précis
    throw new Error('Something went wrong');
}

== Middleware d'authentification

La session est démarrée, il nous faut maintenant un middleware qui permet de vérifier si on est authentifié, et qui transmet les informations de session aux vues.

Plusieurs étapes sont nécessaires, notamment un middleware de gestion d'erreur. En effet, si on n'est pas authentifié et qu'on tente d'accéder à certaines routes, on doit provoquer une erreur et afficher une page dédiée, le tout avec le code http correct.

== Démonstration 04

Middleware d'authentification

[NOTE.speaker]
--
*Middleware d'authentification : gestion d'erreur*

[NOTE.speaker]
Copypasta le code des middlewares, le lire et l'expliquer plutôt que livecoder

Voici le middleware de gestion d'erreur :
[source ,typescript]
----
import {
    ExceptionFilter,
    Catch,
    ArgumentsHost,
    HttpException,
    HttpStatus,
} from '@nestjs/common';
import { HttpAdapterHost } from '@nestjs/core';

@Catch()
export class AllExceptionsFilter implements ExceptionFilter {
    constructor(private readonly httpAdapterHost: HttpAdapterHost) {}

    catch(exception: unknown, host: ArgumentsHost) {
        // In certain situations `httpAdapter` might not be available in the
        // constructor method, thus we should resolve it here.
        const { httpAdapter } = this.httpAdapterHost;
        const ctx = host.switchToHttp();
        const httpStatus =
            exception instanceof HttpException
                ? exception.getStatus()
                : HttpStatus.INTERNAL_SERVER_ERROR;

        const responseBody = {
            statusCode: httpStatus,
            timestamp: new Date().toISOString(),
            path: httpAdapter.getRequestUrl(ctx.getRequest()),
            error: exception.toString(),
        };

        const response = ctx.getResponse();
        return httpAdapter.render(response, 'error', responseBody);
    }
}
----

*Middleware d'authentification : isAuth*

[source ,typescript]
----
import {
    Injectable,
    NestMiddleware,
    HttpException,
    HttpStatus,
} from '@nestjs/common';
import { Request, Response, NextFunction } from 'express';

@Injectable()
export class IsAuthMiddleware implements NestMiddleware {
    use(req: Request, res: Response, next: NextFunction) {
        delete req.app.locals.user;
        if ('user' in req.session) {
            req.app.locals.user = req.session.user;
            return next();
        }

        // * throw ou next ? throw car NestJS
        throw new HttpException('Forbidden', HttpStatus.FORBIDDEN);
    }
}
----

== Démonstration 05

Middleware d'authentification

[NOTE.speaker]
--
*Middleware d'authentification : branchement du middleware auth*

// On applique le middleware sur le contrôleur `notes.controller`

Pour brancher ce middleware, il suffit de modifier le module `app.module`.

On importe le middleware et on configure le module avec :

[source ,typescript]
----
// src/app.module.ts
import { IsAuthMiddleware } from './common/middlewares/isAuth';
// ...
export class AppModule implements NestModule {
    configure(consumer: MiddlewareConsumer) {
        // On applique le middleware sur le contrôleur `notes.controller`
        consumer.apply(IsAuthMiddleware).forRoutes('notes');
    }
}
----

*NOTE :* Pour appliquer ce middleware sur plusieurs resources, on pourrait ajouter plusieurs ressources en argument à la methode `forRoutes` : `forRoutes('notes', 'autre')`.

== Correction

1. Création du module auth :
+
```bash
nest g resource auth --no-spec
```

2. Register (auth.controller.ts) :
+
```typescript
@Post('register')
async register(@Body() registerDto: RegisterDto) {
  const hashedPassword = await bcrypt.hash(registerDto.password, 10);
  return this.authService.create({
    ...registerDto,
    password: hashedPassword
  });
}
```

3. Login (auth.controller.ts) :
+
```typescript
@Post('login')
async login(
  @Body() loginDto: LoginDto,
  @Session() session: Record<string, any>
) {
  const user = await this.authService.validateUser(
    loginDto.email,
    loginDto.password
  );
  if (user) {
    session.user = user;
    return user;
  }
  throw new UnauthorizedException();
}
```

4. Logout (auth.controller.ts) :
+
```typescript
@Get('logout')
async logout(@Session() session: Record<string, any>) {
  session.destroy();
  return { message: 'Logged out successfully' };
}
```
