== Introduction

* Définition : Reverse proxy agit comme intermédiaire entre clients et serveurs.
* Avantages : Sécurité accrue, répartition de charge, SSL simplifié.
* Cas d'usage : Gestion de plusieurs services sur un même domaine, équilibrage de charge.

[NOTE.speaker]
====
Un reverse proxy reçoit les requêtes des clients et les redirige vers le serveur approprié. Il cache la structure interne du réseau, améliorant la sécurité et l'efficacité.
====

== Fonctionnement

* Gère les requêtes : Dirige vers le bon serveur backend.
* Différences : Contrairement à un proxy classique qui agit pour le client, un reverse proxy agit pour le serveur.

[NOTE.speaker]
====
Le reverse proxy intercepte les requêtes entrantes et les redistribue vers les serveurs cibles en fonction de règles définies.
====

== Présentation de Caddy

* Avantages : Configuration simple, SSL automatique.
* Fonctionnalités : Support HTTP/2, gestion des certificats SSL.

https://caddyserver.com/

[NOTE.speaker]
====
Caddy est connu pour sa facilité d'utilisation et sa gestion automatique des certificats SSL, ce qui simplifie le déploiement sécurisé des applications.
====

=== Configuration avec Docker Compose

* Installation : Utilisation de Caddy via Docker Compose.
* Configuration : Fichier `Caddyfile` pour définir les règles de redirection.

```yaml
version: '3.7'

services:
  caddy:
    image: caddy:latest
    ports:
      - "80:80"
    volumes:
      - ./Caddyfile:/etc/caddy/Caddyfile
    networks:
      - web

  myapp:
    image: myapp:latest
    networks:
      - web

networks:
  web:
```

```caddyfile
localhost {
    reverse_proxy myapp:80
}
```

[NOTE.speaker]
====
Nous utilisons Docker Compose pour orchestrer le conteneur Caddy. Le fichier `Caddyfile` définit que les requêtes vers `localhost` sont redirigées vers le service `myapp`.

Le service `myapp` n'a plus besoin d'exporter de port.
====

== Gestion des sous-domaines

* Sous-domaines : Permettent de rediriger vers différents services.
* Exemple de configuration :

```caddyfile
app1.localhost {
    reverse_proxy app1:80
}

app2.localhost {
    reverse_proxy app2:80
}
```

[NOTE.speaker]
====
Caddy peut gérer plusieurs sous-domaines, chacun redirigeant vers un service différent. Cela simplifie la gestion de plusieurs applications sur un même serveur.
====
