== Variables et secrets

* Variables : Stockage de valeurs dynamiques dans le workflow.
* Secrets : Informations sensibles sécurisées.

```yaml
steps:
  - name: Print variable
    run: echo ${{ vars.MY_VAR }}
```

[NOTE.speaker]
====
Les variables et secrets sont utilisées pour stocker des valeurs qui peuvent être réutilisées. Ils sont gérés via les paramètres de dépôt ou de l'organisation : "Settings" > "Secrets and variables" > "Actions"
====

// tag::demo[]
=== Démonstration

Créer une variable et l'afficher avec un echo

[NOTE.speaker]
====
1. Créer un fichier `.github/workflows/variables.yml`.
2. Définir une variable `MY_VAR` dans les paramètres du repo.
3. Ajouter une étape pour afficher la variable avec `run: echo ${{ vars.MY_VAR }}`.
4. Exécuter le workflow pour voir le résultat.
====
// end::demo[]

=== Gestion des secrets dans Github Actions

* Configuration : Ajouter des secrets dans les paramètres du dépôt.
* Utilisation : Référence dans les workflows pour des informations sécurisées.

```yaml
steps:
  - name: Deploy
    run: surge --project . --token ${{ secrets.SURGE_TOKEN }}
```

[NOTE.speaker]
====
Les secrets sont configurés dans la section "Settings" > "Secrets and variables" > "Actions" du dépôt ou de l'organisation. Ils peuvent être utilisés dans les workflows via `${{ secrets.SECRET_NAME }}`.
====

== Introduction à Surge.sh

* Utilité : Héberger des sites statiques facilement.
* Configuration : Installation et déploiement rapide.

[NOTE.speaker]
====
Surge.sh est un service de déploiement simple pour les sites statiques. Il est idéal pour les déploiements rapides et les démonstrations.

Github pages est une autre option pour héberger des sites statiques, mais le repo doit être public, ou avoir un plan pay Github.
====

// tag::demo[]
=== Démonstration

Montrer comment fonctionne Surge.sh

[NOTE.speaker]
====
1. Installer Surge en local avec `npm install --global surge`.
2. Builder le template Vite avec `npm run build`.
3. Utiliser la commande `surge` pour déployer le site.
4. Observer l'URL générée pour accéder au site en ligne.
====
// end::demo[]
