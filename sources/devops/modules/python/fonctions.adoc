== Késako

Une fonction est un bloc de code qui effectue une tâche spécifique. Elle peut prendre des paramètres en entrée et renvoyer une valeur en sortie.

Elle a pour but de structurer le code en séparant les différentes tâches et peut être utilisée plusieurs fois dans un programme.

.Exemple de déclaration
```python
def function_name(param1, param2):
    # instructions
    return result
```

=== Exemple simple

```python
def afficher_personne(nom, age):
    print(f"Nom : {nom}, age : {age}")

afficher_personne("Alice", 30)
```

[NOTE.speaker]
--
- `def afficher_personne(nom, age):` déclare une fonction `afficher_personne` qui prend deux paramètres `nom` et `age`
- `print(f"Nom : {nom},  age : {age}")` affiche le nom et l'âge de la personne
- `afficher_personne("Alice", 30)` appelle la fonction `afficher_personne` avec les valeurs "Alice" et 30
- ici, il n'y a pas de retour
--

=== Exemple avec valeur de retour

```python
def calculer_moyenne(notes):
    return sum(notes) / len(notes)

moyenne = calculer_moyenne([10, 12, 14])
print(moyenne)
```

[NOTE.speaker]
--
- `def calculer_moyenne(notes):` déclare une fonction `calculer_moyenne` qui prend une liste de notes en paramètre
- `return sum(notes) / len(notes)` renvoie la moyenne des notes ; `sum` et `len` sont des fonctions natives de Python
- `moyenne = calculer_moyenne([10, 12, 14])` appelle la fonction `calculer_moyenne` avec la liste `[10, 12, 14]` et stocke le résultat dans la variable `moyenne`
--

== Fonction lambda

Une fonction lambda est une fonction anonyme qui peut prendre un nombre quelconque d'arguments, mais ne peut contenir qu'une seule instruction.

.Exemple de déclaration
```python
lambda param1, param2: instruction
```

.Exemple d'utilisation
```python
addition = lambda a, b: a + b
print(addition(2, 3))
```

[NOTE.speaker]
--
- `lambda a, b: a + b` déclare une fonction lambda qui prend deux paramètres `a` et `b` et renvoie leur somme
- `print(addition(2, 3))` appelle la fonction lambda avec les valeurs 2 et 3 et affiche le résultat
--

== Bonnes pratiques

* *Noms descriptifs* : Utiliser des noms de fonction clairs et explicites.
* *Documentation* : Ajouter des docstrings pour décrire le comportement des fonctions.

.Exemple
```python
def obtenir_augmentation_salaire(salaire, pourcentage):
    """
    Calcule le nouveau salaire après une augmentation.

    :param salaire: salaire actuel
    :param pourcentage: pourcentage d'augmentation
    :return: nouveau salaire après augmentation
    """
    return salaire + (salaire * pourcentage / 100)

nouveau_salaire = obtenir_augmentation_salaire(2000, 10)
print(nouveau_salaire)
```

[NOTE.speaker]
--
* `def obtenir_augmentation_salaire(salaire, pourcentage):` déclare une fonction `obtenir_augmentation_salaire` qui prend le salaire actuel et le pourcentage d'augmentation en paramètres
* La docstring décrit le comportement de la fonction, les paramètres et la valeur de retour
** `Calcule ...` : Description de la fonction
** `:param salaire:` : Description du paramètre `salaire`
** `:param pourcentage:` : Description du paramètre `pourcentage`
** `:return:` : Description de la valeur de retour
* `return salaire + (salaire * pourcentage / 100)` renvoie le nouveau salaire après augmentation
* `nouveau_salaire = obtenir_augmentation_salaire(2000, 10)` appelle la fonction `obtenir_augmentation_salaire` avec les valeurs 2000 et 10 et stocke le résultat dans la variable `nouveau_salaire`

*Introduction aux Fonctions*

Objectif : Introduire la notion de fonction en Python, en expliquant ce qu'elle est, son utilité et comment la définir.

.Exemple de code
```python
# Définir une fonction simple qui affiche un message
def saluer():
    print("Bonjour tout le monde!")

# Appel de la fonction
saluer()
```

Explication :

* Qu'est-ce qu'une fonction ? Une fonction est un bloc de code réutilisable qui exécute une tâche spécifique. Elle permet de structurer le code, de le rendre plus lisible et de réduire la redondance.
* Syntaxe : Les fonctions sont définies en utilisant le mot-clé `def` suivi du nom de la fonction et de parenthèses.
* Appel de fonction : Pour exécuter le code contenu dans une fonction, on doit l'appeler en utilisant son nom suivi de parenthèses.

*Fonctions avec Paramètres et Valeurs de Retour*

Objectif : Montrer comment une fonction peut prendre des paramètres et retourner des valeurs pour rendre le code plus flexible et utile.

.Exemple de code
```python
# Définir une fonction avec des paramètres
def additionner(a, b):
    return a + b

# Appel de la fonction avec des arguments
resultat = additionner(3, 5)
print(f"Le résultat de l'addition est : {resultat}")
```

Explication :
* Paramètres : Les paramètres sont des variables qui permettent de passer des informations à une fonction. Ici, `a` et `b` sont des paramètres.
* Valeur de retour : La fonction peut retourner une valeur à l'aide du mot-clé `return`. Dans cet exemple, la fonction retourne la somme de `a` et `b`.
* Importance des paramètres et du retour : Les paramètres rendent les fonctions plus dynamiques et réutilisables dans différents contextes, tandis que les valeurs de retour permettent de récupérer le résultat de l'exécution de la fonction.

*Fonctions Lambda*

Objectif : Introduire les fonctions lambda (ou fonctions anonymes), qui sont une manière concise de définir des fonctions courtes.

.Exemple de code
```python
# Définir une fonction lambda pour multiplier deux nombres
multiplier = lambda x, y: x * y

# Utilisation de la fonction lambda
resultat = multiplier(4, 7)
print(f"Le résultat de la multiplication est : {resultat}")
```

Explication :
* Qu'est-ce qu'une fonction lambda ? Une fonction lambda est une petite fonction anonyme qui est définie à l'aide du mot-clé `lambda`. Elles sont souvent utilisées pour des opérations simples qui peuvent être exprimées en une seule ligne de code.
* Syntaxe : `lambda paramètres: expression` définit une fonction lambda. Elle est immédiatement prête à être utilisée après sa définition.
* Limites des fonctions lambda : Elles sont limitées à une seule expression, ce qui les rend peu adaptées pour des tâches plus complexes.

*Bonnes Pratiques pour Écrire des Fonctions*

Objectif : Mettre en avant les bonnes pratiques lors de l'écriture de fonctions pour améliorer la qualité du code.

* Nom de la fonction : Utilisez des noms de fonctions descriptifs qui indiquent clairement ce que fait la fonction. Exemple : calculer_moyenne() plutôt que cmoy().
* Documentation : Ajoutez une docstring pour expliquer ce que fait la fonction, ses paramètres, et ce qu'elle retourne.

.Exemple de code
```python
def additionner(a, b):
    """
    Retourne la somme de deux nombres.
    
    Paramètres:
    a (int, float): Le premier nombre.
    b (int, float): Le deuxième nombre.
    
    Retour:
    int, float: La somme des deux nombres.
    """
    return a + b
```

Utilisation des paramètres par défaut : Fournissez des valeurs par défaut aux paramètres quand cela est possible.

.Exemple de code
```python
def saluer(nom="tout le monde"):
    print(f"Bonjour {nom}!")
```

Gestion des erreurs : Pensez à gérer les erreurs et les exceptions pour éviter que le programme ne plante de manière inattendue.

```python
def diviser(a, b):
    try:
        return a / b
    except ZeroDivisionError:
        return "Erreur : division par zéro!"
```

Modularité : Évitez les fonctions trop longues. Si une fonction fait trop de choses, divisez-la en plusieurs sous-fonctions.

*Démonstration finale*

Objectif : Intégrer tous les concepts en une seule démonstration pour montrer comment tout cela fonctionne ensemble.

.Exemple de code
```python
def calculer_surface_rectangle(longueur, largeur):
    """
    Calcule la surface d'un rectangle.

    Paramètres:
    longueur (float): La longueur du rectangle.
    largeur (float): La largeur du rectangle.

    Retour:
    float: La surface du rectangle.
    """
    return longueur * largeur

# Utilisation avec des fonctions lambda
perimetre_rectangle = lambda longueur, largeur: 2 * (longueur + largeur)

# Bonnes pratiques : gestion des erreurs
def calculer_diagonale_rectangle(longueur, largeur):
    """
    Calcule la diagonale d'un rectangle en utilisant le théorème de Pythagore.
    """
    try:
        return (longueur**2 + largeur**2)**0.5
    except TypeError:
        return "Erreur : les paramètres doivent être des nombres."

# Exécution de la démonstration
longueur = 5
largeur = 3

surface = calculer_surface_rectangle(longueur, largeur)
perimetre = perimetre_rectangle(longueur, largeur)
diagonale = calculer_diagonale_rectangle(longueur, largeur)

print(f"Surface: {surface}, Périmètre: {perimetre}, Diagonale: {diagonale:.2f}")
```

Conclusion :

* Cette démonstration montre l'utilité des fonctions en Python pour organiser et structurer le code.
* Les fonctions avec des paramètres et des valeurs de retour permettent de créer des blocs de code réutilisables et flexibles.
* Les fonctions lambda offrent une manière concise d'écrire des fonctions simples.
* Respecter les bonnes pratiques garantit un code propre, lisible et maintenable.
