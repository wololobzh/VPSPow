== Introduction aux Pipes et Redirections

Les pipes permettent de rediriger la sortie d'une commande comme entrée d'une autre.

* Le symbole `|` est utilisé pour rediriger la sortie standard d'une commande vers l'entrée d'une autre commande.
* Les redirections permettent de diriger la sortie d'une commande vers un fichier ou d'autres commandes.

[NOTE.speaker]
--
Les pipes et redirections sont essentiels pour chaîner les commandes et traiter les données efficacement. Le pipe permet d'envoyer la sortie d'une commande vers une autre, tandis que les redirections standard permettent d'enregistrer ou de manipuler les sorties de manière spécifique.
--

=== Sorties standard et erreur

* La sortie standard est redirigée avec `>`
* La sortie d'erreur est redirigée avec `2>`

[NOTE.speaker]
--
`>` redirige la sortie standard vers un fichier ou une autre commande, tandis que `2>` redirige les erreurs. Par exemple :
```bash
commande > fichier.txt 2> erreurs.txt
```
Cela enregistre les résultats dans un fichier et les erreurs dans un autre fichier.
--

=== Utilisation des Pipes

* `grep` permet de filtrer des lignes contenant un motif spécifique.
* `wc -l` compte le nombre de lignes dans un fichier ou un flux de données.
* `gzip` compresse ou décompresse les fichiers.
* `pv` affiche l'avancement des données en cours de traitement dans un pipe.

[NOTE.speaker]
--
Les pipes permettent de traiter et manipuler de grandes quantités de données de manière efficace. Par exemple :
```bash
grep "motif" fichier.txt | wc -l
```
Cela compte le nombre de lignes contenant "motif" dans un fichier.
--

== Redirections complexes

Il est possible de combiner plusieurs redirections pour gérer à la fois la sortie standard et la sortie d'erreur.

.Redirection de la sortie standard et de l'erreur vers un fichier unique
```bash
commande > fichier.txt 2>&1
```
.Redirection de l'entrée d'une commande depuis un fichier
```bash
commande < input.txt
```

[NOTE.speaker]
--
Les redirections complexes permettent de gérer les sorties multiples d'une commande. La commande `2>&1` redirige à la fois la sortie standard et l'erreur vers le même fichier ou destination. Utiliser `< input.txt` permet d'alimenter une commande avec un fichier en tant qu'entrée.
--

== Les commandes incontournables du terminal

* `grep` : recherche un motif spécifique dans un fichier ou un flux de données.
* `find` : recherche des fichiers dans un répertoire en fonction de critères (nom, taille, etc.).
* `sed` : permet l'édition en flux pour rechercher et remplacer des chaînes de caractères dans un fichier.
* `awk` : un langage de traitement de texte pour extraire et manipuler des colonnes dans un fichier.
* `uniq` : élimine les doublons dans des fichiers triés.

[NOTE.speaker]
--
Ces commandes sont essentielles pour traiter, rechercher et modifier des fichiers ou des flux de données. Par exemple, `grep` permet de rechercher des motifs spécifiques, tandis que `awk` est puissant pour extraire des colonnes dans des fichiers structurés. `uniq` est utile pour supprimer les doublons après un tri.
--

=== Commande `grep`

Filtre les lignes contenant un motif spécifique :
```bash
grep "motif" fichier.txt
```

[NOTE.speaker]
--
La commande `grep` est l'une des plus couramment utilisées pour rechercher des motifs dans des fichiers. Par exemple :

```bash
grep "erreur" /var/log/syslog
```
Cela extrait toutes les lignes du fichier de log qui contiennent le mot "erreur".
--

=== Commande `find`

Recherche des fichiers dans des répertoires en fonction de critères :

```bash
find /chemin -name "*.txt"
```

[NOTE.speaker]
--
`find` permet de rechercher des fichiers dans un répertoire spécifique, avec de nombreux critères comme le nom, la taille, la date de modification. Par exemple :

```bash
find /home -name "*.jpg" -size +1M
```
Cela recherche les fichiers images de plus de 1 Mo dans le répertoire `/home`.
--

=== Commande `sed`

Recherche et remplace une chaîne dans un fichier :

```bash
sed -i 's/ancien/nouveau/' fichier.txt
```

[NOTE.speaker]
--
`sed` est un puissant éditeur de flux qui permet de modifier le contenu des fichiers en ligne de commande. Par exemple :

```bash
sed -i 's/erreur/succès/g' fichier.txt
```
Remplace **toutes** les occurrences de "erreur" par "succès" dans le fichier.
--

=== Commande `awk`

Extraction de colonnes spécifiques dans un fichier :

```bash
awk '{print $1, $3}' fichier.txt
```

[NOTE.speaker]
--
`awk` est utile pour manipuler des fichiers de données structurées. Par exemple, pour extraire la première et la troisième colonne d'un fichier :

```bash
awk '{print $1, $3}' fichier.csv
```
Cela affiche uniquement les colonnes 1 et 3 du fichier CSV.
--

=== Commande `uniq`

Supprime les lignes en double dans un fichier trié :

```bash
sort fichier.txt | uniq
```

[NOTE.speaker]
--
La commande `uniq` ne fonctionne que sur des fichiers triés. Pour supprimer les doublons, il est donc recommandé de trier le fichier d'abord avec `sort`, puis d'utiliser `uniq` pour éliminer les lignes répétées.
--
