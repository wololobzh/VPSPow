== Introduction

* ElasticSearch est un moteur de recherche distribué et open source.
* Il permet de stocker, rechercher et analyser de grandes quantités de données rapidement.
* Cas d'utilisation courants : 
** moteurs de recherche
** analyse de logs
** monitoring de systèmes

[NOTE.speaker]
--
ElasticSearch est très utilisé dans les environnements Big Data grâce à ses performances et à sa capacité à traiter d'énormes volumes de données en temps réel. Il est souvent intégré avec Kibana et Logstash dans le stack ELK.
--

=== Cas d'utilisation d'ElasticSearch

* Recherche en texte intégral pour des sites web.
* Surveillance de l'infrastructure IT et analyse des logs.
* Analyse des données financières ou commerciales.

[NOTE.speaker]
--
ElasticSearch est notamment utilisé dans les environnements où la rapidité de recherche et l’analyse sont critiques, comme dans le e-commerce pour la gestion des produits ou encore dans l'analyse de logs système en temps réel.
--

== Installation

* Prérequis système : 
** Java 8 ou supérieur.
** Minimum 2 Go de RAM.
* Installation sur Ubuntu/Debian : 
** `sudo apt-get update`
** `sudo apt-get install elasticsearch`

[NOTE.speaker]
--
L'installation d'ElasticSearch nécessite des ressources suffisantes pour garantir des performances optimales. Il est recommandé de configurer le système pour allouer suffisamment de mémoire à ElasticSearch.
--

// tag::demo[]
=== Démonstration

Installation d'ElasticSearch sur Ubuntu/Debian

[NOTE.speaker]
--
1. Mettre à jour le système avec `sudo apt-get update`.
2. Installer ElasticSearch avec `sudo apt-get install elasticsearch`.
3. Lancer le service avec `sudo systemctl start elasticsearch`.
4. Vérifier le statut du service avec `sudo systemctl status elasticsearch`.
5. Accéder à ElasticSearch via le navigateur à l'adresse : `http://localhost:9200`.
--
// end::demo[]

== Configuration de base

* Fichier de configuration principal : `elasticsearch.yml`.
* Configuration des paramètres réseau : 
** Port par défaut : 9200.
** Configuration des nœuds et du cluster.
* Sécurisation de l'accès aux données : 
** Authentification.
** Contrôle d'accès basé sur les rôles.

[NOTE.speaker]
--
La configuration de base d'ElasticSearch est essentielle pour garantir à la fois l'efficacité et la sécurité du système. Il est important de configurer correctement les paramètres réseau pour éviter toute exposition non désirée.
--

== Utilisation

* Indexation de documents : 
** Utilisation de l'API REST pour indexer des données.
** Exemple : `POST /index_name/_doc/1`.
* Requêtes de recherche : 
** Utilisation de l'API de recherche pour récupérer des documents.
** Exemple : `GET /index_name/_search`.

[NOTE.speaker]
--
ElasticSearch permet d'indexer des documents JSON. Chaque document est associé à un index, ce qui facilite la recherche à travers des milliards de documents. Les requêtes sont effectuées via des API REST, ce qui simplifie les interactions avec le système.
--

=== Introduction à Kibana

* Kibana est un outil de visualisation pour ElasticSearch.
* Permet de créer des tableaux de bord interactifs.
* Utilisé pour analyser les données indexées dans ElasticSearch.

https://www.elastic.co/fr/kibana[Site officiel de Kibana]

[NOTE.speaker]
--
Kibana est souvent utilisé en combinaison avec ElasticSearch pour visualiser les données sous forme de graphiques, de cartes et d’autres représentations. Il permet de créer des dashboards en temps réel à partir des données d'ElasticSearch.
--
