== Introduction aux bases de données

* C'est une collection organisée d'informations structurées
* Faciliter le stockage, la récupération et la gestion des données
* Inventé dans les années 1960
* Utilisé dans toutes les industries

[NOTE.speaker]
--
Une base de données est une collection organisée d'informations structurées pour faciliter le stockage, la récupération et la gestion. L'évolution des bases de données remonte aux années 1960 avec l'émergence des systèmes de gestion de bases de données (SGBD) pour organiser des ensembles d'informations complexes. Aujourd'hui, elles sont utilisées dans presque toutes les industries pour gérer et analyser des données.
--

=== Types de bases de données

* Bases de données relationnelles (SQL)
* Bases de données NoSQL (clé-valeur, documentaires, graphiques, colonnes)
* Comparaison SQL vs NoSQL

[NOTE.speaker]
--
Les bases de données relationnelles, comme PostgreSQL, sont basées sur un modèle structuré avec des tables, des lignes et des colonnes. Elles utilisent le langage SQL pour interroger les données. Les bases de données NoSQL, telles que MongoDB, sont non-relationnelles et permettent une grande flexibilité pour les données non structurées ou semi-structurées, souvent préférées pour des applications nécessitant une échelle massive.
--

== Rôle d'un DBA (Database Administrator)

* Gestion des performances
* Sécurité des données
* Sauvegarde et récupération
* Surveillance et maintenance

[NOTE.speaker]
--
Le rôle d'un DBA (Database Administrator) est essentiel pour assurer le bon fonctionnement d'une base de données. Il veille à ce que les bases soient performantes et sécurisées, et il planifie les sauvegardes et restaurations en cas de panne ou de perte de données. La surveillance continue est cruciale pour identifier et résoudre les problèmes avant qu'ils ne deviennent critiques.
--

=== Tâches d'un DBA au quotidien

* Monitoring et optimisation
* Maintenance des index
* Gestion des accès utilisateurs
* Résolution des incidents

[NOTE.speaker]
--
Le DBA assure le suivi des performances en surveillant les métriques importantes comme l'utilisation du processeur et de la mémoire. Il optimise les requêtes lentes, indexe les données pour une récupération plus rapide et gère les autorisations d'accès des utilisateurs pour garantir la sécurité.
--

== Pourquoi choisir PostgreSQL ?

* Support des types de données avancés (JSON, XML, hstore)
* Respect des normes SQL
* Open-source, robustesse et fiabilité
* Extensions et modules (PostGIS, Citus)
* Riche en fonctionnalités : ACID, types de données avancés, indexation puissante, fonctions de fenêtres et agrégats
* Prête pour la Haute Disponibilité

[NOTE.speaker]
--
PostgreSQL est une solution open-source très robuste qui respecte pleinement les standards SQL. Ses fonctionnalités avancées, telles que le support de JSON et des modules comme PostGIS pour les données géospatiales, en font un choix privilégié pour des projets complexes. Il est également largement utilisé grâce à sa communauté active qui propose des extensions variées pour s'adapter à différents besoins.
--
