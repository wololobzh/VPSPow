== Introduction aux scripts Bash

Bash (Bourne Again Shell) est un interpréteur de commandes, l'un des plus utilisés dans les systèmes Unix/Linux. Il permet d'exécuter des commandes, de créer des scripts pour automatiser des tâches et d'interagir avec le système.

Développé par Brian Fox en 1989 pour le projet GNU, Bash est une amélioration du Bourne Shell (sh) avec des fonctionnalités supplémentaires telles que l'historique des commandes, les commandes composées, et plus encore.

=> Un script Bash est simplement une suite de commandes sauvegardées dans un fichier texte avec des structures de contrôles et des fonctions.

=== Déclaration du shell

Les scripts Bash commencent par la ligne suivante pour indiquer l'interpréteur à utiliser :

[source,shell]
----
#!/bin/bash
----

[NOTE.speaker]
--
Le symbole `#!` suivi du chemin vers l'interpréteur indique au système quel programme doit exécuter le script. Ici, `/bin/bash` fait référence à l'interpréteur Bash.
--

=== Écriture des commandes dans un script

On peut écrire n'importe quelle commande que l'on taperait normalement dans le terminal :

[source,shell]
----
echo "Bonjour, le monde"
----

[NOTE.speaker]
--
La commande `echo` affiche simplement un message à l'écran. Ici, "Bonjour, le monde" sera affiché lors de l'exécution du script.
--

=== Attribution des permissions d'exécution

Un script doit avoir les permissions d'exécution pour être lancé :

[source,shell]
----
chmod +x monscript.sh
----

[NOTE.speaker]
--
La commande `chmod +x` permet de rendre un fichier exécutable. Une fois le fichier marqué comme exécutable, vous pouvez le lancer directement avec `./monscript.sh`.
--

// tag::demo[]
== Démonstration 1

Création d'un script qui affiche "Hello World" à l'écran

[NOTE.speaker]
--
1. Créer un fichier appelé `hello.sh`.
2. Ajouter les lignes suivantes :
   ```
   #!/bin/bash
   echo "Hello World"
   ```
3. Sauvegarder et fermer le fichier.
4. Rendre le script exécutable avec `chmod +x hello.sh`.
5. Lancer le script avec `./hello.sh`.
--
// end::demo[]

// tag::demo[]
== Démonstration 2

Création d'un script pour sauvegarder un fichier

[NOTE.speaker]
--
1. Créer un fichier appelé `sauvegarde.sh`.
2. Ajouter les lignes suivantes :
   ```
   #!/bin/bash
   cp fichier.txt fichier.txt.bak
   ```
3. Sauvegarder et fermer le fichier.
4. Rendre le script exécutable avec `chmod +x sauvegarde.sh`.
5. Lancer le script avec `./sauvegarde.sh`.
6. Un fichier `fichier.txt.bak` sera créé en tant que copie de `fichier.txt`.
--
// end::demo[]
