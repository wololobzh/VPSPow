== Pourquoi utiliser des fonctions dans un script Bash ?

* Les fonctions permettent de réutiliser du code.
* Elles améliorent la lisibilité du script.
* Elles facilitent la maintenance et l'extension du code.

[NOTE.speaker]
--
Les fonctions en Bash permettent d’organiser le code de manière modulaire. Plutôt que de répéter des blocs de code, on peut les regrouper dans une fonction et les appeler autant de fois que nécessaire.
--

== Syntaxe de base d'une fonction

.Créer une fonction simple
[source,bash]
----
function nom_fonction {
    # instructions
}
----

.Appeler une fonction
[source,bash]
----
nom_fonction
----

[NOTE.speaker]
--
La syntaxe d’une fonction en bash est simple : le mot-clé `function` peut être optionnel, mais il est souvent utilisé pour rendre le code plus lisible. Une fois définie, la fonction peut être appelée par son nom.
--

== Exemple : Fonction de calcul

Créer une fonction pour additionner deux nombres

[source,bash]
----
function additionner {
    local somme=$(( $1 + $2 ))
    echo "La somme est : $somme"
}

# Appel de la fonction
additionner 5 10
----

[NOTE.speaker]
--
Ici, la fonction `additionner` prend deux arguments et calcule leur somme. Le mot-clé `local` est utilisé pour déclarer une variable locale à la fonction, évitant ainsi les conflits avec d'autres variables dans le script.
--

=== Passage de paramètres aux fonctions

* Les fonctions peuvent accepter des arguments comme n'importe quelle commande en bash.
* Ces arguments sont récupérés via `$1`, `$2`, etc.

[NOTE.speaker]
--
Les arguments passés aux fonctions sont similaires à ceux passés aux scripts. Le premier argument est accessible avec `$1`, le deuxième avec `$2`, et ainsi de suite. Cela permet de créer des fonctions plus dynamiques et réutilisables.
--

== Utilisation du retour de valeur

* En bash, une fonction peut retourner une valeur en utilisant la commande `return` ou en utilisant `echo` pour envoyer une valeur en sortie.

.Exemple de fonction avec retour
[source,bash]
----
function retourner_valeur {
    local result=$(( $1 * 2 ))
    echo $result
}

# Appel de la fonction
valeur=$(retourner_valeur 5)
echo "Le résultat est : $valeur"
----

[NOTE.speaker]
--
Le retour de valeur en bash se fait généralement via `echo`, qui permet de capturer la sortie de la fonction. `return` est limité aux codes de sortie (0 ou 1) et ne doit pas être utilisé pour retourner des valeurs autres que des codes d’erreur.
--
