== Sécurisation des Workflows

=== Contrôles d'Accès

* Permissions des Workflows
** Limitez l'exécution des workflows à des branches spécifiques ou à des collaborateurs autorisés.
* Actions de Tierce Partie
** Utilisez des actions vérifiées pour éviter l'exécution de code malveillant.

[NOTE.speaker]
--
Limitez l'accès aux workflows pour renforcer la sécurité. Utilisez uniquement des actions de tierce partie provenant de sources fiables.
--

=== Isolation des Environnements

* Utilisation de conteneurs Docker
* Limitation des effets des failles de sécurité

[NOTE.speaker]
--
L'isolation des environnements aide à limiter l'impact des failles. Les conteneurs Docker offrent un bon niveau d'isolation surtout avec un runner dédié.
--

=== Audit et Conformité

* Maintien des logs d'audit
* Vérifications de conformité

[NOTE.speaker]
--
Les logs d'audit sont essentiels pour la traçabilité. Assurez-vous que les workflows respectent les politiques de sécurité.
--

// tag::demo[]
== Démonstration

Mise en place de permissions et d'actions sécurisées dans GitHub Actions.

[NOTE.speaker]
--
1. Accédez aux paramètres de votre dépôt GitHub.
2. Configurez les branches protégées pour limiter l'exécution des workflows.
3. Choisissez uniquement des actions vérifiées pour vos workflows.
--
// end::demo[]

== Gestion des Secrets

=== Stockage Sécurisé

* Utilisation de GitHub Secrets
* Chiffrement des secrets

[NOTE.speaker]
--
GitHub Secrets est un outil efficace pour stocker des informations sensibles. Assurez-vous que les secrets sont chiffrés à tout moment.
--

=== Accès Limité

* Principle of Least Privilege (POLP)
* Rotation régulière des secrets

[NOTE.speaker]
--
Appliquez le principe du moindre privilège pour les secrets. Changez-les régulièrement pour réduire les risques en cas de fuite.
--

=== Utilisation Responsable

* Évitez de stocker des secrets dans le code
* Utilisation de variables d'environnement

[NOTE.speaker]
--
Ne stockez jamais de secrets directement dans le code. Utilisez des variables d'environnement pour une gestion sécurisée.
--

== Pratiques Recommandées

* Revue de Code
** Effectuez des revues régulières des fichiers de configuration.
* Notifications et Alertes
** Configurez des alertes pour toute activité suspecte.
