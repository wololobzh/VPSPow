== Objectifs pédagogiques

// tag::objectifs[]
* **Comprendre** le rôle des artefacts dans les workflows CI/CD
* **Appliquer** des techniques pour stocker et récupérer des artefacts
* **Utiliser** des outils pour gérer les artefacts efficacement
// end::objectifs[]

// tag::deroulement[]
== Types d'artefacts

* Binaires
* Libraries
* Rapports de tests
* Fichiers de configuration

[NOTE.speaker]
--
Les types d'artefacts incluent les binaires, les libraries, les rapports de tests, et les fichiers de configuration. Chaque type a un rôle spécifique dans le cycle de développement et de déploiement.
--

== Stockage et récupération

* Utilisation via :
** directement dans Github Actions
** des serveurs de stockage dédiés
** des registres d'artefacts
*** JFrog Artifactory
*** Sonatype Nexus
*** GitLab Container Registry

[NOTE.speaker]
--
Pour assurer une gestion efficace, les artefacts doivent être stockés de manière sécurisée et récupérables à tout moment. Les serveurs de stockage dédiés sont souvent utilisés pour cette tâche.

Chaque solution a des avantages et des inconvénients, et il est important de choisir celle qui convient le mieux à votre workflow.
--

== Bonnes pratiques pour la gestion des artefacts

* Versionnement
* Nettoyage régulier
* Accès sécurisé

[NOTE.speaker]
--
Adoptez des bonnes pratiques comme le versionnement des artefacts pour suivre les modifications, effectuez un nettoyage régulier pour gérer l'espace de stockage, et assurez un accès sécurisé pour protéger vos données.
--
