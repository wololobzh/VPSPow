== Node.js

=== Qu'est-ce que Node.js ?

Node.js est un environnement d'exécution JavaScript côté serveur, construit sur le moteur JavaScript V8 de Chrome. Il permet d'exécuter du code JavaScript en dehors d'un navigateur web.

=== Installation de Node.js

=== Sur Windows

. Téléchargez l'installateur depuis https://nodejs.org/
. Exécutez l'installateur et suivez les instructions

=== Sur macOS

Utilisez Homebrew :

[source,bash]
----
brew install node
----

=== Sur Linux (Ubuntu/Debian)

[source,bash]
----
sudo apt update
sudo apt install nodejs npm
----

=== Vérification de l'installation

Après l'installation, vérifiez que Node.js et npm sont correctement installés :

[source,bash]
----
node --version
npm --version
----

== npm (Node Package Manager)

=== Qu'est-ce que npm ?

npm est le gestionnaire de paquets par défaut pour Node.js. Il permet d'installer, partager et gérer les dépendances dans les projets Node.js.

=== Configuration de npm

=== Initialisation d'un projet

Pour initialiser un nouveau projet Node.js :

[source,bash]
----
mkdir mon-projet
cd mon-projet
npm init -y
----

Cette commande crée un fichier `package.json` avec des valeurs par défaut.

=== Gestion des dépendances avec package.json

Le fichier `package.json` est crucial pour la gestion des dépendances et la configuration du projet.

=== Structure de base d'un package.json

[source,json]
----
{
  "name": "mon-projet",
  "version": "1.0.0",
  "description": "Description de mon projet",
  "main": "index.js",
  "scripts": {
    "test": "echo \"Error: no test specified\" && exit 1"
  },
  "keywords": [],
  "author": "Votre Nom",
  "license": "MIT",
  "dependencies": {},
  "devDependencies": {}
}
----

=== Installation des dépendances

Pour installer une dépendance :

[source,bash]
----
npm install express
----

Cette commande ajoute `express` à la section `dependencies` du `package.json`.

Pour une dépendance de développement :

[source,bash]
----
npm install --save-dev jest
----

Cette commande ajoute `jest` à la section `devDependencies`.

=== Gestion des versions des dépendances

npm utilise le versionnage sémantique (SemVer) pour gérer les versions des paquets.

* `^1.2.3` : Compatible avec 1.x.x
* `~1.2.3` : Compatible avec 1.2.x
* `1.2.3` : Exactement la version 1.2.3

=== Scripts npm

Définissez des scripts dans `package.json` pour automatiser des tâches :

[source,json]
----
{
  "scripts": {
    "start": "node index.js",
    "test": "jest",
    "build": "webpack"
  }
}
----

Exécutez un script avec :

[source,bash]
----
npm run start
----

=== Bonnes pratiques

. Utilisez `.npmrc` pour des configurations spécifiques au projet
. Incluez `package-lock.json` dans votre contrôle de version
. Utilisez `npm ci` au lieu de `npm install` dans les environnements CI/CD pour une installation déterministe
. Mettez régulièrement à jour vos dépendances avec `npm update`

== Conclusion

* Node.js et npm sont des outils fondamentaux pour le développement moderne et le DevOps
* Une bonne compréhension de leur installation, configuration et utilisation est cruciale
* La gestion efficace des dépendances via `package.json` est essentielle pour la maintenabilité des projets
* L'utilisation judicieuse des scripts npm peut grandement améliorer l'efficacité du workflow de développement
* Une mise à jour régulière et une surveillance des dépendances sont importantes pour la sécurité et les performances
