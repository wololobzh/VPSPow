== Introduction aux pointeurs en Go

=== Qu'est-ce qu'un pointeur ?

Un pointeur est une variable qui stocke l'adresse mémoire d'une autre variable.

[source,go]
----
x := 42
ptr := &x  // ptr est un pointeur vers x
fmt.Println(*ptr)  // Affiche la valeur de x (42)
*ptr = 24  // Modifie la valeur de x à travers le pointeur
fmt.Println(x)  // Affiche 24
----

=== Différence avec Python

[cols="1,1"]
|===
|Go |Python

|Utilisation explicite des pointeurs
|Pas de pointeurs explicites (références implicites pour les objets)

|Contrôle direct de la mémoire
|Gestion automatique de la mémoire
|===

=== Utilisation des pointeurs dans les fonctions

[source,go]
----
func incrementer(x *int) {
    *x++
}

num := 5
incrementer(&num)
fmt.Println(num)  // Affiche 6
----

== Méthodes sur les structs

En Go, on peut ajouter des méthodes aux structs, similaires aux méthodes d'instance en Python.

[source,go]
----
type Rectangle struct {
    Width, Height float64
}

func (r Rectangle) Area() float64 {
    return r.Width * r.Height
}

func (r *Rectangle) Scale(factor float64) {
    r.Width *= factor
    r.Height *= factor
}

rect := Rectangle{Width: 10, Height: 5}
fmt.Println(rect.Area())  // Affiche 50

rect.Scale(2)
fmt.Println(rect.Width, rect.Height)  // Affiche 20 10
----

== Introduction à la concurrence avec les goroutines

=== Qu'est-ce qu'une goroutine ?

Une goroutine est une fonction exécutée de manière concurrente avec d'autres goroutines dans le même espace d'adressage.

[source,go]
----
func sayHello() {
    fmt.Println("Hello, Gopher!")
}

func main() {
    go sayHello()  // Lance sayHello comme une goroutine
    time.Sleep(time.Second)  // Attend pour voir le résultat
}
----

=== Pourquoi Go est performant pour la concurrence

- Goroutines légères (quelques Ko de mémoire)
- Multiplexage des goroutines sur des threads OS
- Modèle de concurrence simple à utiliser

== Démonstration

Utilisation de pointeurs et méthodes

[NOTE.speaker]
--
Nous allons créer une structure `Counter` avec une méthode pour l'incrémenter en utilisant un pointeur.

1. Créer un fichier `counter.go`
2. Définir la structure `Counter` et sa méthode `Increment`
3. Démontrer l'utilisation du pointeur dans la méthode

.counter.go
```go
package main

import "fmt"

type Counter struct {
    value int
}

func (c *Counter) Increment() {
    c.value++
}

func main() {
    counter := Counter{value: 0}
    
    counter.Increment()
    counter.Increment()
    
    fmt.Println("Counter value:", counter.value)  // Affiche 2
    
    incrementFiveTimes(&counter)
    
    fmt.Println("Counter value after function:", counter.value)  // Affiche 7
}

func incrementFiveTimes(c *Counter) {
    for i := 0; i < 5; i++ {
        c.Increment()
    }
}
```

Le pointeur permet de modifier directement la valeur du compteur, à la fois dans la méthode `Increment` et dans la fonction `incrementFiveTimes`.
