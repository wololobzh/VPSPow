=== Les boucles

En Go, il n'existe qu'un seul type de boucle : la boucle `for`. Elle peut être utilisée de plusieurs façons pour remplacer les boucles `while` et `for` de Python.

.Boucle for classique
[source,go]
----
for i := 0; i < 5; i++ {
    fmt.Println(i)
}
----

.Boucle for comme while
[source,go]
----
i := 0
for i < 5 {
    fmt.Println(i)
    i++
}
----

.Boucle for infinie
[source,go]
----
for {
    // Code à répéter indéfiniment
}
----

[NOTE.speaker]
--
Notez l'absence de parenthèses autour des conditions et l'obligation d'utiliser des accolades.
--

=== Les conditions

.If-else
[source,go]
----
if x > 0 {
    fmt.Println("Positif")
} else if x < 0 {
    fmt.Println("Négatif")
} else {
    fmt.Println("Zéro")
}
----

.Switch
[source,go]
----
switch day {
case "lundi":
    fmt.Println("Début de semaine")
case "vendredi":
    fmt.Println("Fin de semaine")
default:
    fmt.Println("Milieu de semaine")
}
----

[NOTE.speaker]
--
Contrairement à d'autres langages, il n'y a pas besoin de `break` après chaque `case` en Go.
--

=== Comparaison avec Python

[cols="1,1,1"]
|===
|Aspect |Go |Python

|Boucle for
|Unique type de boucle
|`for` et `while` distincts

|Condition if
|Pas de parenthèses, accolades obligatoires
|Utilisation de `:` et indentation

|Switch
|Pas de `break` nécessaire
|Utilise `if-elif-else`
|===

== Gestion des erreurs en Go

=== Concept de base

Go utilise des retours multiples pour gérer les erreurs, contrairement aux exceptions en Python.

[source,go]
----
func divide(a, b float64) (float64, error) {
    if b == 0 {
        return 0, errors.New("division par zéro")
    }
    return a / b, nil
}

result, err := divide(10, 2)
if err != nil {
    fmt.Println("Erreur:", err)
} else {
    fmt.Println("Résultat:", result)
}
----

=== Bonnes pratiques

1. Toujours vérifier les erreurs retournées
2. Utiliser des erreurs personnalisées pour plus de contexte
3. Propager les erreurs vers le haut de la pile d'appel si nécessaire

[source,go]
----
if err != nil {
    return fmt.Errorf("échec de l'opération: %w", err)
}
----

== Introduction aux packages standard en Go

=== Package fmt

Utilisé pour l'entrée/sortie formatée.

[source,go]
----
fmt.Println("Hello, World!")
fmt.Printf("Nombre: %d\n", 42)
----

=== Package errors

Pour créer et manipuler des erreurs.

[source,go]
----
err := errors.New("une erreur s'est produite")
----

== Démonstration : Gestion des erreurs en Go

[NOTE.speaker]
--
Nous allons créer une fonction qui lit un fichier et gère les erreurs potentielles.

1. Créer un fichier `file_reader.go`
2. Implémenter une fonction qui lit le contenu d'un fichier
3. Gérer les erreurs possibles (fichier non trouvé, problème de lecture)
4. Montrer comment propager et gérer ces erreurs dans la fonction `main()`

.file_reader.go
```go
package main

import (
    "fmt"
    "io/ioutil"
)

func readFile(filename string) (string, error) {
    content, err := ioutil.ReadFile(filename)
    if err != nil {
        return "", fmt.Errorf("erreur de lecture du fichier %s: %w", filename, err)
    }
    return string(content), nil
}

func main() {
    content, err := readFile("example.txt")
    if err != nil {
        fmt.Println("Erreur:", err)
        return
    }
    fmt.Println("Contenu du fichier:", content)
}
```

L'utilisation de `fmt.Errorf` permet d'ajouter un contexte à l'erreur, qui sera utilisé lors de l'affichage de l'erreur.

== Exercice : Conversion d'entrées utilisateur en entiers

Objectif : Écrire un programme qui lit des entrées utilisateur, les convertit en entiers et gère les erreurs de conversion.

1. Créez un fichier `user_input.go`
2. Implémentez une fonction `readInteger() (int, error)` qui :
   - Lit une entrée utilisateur
   - Tente de la convertir en entier
   - Retourne l'entier et une éventuelle erreur
3. Dans la fonction `main()`, utilisez une boucle pour lire 5 entiers
4. Gérez les erreurs de conversion et affichez un message approprié
5. Calculez et affichez la somme des entiers valides entrés

[TIP]
Utilisez `fmt.Scan()` pour lire l'entrée utilisateur et `strconv.Atoi()` pour la conversion en entier.
