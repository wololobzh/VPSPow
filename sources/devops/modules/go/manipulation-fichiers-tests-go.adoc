== Lire et écrire dans des fichiers en Go

=== Utilisation des packages os et io/ioutil

Go fournit plusieurs packages pour manipuler les fichiers. Les plus couramment utilisés sont `os` et `io/ioutil`.

.Lecture d'un fichier
[source,go]
----
import (
    "fmt"
    "io/ioutil"
)

func main() {
    content, err := ioutil.ReadFile("example.txt")
    if err != nil {
        fmt.Println("Erreur de lecture:", err)
        return
    }
    fmt.Println(string(content))
}
----

.Écriture dans un fichier
[source,go]
----
import (
    "fmt"
    "os"
)

func main() {
    data := []byte("Hello, Go!")
    err := ioutil.WriteFile("output.txt", data, 0644)
    if err != nil {
        fmt.Println("Erreur d'écriture:", err)
        return
    }
}
----

=== Comparaison avec Python

[cols="1,1"]
|===
|Go |Python

|`ioutil.ReadFile()` / `ioutil.WriteFile()`
|`open()` avec `read()` / `write()`

|Gestion explicite des erreurs
|Utilisation de try/except

|Manipulation de []byte
|Manipulation de str ou bytes
|===

== Gestion avancée des erreurs

Go encourage une gestion explicite et détaillée des erreurs.

.Création d'erreurs personnalisées
[source,go]
----
import "errors"

var ErrDivisionByZero = errors.New("division by zero")

func divide(a, b float64) (float64, error) {
    if b == 0 {
        return 0, ErrDivisionByZero
    }
    return a / b, nil
}
----

.Utilisation de type assertions pour des erreurs spécifiques
[source,go]
----
result, err := divide(10, 0)
if err != nil {
    if errors.Is(err, ErrDivisionByZero) {
        fmt.Println("Erreur de division par zéro détectée")
    } else {
        fmt.Println("Une autre erreur est survenue:", err)
    }
    return
}
----

== Test unitaire et documentation en Go

=== Introduction aux tests unitaires

Go a un support intégré pour les tests unitaires via le package `testing`.

.Exemple de test unitaire (math_test.go)
[source,go]
----
package main

import "testing"

func TestAdd(t *testing.T) {
    result := Add(2, 3)
    if result != 5 {
        t.Errorf("Add(2, 3) = %d; want 5", result)
    }
}
----

Pour exécuter les tests : `go test`

=== Documentation de code

Go encourage la documentation du code directement dans les fichiers source.

[source,go]
----
// Add returns the sum of two integers.
// It demonstrates a simple addition operation.
func Add(a, b int) int {
    return a + b
}
----

Utilisez `go doc` pour générer la documentation à partir de ces commentaires.

== Démonstration 

Gestion de fichiers et tests

[NOTE.speaker]
--
Nous allons créer un programme qui gère une liste de tâches dans un fichier, avec des tests unitaires.

1. Créer un fichier `task_manager.go`
2. Implémenter des fonctions pour lire et écrire des tâches dans un fichier
3. Ajouter des tests unitaires dans `task_manager_test.go`

.task_manager.go
```go
package main

import (
    "encoding/json"
    "io/ioutil"
)

type Task struct {
    Title       string `json:"title"`
    Description string `json:"description"`
    Done        bool   `json:"done"`
}

func saveTasks(filename string, tasks []Task) error {
    data, err := json.Marshal(tasks)
    if err != nil {
        return err
    }
    return ioutil.WriteFile(filename, data, 0644)
}

func loadTasks(filename string) ([]Task, error) {
    data, err := ioutil.ReadFile(filename)
    if err != nil {
        return nil, err
    }
    var tasks []Task
    err = json.Unmarshal(data, &tasks)
    return tasks, err
}
```

.task_manager_test.go
```go
package main

import (
    "os"
    "testing"
)

func TestSaveAndLoadTasks(t *testing.T) {
    tasks := []Task{
        {Title: "Task 1", Description: "Description 1", Done: false},
        {Title: "Task 2", Description: "Description 2", Done: true},
    }

    filename := "test_tasks.json"
    
    err := saveTasks(filename, tasks)
    if err != nil {
        t.Fatalf("Failed to save tasks: %v", err)
    }

    loadedTasks, err := loadTasks(filename)
    if err != nil {
        t.Fatalf("Failed to load tasks: %v", err)
    }

    if len(loadedTasks) != len(tasks) {
        t.Errorf("Loaded %d tasks, expected %d", len(loadedTasks), len(tasks))
    }

    // Clean up
    os.Remove(filename)
}
```

Les tests vérifient le bon fonctionnement des fonctions `saveTasks` et `loadTasks`. Montrez comment Go gère les fichiers temporaires et le nettoyage après les tests.

== Exercice : Gestionnaire de tâches avec fichier

Objectif : Créer un programme complet de gestion de tâches avec sauvegarde dans un fichier et tests unitaires.

1. Créez un fichier `task_manager.go` (si ce n'est pas déjà fait)

   - `addTask(tasks []Task, newTask Task) []Task`
   - `removeTask(tasks []Task, index int) ([]Task, error)`

4. Créez un fichier `task_manager_test.go` et écrivez des tests unitaires pour toutes les fonctions
5. Dans `main()`, créez une interface utilisateur simple en ligne de commande pour interagir avec le gestionnaire de tâches
