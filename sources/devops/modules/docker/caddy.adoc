== Introduction à Caddy

- Caddy est un serveur web moderne.
- Caractéristiques principales : HTTPS automatique, configuration simple, extensible.

[NOTE.speaker]
--
Caddy est un serveur web open-source qui se distingue par sa simplicité et sa capacité à gérer automatiquement HTTPS. Il est souvent comparé à Nginx et Apache, mais il est conçu pour être plus facile à configurer et à utiliser, notamment grâce à son fichier de configuration simple, le Caddyfile.
--

== Installation et Configuration de Caddy

=== Installation de base avec Docker

```bash
docker run -d -p 80:80 -p 443:443 caddy
```

[NOTE.speaker]
--
Pour installer Caddy via Docker, utilisez la commande ci-dessus. Cela lancera un conteneur Caddy en écoutant sur les ports 80 et 443.
--

=== Configuration initiale avec le fichier Caddyfile

```Caddyfile
example.com {
    respond "Hello, Caddy!"
}
```

[NOTE.speaker]
--
Le `Caddyfile` est le fichier de configuration de Caddy. Dans cet exemple, le serveur répondra avec "Hello, Caddy!" pour les requêtes vers `example.com`. Caddy gère automatiquement les certificats SSL pour les domaines configurés.
--

== Auto-discovery avec Caddy

- Utilisation du projet https://github.com/lucaslorentz/caddy-docker-proxy[lucaslorentz/caddy-docker-proxy]
- Permet à Caddy de détecter automatiquement les services Docker.

[NOTE.speaker]
--
L'auto-discovery avec Caddy est facilitée par le projet `lucaslorentz/caddy-docker-proxy`. Ce plugin permet à Caddy de découvrir automatiquement les conteneurs Docker et de configurer le routage en fonction des labels Docker.
--

== Conclusion

// tag::conclusion[]
* Caddy simplifie la gestion des serveurs web avec une configuration facile.
* L'auto-discovery offre une gestion dynamique des services Docker.
* Caddy est une alternative moderne et efficace aux serveurs web traditionnels.

[NOTE.speaker]
--
L'utilisation de Caddy avec Docker permet une configuration simplifiée et dynamique, idéale pour les environnements de développement et de production. Sa capacité à gérer automatiquement le HTTPS et à découvrir les services Docker en fait un outil précieux pour les développeurs.
