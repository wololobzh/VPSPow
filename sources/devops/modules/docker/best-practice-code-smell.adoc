== Qu'est-ce ?

* Pas techniquement des bugs ou des vulnérabilités
* Problème potentiel de conception ou de maintenabilité
* Peuvent éventuellement conduire à des erreurs ou des problèmes de performance

[NOTE.speaker]
--
Exemples rapides :

. Instructions redondantes ou inutiles : des commandes qui répètent inutilement des actions déjà effectuées.
. Utilisation d'images de base lourdes : Choisir des images de base plus légères pourrait améliorer l'efficacité et la sécurité.
. Manque de clarté dans les commentaires : Insuffisance de documentation ou de commentaires explicatifs rendant le Dockerfile difficile à comprendre.
. Mauvaises pratiques de gestion des couches : Un nombre excessif de couches ou une mauvaise organisation des commandes qui pourraient gonfler inutilement l'image.
. Non-utilisation de bonnes pratiques pour la sécurité : Par exemple, ne pas spécifier de versions pour les dépendances, ce qui pourrait entraîner des mises à jour inattendues.

=== Prefer COPY over ADD for copying local resources

https://rules.sonarsource.com/docker/type/Code%20Smell/RSPEC-7029/[Lien]

Préférer COPY à ADD pour copier des ressources locales pour des raisons de sécurité et de clarté.

=== WORKDIR instruction should only be used with absolute path

https://rules.sonarsource.com/docker/type/Code%20Smell/RSPEC-7021/[Lien]

L'instruction WORKDIR doit être utilisée avec un chemin absolu pour éviter les erreurs de chemin.

=== Prefer Exec form for ENTRYPOINT and CMD instructions

https://rules.sonarsource.com/docker/type/Code%20Smell/RSPEC-7019/[Lien]

Préférer la forme Exec pour les instructions ENTRYPOINT et CMD pour des raisons de clarté et de sécurité.

=== "WORKDIR" instruction should be used instead of "cd" commands

https://rules.sonarsource.com/docker/type/Code%20Smell/RSPEC-6597/[Lien]

Préférer l'instruction WORKDIR à l'utilisation de commandes "cd" pour des raisons de clarté et de sécurité.

=== Specific version tag for image should be used

https://rules.sonarsource.com/docker/type/Code%20Smell/RSPEC-6596/[Lien]

Utiliser des tags de version spécifiques pour les images pour éviter les mises à jour inattendues.

=== Package update should not be executed without installing it

https://rules.sonarsource.com/docker/type/Code%20Smell/RSPEC-6595/[Lien]

Ne pas exécuter de mise à jour de paquet sans l'installer pour éviter les mises à jour inattendues.

=== Cache should be cleaned after package installation

https://rules.sonarsource.com/docker/type/Code%20Smell/RSPEC-6587/[Lien]

Nettoyer le cache après l'installation de paquets pour réduire la taille de l'image.

=== Deprecated instructions should not be used

https://rules.sonarsource.com/docker/type/Code%20Smell/RSPEC-6586/[Lien]

Ne pas utiliser d'instructions obsolètes pour éviter les problèmes de compatibilité.

=== Consent flag should be set to avoid manual input

https://rules.sonarsource.com/docker/type/Code%20Smell/RSPEC-6584/[Lien]

Définir le drapeau de consentement pour éviter les saisies manuelles.

=== Environment variables should not be unset on a different layer than they were set

https://rules.sonarsource.com/docker/type/Code%20Smell/RSPEC-6581/[Lien]

Ne pas annuler les variables d'environnement sur une couche différente de celle où elles ont été définies pour éviter les erreurs.

=== Expanded filenames should not become options

https://rules.sonarsource.com/docker/type/Code%20Smell/RSPEC-6573/[Lien]

Les noms de fichiers étendus ne doivent pas devenir des options pour éviter les erreurs.

=== Double quote to prevent globbing and word splitting

https://rules.sonarsource.com/docker/type/Code%20Smell/RSPEC-6570/[Lien]

Utiliser des guillemets doubles pour éviter le globbing et la division de mots.

=== Instructions should be upper case

https://rules.sonarsource.com/docker/type/Code%20Smell/RSPEC-6476/[Lien]

Les instructions doivent être en majuscules pour des raisons de clarté.

=== Reduce the amount of consecutive RUN instructions

https://rules.sonarsource.com/docker/type/Code%20Smell/RSPEC-7031/[Lien]

Réduire le nombre d'instructions RUN consécutives pour améliorer la lisibilité et la performance.

=== Use ADD instruction to retrieve remote resources

https://rules.sonarsource.com/docker/type/Code%20Smell/RSPEC-7026/[Lien]

Utiliser l'instruction ADD pour récupérer des ressources distantes pour des raisons de sécurité.

=== Too long RUN instruction should be split into multiple lines

https://rules.sonarsource.com/docker/type/Code%20Smell/RSPEC-7020/[Lien]

Les instructions RUN trop longues doivent être divisées en plusieurs lignes pour des raisons de lisibilité.

=== Arguments in long RUN instructions should be sorted

https://rules.sonarsource.com/docker/type/Code%20Smell/RSPEC-7018/[Lien]

Les arguments dans les longues instructions RUN doivent être triés pour des raisons de lisibilité.

=== Track uses of "TODO" tags

https://rules.sonarsource.com/docker/type/Code%20Smell/RSPEC-1135/[Lien]

Faire les choses tout de suite, ne pas laisser de TODO pour plus tard.

=== Descriptive labels are mandatory

https://rules.sonarsource.com/docker/type/Code%20Smell/RSPEC-7028/[Lien]

Les étiquettes des images doivent être descriptives pour faciliter la maintenance.

=== Use digest to pin versions of base images

https://rules.sonarsource.com/docker/type/Code%20Smell/RSPEC-7023/[Lien]

Utiliser des hachages pour épingler les versions des images de base pour éviter les mises à jour inattendues.

=== Dockerfile parsing failure

https://rules.sonarsource.com/docker/type/Code%20Smell/RSPEC-2260/[Lien]

Échec de l'analyse du Dockerfile.
