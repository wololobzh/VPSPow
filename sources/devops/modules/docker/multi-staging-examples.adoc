== Démonstrations

// tag::demo[]
=== Démonstration 1 : Dockerfile multi-stage pour NestJS

[NOTE.speaker]
--
1. Créer un fichier nommé `Dockerfile`.
2. Ajouter un stage pour le développement :

```dockerfile
FROM node:14 AS builder
WORKDIR /app
COPY package.json yarn.lock ./
RUN yarn install
COPY . .
RUN yarn build
```

[start=3]
. Ajouter un stage pour la production :

```dockerfile
FROM node:14-alpine
WORKDIR /app
COPY --from=builder /app/dist ./dist
COPY package.json yarn.lock ./
RUN yarn install --production
CMD ["node", "dist/main"]
```

[start=4]
. Construire l'image avec la commande `docker build -t nestjs-app .`.
. Expliquer les étapes distinctes pour le développement et la production.
--
// end::demo[]

=== Démonstration 2 : Dockerfile multi-stage pour React

[NOTE.speaker]
--
1. Créer un fichier nommé `Dockerfile`.

```dockerfile

WORKDIR /app
COPY package.json yarn.lock ./
RUN yarn install

RUN yarn build
```

[start=3]


== Comparaison avec les Dockerfiles traditionnels

* Analyse des différences de taille entre les images
* Sécurité améliorée en évitant l'exposition des dépendances de développement

[NOTE.speaker]
--
Comparer la taille des images générées par les Dockerfiles traditionnels et multi-stage. Souligner l'amélioration de la sécurité avec multi-staging en limitant l'exposition des dépendances.
--

== Meilleures pratiques pour le multi-staging

* **Optimisation des couches** : Réduire le nombre d'instructions
* **Utilisation d'images de base légères** : Par exemple, `alpine`
* **Nettoyage des artefacts inutiles** : Supprimer les fichiers temporaires

[NOTE.speaker]
--
Pour optimiser le multi-staging, minimiser le nombre de couches dans chaque étape, utiliser des images de base légères et nettoyer les fichiers inutiles pour réduire la taille de l'image finale.
--

=== Exercice 2 : Optimiser un Dockerfile existant

Réorganiser un Dockerfile existant pour utiliser le multi-staging et réduire la taille de l'image.

```dockerfile
FROM node:14

# Créer un répertoire de travail
WORKDIR /app

# Copier les fichiers de configuration
COPY package.json yarn.lock ./

# Installer les dépendances
RUN yarn install

# Copier le reste des fichiers de l'application
COPY . .

# Construire l'application
RUN yarn build

# Exposer le port de l'application
EXPOSE 3000

# Démarrer l'application
CMD ["node", "dist/main"]
```
