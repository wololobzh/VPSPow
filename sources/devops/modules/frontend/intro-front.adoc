== Introduction générale
* Vue d'ensemble du développement web
  - **Frontend** : Ce que l'utilisateur voit (interface utilisateur)
  - **Backend** : Ce qui se passe côté serveur (logique, base de données)
  - **Full stack** : Combine frontend et backend
* Rôle du frontend dans une application web
  - Gérer l'affichage des données, les interactions avec l'utilisateur
  - Utilisation des navigateurs pour afficher les pages web

== Le HTML C’est quoi ?

* Hyper Text Markup Language 
* C’est un langage de balise pour l'hypertexte, en gros cela permet de créer des pages web.
* L’extension des fichiers html est .html

[NOTE.speaker]
--
HTML signifie « HyperText Markup Language » qu'on peut traduire par « langage de balises pour l'hypertexte ». Il est utilisé afin de créer et de représenter le contenu d'une page web et sa structure. D'autres technologies sont utilisées avec HTML pour décrire la présentation d'une page (CSS) et/ou ses fonctionnalités interactives (JavaScript).

L'« hypertexte » désigne les liens qui relient les pages web entre elles, que ce soit au sein d'un même site web ou entre différents sites web. Les liens sont un aspect fondamental du Web. Ce sont eux qui forment cette « toile » (ce mot est traduit par web en anglais). En téléchargeant du contenu sur l'Internet et en le reliant à des pages créées par d'autres personnes, vous devenez un participant actif du World Wide Web.
--

=== Le HTML C’est quoi ?

Permet de structurer l'information d'une page avec des balises

[NOTE.speaker]
--
Un document HTML permet de construire le fond, d'apporter la structure à nos pages WEB.
--

=== Une balise c’est quoi ?

Permet de construire un élément d’une page web.

[NOTE.speaker]
--
La structure d'un document HTML est composée de balises avec une syntaxe particulière qu'on découvre dans la slide suivante.
--

=== Trois types de balises

* <balise>contenu</balise>
* <balise>
* <!-- commentaires - ->

[NOTE.speaker]
--
La première est une balise englobe un contenu.  
La seconde est auto-fermante.  
La troisième permet de définir un commentaire.
--

=== Les balises peuvent avoir des attributs

Mais... qu'est ce qu'un attribut ?

=== Un attribut c’est quoi ?

* Un attribut permet d’apporter une information à la balise.
* Il existe des attributs universels et des attributs spécifiques à chaque balise.

[NOTE.speaker]
--
On voit la syntaxe dans la slide suivante.
--

=== Attribut : Syntaxe

[source, html]
----
<balise attribut=”information”></balise>
----

[NOTE.speaker]
--
Le mot clé attribut va être remplacé par l'attribut spécifique à une balise (par exemple src sur une balise image pour ajouter la source).
On peut ajouter autant d'attributs que nécessaire à une balise.
--

=== Structure d’un document HTML

* Langage de balisage utilisé pour structurer le contenu d'une page web
  - Balises principales : `html`, `head`, `body`, `div`, `a`, `img`, etc.
  - Importance des attributs (`class`, `id`, `href`, `src`)
* Structure d'une page web HTML :
```html
<!DOCTYPE html>
<html>
  <head>
    <title>Titre de la page</title>
  </head>
  <body>
    <h1>Bienvenue sur ma page</h1>
    <p>Ceci est un paragraphe</p>
  </body>
</html>
``` 

[NOTE.speaker]
--
Notre balise HTML englobe toutes les autres balises du document.
Le document est composé d'une partie header (entête) et body (corps de document) qui permet d'avoir les informations visibles sur la page.
--

== CSS - Cascading Style Sheets

=== Qu'est-ce que le CSS ?
* Langage de styles utilisé pour la mise en forme des éléments HTML

[NOTE.speaker]
--
CSS (Cascading Style Sheets) permet de créer des pages web à l'apparence soignée. On va pouvoir, via le CSS mettre en forme nos balises HTML. Cela permettra par exemple d'ajouter de la couleur sur nos titres et paragraphes, mettre des images de fond sur des balises de type block ou encore changer la typographie du document (utilisation de polices et de tailles de polices différentes).
--

=== Définition

Cascading Style Sheets

[NOTE.speaker]
--
En français : Les feuilles de style en cascade.
--

=== Lier le style au contenu

Pour apporter du style à une page HTML, il faut la lier à un fichier CSS.

[NOTE.speaker]
--
On voit la balise qui permet de faire le lien dans la slide suivante.
--

=== Lier le style au contenu : Syntaxe

[source, html]
----
<link href="style.css" rel="stylesheet" />
----

=== Anatomie d'une règle CSS

[source, css]
----
selecteur {
    property1: value;
    property2: value;
}
----

[NOTE.speaker]
--
Sélecteurs :
C'est le nom de l'élément HTML situé au début de l'ensemble de règles. Il permet de sélectionner les éléments sur lesquels appliquer le style souhaité (en l'occurence, les éléments p). Pour mettre en forme un élément différent, il suffit de changer le sélecteur.

Déclaration :
C'est une règle simple comme color: red; qui détermine les propriétés de l'élément que l'on veut mettre en forme.

Propriétés :
Les différentes façons dont on peut mettre en forme un élément HTML (dans ce cas, color est une propriété des éléments p). En CSS, vous choisissez les différentes propriétés que vous voulez utiliser dans une règle CSS.

Valeur de la propriété :
À droite de la propriété, après les deux points, on a la valeur de la propriété. Celle-ci permet de choisir une mise en forme parmi d'autres pour une propriété donnée (par exemple, il y a d'autres couleurs que red pour la propriété color).
--

=== Sélecteurs

* Pour appliquer du CSS à un élément d’une page Web, il doit être sélectionner. Il faut donc un sélecteur.
* Les trois sélecteurs principaux :
** Sélecteur de balise
** Sélecteur de classe
** Sélecteur d’identifiant

=== Sélecteur de balise

Le sélecteur de balise fonctionne en appelant le nom de l’élément HTML.

[NOTE.speaker]
--
En anglais, cela s'appelle aussi le sélecteur TAG NAME.
--

=== Sélecteur de balise

* h1 { /* Propriété CSS */ }
* p { /* Propriété CSS */ }
* div { /* Propriété CSS */ }
* a { /* Propriété CSS */ }
* span { /* Propriété CSS */ }

=== Sélecteur de classe

* Le sélecteur de classe est défini sur un élément HTML avec l’attribut class
* La valeur de l'attribut doit être un moyen d'identifier facilement l'élement dans le document. Il doit contenir des lettres [a-zA-Z] et ne doit surtout pas contenir d'espaces.
* Un élément HTML peut avoir plusieurs class (séparés par des espaces dans la valeur)


=== Définition d'une classe

[source, css]
----
.rose {
    color : pink;
}
----

=== Appliquer une classe à un élément

[source, html]
----
<div class="rose"></div>
----

=== Sélecteur d'identifiant

* Le sélecteur d’identifiant est défini sur un élément HTML avec l’attribut id
* L'id est unique
* La valeur de l'attribut doit être un moyen d'identifier facilement l'élement dans le document. Il doit contenir des lettres [a-zA-Z] et ne doit surtout pas contenir d'espaces.

=== Sélecteur d'identifiant

[source, css]
----
#wololo {
    color: red;
}
----

=== Sélecteur d'identifiant

[source, html]
----
<div id="wololo"></div>
----

== JavaScript - Dynamiser une page web

=== Qu'est-ce que JavaScript ?
* Langage de programmation qui permet de rendre une page interactive
* Utilisation pour manipuler le DOM (Document Object Model) : Ajouter, supprimer ou modifier des éléments HTML en temps réel

=== Exemple de script JavaScript simple
```javascript
document.querySelector("h1").addEventListener("click", function() {
  alert("Vous avez cliqué sur le titre !");
});
```

=== Concepts de base de JavaScript

* Variables : `const`, `let` (et `var`)
* Fonctions : Définir des comportements interactifs
* Manipulation des éléments HTML : `document.getElementById()`, `querySelector()`

=== Démonstration

[NOTE.speaker]
--
* Exemple de script JavaScript interactif
* Présenter les concepts de base : variables, fonctions, manipulation du DOM

```js
console.log('HW!');

const input = document.querySelector('input');
let name = 'World';

function init() {
    input.value = name;
    input.addEventListener('input', changeName);
    
    displayName();
}

function displayName() {
    const target = document.getElementById('name');
    target.textContent = name;
}

function changeName(event) {
    name = event.target.value;
    displayName();
}

init();
```
