== Introduction aux API REST

Une API REST (Representational State Transfer) est un style d'architecture pour la création de services web. Elle utilise les méthodes HTTP standard (GET, POST, PUT, DELETE) pour interagir avec les ressources.

== Configuration de l'environnement

=== Installation de Flask

[source,bash]
----
pip install flask
----

=== Code de base (app.py)

[source,python]
----
from flask import Flask, jsonify

app = Flask(__name__)

# Données en mémoire pour simuler une base de données
books = [
    {"id": 1, "title": "To Kill a Mockingbird", "author": "Harper Lee"},
    {"id": 2, "title": "1984", "author": "George Orwell"},
    {"id": 3, "title": "Pride and Prejudice", "author": "Jane Austen"}
]

@app.route('/')
def home():
    return jsonify({"message": "Bienvenue dans l'API de livres!"})

@app.route('/api/books', methods=['GET'])
def get_books():
    return jsonify({"books": books})

@app.route('/api/books/<int:book_id>', methods=['GET'])
def get_book(book_id):
    book = next((book for book in books if book["id"] == book_id), None)
    if book:
        return jsonify(book)
    return jsonify({"message": "Livre non trouvé"}), 404

if __name__ == '__main__':
    app.run(debug=True)
----

== Explication du code

1. Nous importons Flask et la fonction `jsonify` pour formater nos réponses en JSON.
2. Nous créons une instance de l'application Flask.
3. Nous définissons une liste `books` pour simuler une base de données en mémoire.
4. Nous créons trois routes :
   - `/` : Page d'accueil
   - `/api/books` : Pour obtenir tous les livres
   - `/api/books/<int:book_id>` : Pour obtenir un livre spécifique par son ID

== Lancement de l'application

Pour lancer l'application, exécutez :

[source,bash]
----
python app.py
----

L'API sera accessible à l'adresse `http://localhost:5000`.

== Test de l'API

Vous pouvez tester l'API en utilisant cURL ou un outil comme Postman.

=== Exemples avec cURL

. Obtenir tous les livres :
+
[source,bash]
----
curl http://localhost:5000/api/books
----
. Obtenir un livre spécifique :
+
[source,bash]
----
curl http://localhost:5000/api/books/1
----
