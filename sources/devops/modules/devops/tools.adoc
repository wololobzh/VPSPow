== Git

* permet le contrôle de version en local sur votre machine
* indispensable à tout projet de développement

=== Installer git

https://git-scm.com/downloads

* Windows : un exécutable pour l'installer
* MacOS : Homebrew recommandé (`brew install git`)
* Linux : déjà installé sur certaines distributions, sinon disponible via le gestionnaire de paquet (ex: `apt install git`)

[NOTE.speaker]
--
Pour l'utilisation de git, il y a un module dédié à cela qui arrive juste après
--

== Docker Desktop

* permet de gérer des conteneurs virtuels
* regroupe plusieurs outils utiles pour lister, démarrer, arrêter des conteneurs...

[NOTE.speaker]
--
On reviendra plus tard sur le concept de conteneur. En attendant, Docker Desktop va nous permettre de pouvoir faire les challenges quotidiens.
--

=== Installer Docker Desktop

https://www.docker.com/products/docker-desktop/

* Windows : un exécutable pour l'installer
* MacOS : un dmg permettant de l'installer
* Linux : https://docs.docker.com/desktop/install/linux-install/

== VS Code

* regroupe plusieurs outils pour écrire, tester et déployer le code
* édition du code, détection d'erreurs, gestion de projets...

=== Installer VS Code

https://code.visualstudio.com/

* Windows : un exécutable pour l'installer
* MacOS : Homebrew recommandé (`brew install git`)
* Linux : disponible via le gestionnaire de paquet (ex: `apt install code`)

=== Plugins VS Code

- https://marketplace.visualstudio.com/items?itemName=ms-vscode-remote.remote-containers[DevContainers] : permet de lancer des environnements de développement tout inclus
- https://marketplace.visualstudio.com/items?itemName=MS-vsliveshare.vsliveshare[Live Share] : permet la collaboration à plusieurs sur le même projet. Utile pour suivre le code du formateur
