== Introduction à l'installation d'Ansible

* **Présentation des prérequis** :
  ** Python installé sur la machine
  ** Accès à un terminal avec privilèges sudo
  ** Connexion internet active

[NOTE.speaker]
--
Assurez-vous d'avoir ces éléments en place avant de commencer l'installation.
--

* **Systèmes d'exploitation supportés** :
  ** Linux (Ubuntu, Debian, CentOS, RHEL)
  ** macOS

[NOTE.speaker]
--
Ansible est principalement utilisé sur Linux, mais il peut aussi être installé sur macOS. Windows nécessite l'utilisation du sous-système Windows pour Linux (WSL).
--

// tag::demo[]
== Installation d'Ansible

=== Installation sur Ubuntu/Debian

* **Commande d'installation** :
  ```bash
  sudo apt update
  sudo apt install ansible
  ```

[NOTE.speaker]
--
Passer par une VM Debian vierge. Installer les dépendances.
--

=== Vérification de l'installation

* **Vérification de la version installée** :
  ```bash
  ansible --version
  ```

[NOTE.speaker]
--
Après l'installation, vérifiez qu'Ansible est correctement installé en exécutant `ansible --version`. Cela affichera la version d'Ansible et confirmera une installation réussie.
--

== VM Kourou

Créer ou lancer la VM Kourou, puis la rendre publique.

* Tester la connexion SSH depuis la Debian vers la VM Kourou. 
* Vérifier que python est présent
* L'installer le cas échéant

[NOTE.speaker]
--
Inciter les apprenants à le faire en même temps.
--
