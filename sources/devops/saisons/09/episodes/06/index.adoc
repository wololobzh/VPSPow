// tag::intro[]
Mise en place de déploiements automatisés et à l'optimisation des workflows CI/CD. Configurer des workflows GitHub Actions pour déployer des applications de manière automatisée et améliorer l'efficacité des pipelines.
// end::intro[]

== Objectifs pédagogiques

// tag::objectifs[]
* *Analyser* la performance des workflows CI/CD.
* *Appliquer* les bonnes pratiques pour faire la transition entre Dev et Ops.

// end::objectifs[]

== Prérequis formateur

// tag::prerequis[]
* Expérience avec GitHub Actions et la configuration de déploiements automatisés.
* Connaissance des techniques d'optimisation des workflows CI/CD.
* Compétence dans l'utilisation des caches et la parallélisation des jobs.
// end::prerequis[]
