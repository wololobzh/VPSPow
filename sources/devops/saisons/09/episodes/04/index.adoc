// tag::intro[]
Utilisation de Docker au sein des GitHub Actions pour améliorer l'isolation et la portabilité des environnements d'exécution. Comment implémenter des stratégies de déploiement continu et utiliser Docker pour exécuter des actions dans les pipelines.
// end::intro[]

== Objectifs pédagogiques

// tag::objectifs[]
* *Evaluer* l'usage de Docker dans les workflows GitHub Actions.
* *Se rappeler* des stratégies de déploiement continu.
// end::objectifs[]

== Prérequis formateur

// tag::prerequis[]
* Expérience pratique avec Docker et Docker Compose.
* Connaissance approfondie des stratégies de déploiement continu.
* Compétence dans la création et l'utilisation d'actions Docker dans GitHub Actions.
// end::prerequis[]
