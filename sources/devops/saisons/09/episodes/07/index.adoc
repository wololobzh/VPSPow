// tag::intro[]
Gestion efficace des artefacts générés par les builds et à la sécurisation des workflows CI/CD. Les apprenants veront comment stocker, versionner, et partager des artefacts, tout en mettant en place des pratiques robustes pour protéger les informations sensibles dans les workflows.
// end::intro[]

== Objectifs pédagogiques

// tag::objectifs[]
* *Comprendre* les enjeux de la sécurité dans les workflows CI/CD.
* *Appliquer* une bonne gestion des artefacts.
// end::objectifs[]

== Prérequis formateur

// tag::prerequis[]
* Expérience avec la gestion des artefacts et les registres d'artefacts.
* Connaissance des pratiques de sécurité dans les workflows CI/CD.
* Compétence dans la configuration des permissions et des contrôles d'accès.
// end::prerequis[]
