Le premier jour de la saison est consacré à l'établissement d'une base solide pour le développement logiciel en équipe.
// end::intro[]

== Objectifs pédagogiques

// tag::objectifs[]
* *Analyser* la méthode de collaboration en informatique.
* *Comprendre* les concepts de CI/CD
* *Appliquer* des tests unitaires en tant que DevOps.
// end::objectifs[]

== Prérequis formateur

// tag::prerequis[]
* Connaissance des outils de versionnement Git.
* Maîtrise dans la gestion des rôles et permissions sur Github.
* Expérience pratique avec Docker et Docker Compose.
* Connaissance des outils de build et de test pour le front-end.
// end::prerequis[]
