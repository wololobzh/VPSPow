// tag::intro[]
Approfondissement de l'utilisation des GitHub Actions pour l'intégration continue. Comment configurer des workflows avancés, utiliser des runners locaux pour des tests plus rapides, et développer des actions personnalisées pour répondre à des besoins spécifiques.
// end::intro[]

== Objectifs pédagogiques

// tag::objectifs[]
* *Appliquer* un runner Github Action local
* *Analyser* des workflows avancés
* *Comprendre* l'intérêt des actions personnalisées
// end::objectifs[]

== Prérequis formateur

// tag::prerequis[]
* Expérience approfondie avec GitHub Actions et la création d'actions personnalisées.
* Connaissance des runners auto-hébergés et de leur configuration.
// end::prerequis[]
