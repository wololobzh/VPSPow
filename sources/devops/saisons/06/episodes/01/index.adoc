Début de la saison système, on reviens sur linux pour préciser son importance dans le monde DevOps, puis un installe une VM ubuntu avec VirtualBox pour la bidouiller en SSH.

== Objectifs pédagogiques

// tag::objectifs[]
- **Se rappeler** des différents OS et distributions Linux
- **Appliquer** Linux dans une VM
- **Analyser** les commandes principales
// end::objectifs[]

== Prérequis formateur

// tag::prerequis[]
* Connaitre VirtuablBox
* Avoir l'iso de Debian
// end::prerequis[]
