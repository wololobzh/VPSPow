// tag::intro[]
Les apprenants mettront en place un environnement de tests avec Docker pour simuler des déploiements automatisés. Ils apprendront à utiliser des modules Ansible et appliqueront des playbooks pour gérer des services web sur des conteneurs.
// end::intro[]

== Objectifs pédagogiques

// tag::objectifs[]
* *Compréhension* : Décrire et expliquer le fonctionnement des modules Ansible
* *Application* : Mettre en place un environnement de tests avec Docker
* *Application* : Appliquer des playbooks pour configurer des serveurs web sur des conteneurs
// end::objectifs[]

== Prérequis formateur

// tag::prerequis[]
* Avoir docker installé sur sa machine
// end::prerequis[]
