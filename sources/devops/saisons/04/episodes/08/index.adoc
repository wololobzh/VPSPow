// tag::intro[]
Cet épisode explore l'interaction avec des APIs REST, la manipulation de fichiers, la gestion des entrées/sorties, et l'écriture de tests unitaires en Go.
// end::intro[]

== Objectifs pédagogiques

// tag::objectifs[]
- **Comprendre** comment interagir avec des APIs REST en Go
- **Appliquer** les techniques de manipulation de fichiers et de gestion des E/S
- **Créer** des tests unitaires pour des programmes Go
- **Maîtriser** la gestion avancée des erreurs en Go
// end::objectifs[]

== Prérquis formateur

// tag::prerequis[]
- Expérience pratique avec les requêtes HTTP et les APIs REST
- Connaissance approfondie de la manipulation de fichiers en Go
- Maîtrise des principes de tests unitaires
- Compréhension des bonnes pratiques de gestion des erreurs en Go
// end::prerequis[]
