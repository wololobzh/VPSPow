// tag::intro[]
Cet épisode couvre la création d'un bot Discord en utilisant DiscordGo et son intégration avec une API Flask. Les apprenants développeront un bot capable d'interagir avec une API externe pour gérer des projets et des tâches.
// end::intro[]

== Objectifs pédagogiques

// tag::objectifs[]
- **Comprendre** le fonctionnement de DiscordGo et son interaction avec l'API Discord
- **Appliquer** les méthodes pour créer un bot Discord fonctionnel en Go
- **Intégrer** le bot Discord avec une API Flask externe
- **Gérer** les interactions entre le bot, l'API, et les utilisateurs Discord
// end::objectifs[]

== Prérquis formateur

// tag::prerequis[]
- Maîtrise de Go et de la bibliothèque DiscordGo
- Expérience dans la création et l'utilisation d'APIs REST
- Connaissance de base de Flask et de son fonctionnement
- Compréhension des principes de gestion des erreurs et des réponses API
// end::prerequis[]
