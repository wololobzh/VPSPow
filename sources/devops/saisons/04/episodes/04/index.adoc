// tag::intro[]
Cet épisode approfondit la gestion des bases de données PostgreSQL en explorant l'outil visuel Adminer et en introduisant le concept d'ORM avec SQLAlchemy dans Flask. Nous passerons des requêtes SQL brutes à une approche orientée objet pour interagir avec les bases de données.
// end::intro[]

== Objectifs pédagogiques

// tag::objectifs[]
- **Utiliser** Adminer pour gérer visuellement une base de données PostgreSQL
- **Comparer** les opérations Adminer avec leurs équivalents en ligne de commande psql
- **Comprendre** le concept d'ORM et ses avantages
- **Implémenter** des modèles de données avec SQLAlchemy dans Flask
- **Effectuer** des opérations CRUD en utilisant SQLAlchemy
- **Analyser** les différences entre les requêtes SQL brutes et leur équivalent en ORM
// end::objectifs[]

== Prérequis formateur

// tag::prerequis[]
- Connaissance approfondie de PostgreSQL et des commandes psql
- Expérience avec Flask et le développement web en Python
- Familiarité avec les concepts de base de données relationnelles
- Environnement de développement configuré avec PostgreSQL, Adminer, Flask et SQLAlchemy
// end::prerequis[]
