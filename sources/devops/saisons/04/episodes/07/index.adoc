// tag::intro[]
Cet épisode approfondit les connaissances en Go en explorant les structures de données, les pointeurs, la gestion mémoire et introduit le concept de concurrence avec les goroutines.
// end::intro[]

== Objectifs pédagogiques

// tag::objectifs[]
- **Comprendre** les structures de données spécifiques à Go
- **Appliquer** les concepts de pointeurs et de gestion mémoire
- **Découvrir** les bases de la concurrence avec les goroutines
- **Comparer** ces concepts avec leurs équivalents ou absences en Python
// end::objectifs[]

== Prérquis formateur

// tag::prerequis[]
- Maîtrise des structures de données en Go et en Python
- Expérience pratique avec les pointeurs et la gestion mémoire en langages de bas niveau
- Connaissance des principes de concurrence en programmation
// end::prerequis[]
