// tag::intro[]
Cet épisode présente les bases du langage Go aux développeurs Python. Il couvre les différences clés entre Go et Python, ainsi que les structures de contrôle et la gestion des erreurs spécifiques à Go.
// end::intro[]

== Objectifs pédagogiques

// tag::objectifs[]
- **Comprendre** les concepts de base du langage Go et ses différences avec Python
- **Appliquer** les structures de contrôle en Go
- **Maîtriser** la gestion des erreurs en Go
// end::objectifs[]

== Prérquis formateur

// tag::prerequis[]
- Connaissance approfondie de Go et Python
- Expérience en développement avec les deux langages
- Compréhension des systèmes de typage statique et dynamique
// end::prerequis[]
