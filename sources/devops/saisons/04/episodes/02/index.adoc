// tag::intro[]
Cet épisode couvre les bases du développement backend et l'initiation à la création d'API avec Flask. Nous explorerons d'abord les concepts fondamentaux du backend, puis nous mettrons en pratique ces connaissances en créant une mini API simple avec Flask.
// end::intro[]

== Objectifs pédagogiques

// tag::objectifs[]
- **Comprendre** le rôle et l'architecture du backend dans le développement web
- **Identifier** les composants clés d'une application backend
- **Expliquer** le fonctionnement des API et leur importance
- **Créer** une API simple avec Flask en utilisant la méthode GET
- **Manipuler** des données en mémoire pour simuler une base de données
- **Tester** une API avec des outils comme cURL ou Postman
// end::objectifs[]

== Prérequis formateur

// tag::prerequis[]
- Connaissance de base en programmation Python
- Familiarité avec les concepts HTTP et REST
- Environnement Python configuré avec Flask installé
- Postman ou cURL installé pour tester l'API
// end::prerequis[]
