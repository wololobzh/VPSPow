== Résumé

// tag::resume[]
Cette saison se concentre sur le développement backend avec Python et Go. Elle couvre la gestion de projet avec GitHub, la création d'API, la manipulation de bases de données, et l'intégration de bots Discord, offrant une formation complète pour les développeurs souhaitant découvrir dans le backend.

Exploration du développement back-end, en réalisant des projets variés en Python et Go.
Un accent sera mis sur l'utilisation de GitHub pour la gestion de projet et la collaboration en équipe.

Il faudra insister sur la création de branches, les pull requests, et la gestion des conflits.
La première semaine sera consacrée à la création d'API avec Flask avec Python, la manipulation de bases de données SQL, et l'utilisation de psql pour DevOps.

La deuxième semaine sera dédiée à l'exploration du langage Go, avec discordgo pour la création de bots Discord. Dans le challenge, fil rouge, les apprenants devront créer un bot Discord capable d'interagir avec une API externe pour gérer des projets et des tâches.
// end::resume[]
