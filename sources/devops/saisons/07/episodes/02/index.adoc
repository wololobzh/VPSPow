// tag::intro[]
Apprentissage progréssif de la base des réseaux informatiques, y compris l'adressage IP, le subnetting, les VLANs, le routage, les protocoles essentiels comme DNS, DHCP et NTP, ainsi que les mécanismes de sécurité réseau tels que les pare-feux et les VPN. L’approche est à la fois théorique et pratique
// end::intro[]

== Objectifs pédagogiques

// tag::objectifs[]
* Comprendre l’adressage IPv4 
* Calculer et implémenter des sous-réseaux 
// end::objectifs[]

== Prérequis formateur

// tag::prerequis[]
* Connaissance avancé sur IPv4, 
* IPv6
* Techniques avancées de subnetting VLSM.
// end::prerequis[]
