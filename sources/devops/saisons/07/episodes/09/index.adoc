== Objectifs pédagogiques

// tag::objectifs[]
* Comprendre le rôle du protocole NTP et ses sources de temps
* Comprendre les concepts d'interconnexion des réseaux, y compris les VPNs et les architectures multi-sites.
* Découvrir les techniques d'optimisation des performances réseau pour assurer une connectivité fluide et efficace.
// end::objectifs[]

== Prérequis formateur

// tag::prerequis[]
* Connaître le principe de NTP et savoir le mettre en place sur Linux
* Savoir utiliser un VPN
* Connaître des techniques d'optimisation réseau
// end::prerequis[]
