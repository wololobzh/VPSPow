// tag::intro[]
Apprentissage progréssif de la base des réseaux informatiques, y compris l'adressage IP, le subnetting, les VLANs, le routage, les protocoles essentiels comme DNS, DHCP et NTP, ainsi que les mécanismes de sécurité réseau tels que les pare-feux et les VPN. L’approche est à la fois théorique et pratique
// end::intro[]

== Objectifs pédagogiques

// tag::objectifs[]
* introduction sur les différents types de réseaux (LAN, MAN, WAN, WLAN) et leur typologies
* connaître le modèles OSI
* maîtriser les conversions entre les bases 2, 8, 10 et 16  
// end::objectifs[]

== Prérequis formateur

// tag::prerequis[]
* Maîtrise des concepts réseaux : Connaissance des réseaux informatiques, des protocoles de communication et du modèles OSI.
* Maîtrise des conversions entre les bases 2, 8, 10 et 16
// end::prerequis[]
