// tag::intro[]
Cet épisode est consacré à la mise en place d'un serveur DHCP sur Linux. Nous aborderons l'installation, la configuration avancée, et la gestion du service DHCP pour une attribution IP efficace sur plusieurs sous-réseaux.
// end::intro[]

== Objectifs pédagogiques

// tag::objectifs[]
* Installation, la configuration avancée, et la gestion du service DHCP sur Linux pour une attribution IP efficace sur plusieurs sous-réseaux.
* Voir la configuration NTP, de la sélection des sources de temps, et de la gestion de la synchronisation horaire sur des environnements mixtes.
// end::objectifs[]

== Prérequis formateur

// tag::prerequis[]
* avoir de pré configuré pour les démonstrations 
** une vm linux (Serveur)
** une vm linux (client)
* Savoir configurer un serveur DHCP
// end::prerequis[]
