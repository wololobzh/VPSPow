// tag::intro[]
Exploration du déploiement et de l'hébergement d'applications frontend, avec accent sur les applications Svelte. Présentation des concepts généraux d'hébergement pour DevOps et focus sur le déploiement pratique d'applications Svelte sur GitHub Pages.
// end::intro[]

== Objectifs pédagogiques

// tag::objectifs[]
- **Comprendre** les différentes options d'hébergement pour les applications frontend
- **Distinguer** les spécificités de l'hébergement statique et dynamique
- **Maîtriser** les concepts clés tels que CDN, mise en cache et optimisation des performances
- **Appliquer** les meilleures pratiques de déploiement pour les applications Svelte
- **Configurer** et utiliser GitHub Pages pour héberger une application frontend
- **Résoudre** les problèmes courants liés au déploiement sur GitHub Pages
// end::objectifs[]

== Prérequis formateur

// tag::prerequis[]
- Expérience pratique dans le déploiement d'applications web frontend
- Connaissance approfondie des concepts DevOps liés à l'hébergement web
- Maîtrise du framework Svelte et de son processus de build
- Familiarité avec GitHub et GitHub Pages
- Compréhension des concepts de performance web et d'optimisation
- Capacité à résoudre les problèmes courants de déploiement et à expliquer les solutions de manière claire
// end::prerequis[]
