// tag::intro[]
Présentation des fondamentaux du développement frontend, des concepts de base du web à l'introduction du framework Svelte. Aperçu de l'évolution des technologies frontend et de leur application dans le développement web moderne.
// end::intro[]

== Objectifs pédagogiques

// tag::objectifs[]
- **Comprendre** les concepts de base du développement web et du frontend
- **Distinguer** les rôles du client et du serveur dans l'architecture web moderne
- **Maîtriser** les fondamentaux de HTML, CSS et JavaScript
- **Analyser** l'évolution des architectures web, des applications traditionnelles aux SPA
- **Appliquer** les principes de base du framework Svelte dans le développement frontend
- **Évaluer** les avantages de Svelte par rapport aux autres frameworks frontend
// end::objectifs[]

== Prérequis formateur

// tag::prerequis[]
- Expérience pratique en développement web frontend
- Connaissance de HTML, CSS et JavaScript
- Familiarité avec les concepts d'architecture web client-serveur
- Découverte du framework Svelte et compréhension des autres frameworks majeurs (React, Vue)
- Capacité à expliquer des concepts techniques de manière claire et accessible
// end::prerequis[]
