// tag::intro[]
Cet épisode couvre Git, de ses fondamentaux à ses fonctionnalités avancées. Essentiel pour les développeurs et DevOps, Git est au cœur de la gestion de code moderne.
// end::intro[]

== Objectifs pédagogiques

// tag::objectifs[]
- **Maîtriser** les commandes Git de base
- **Appliquer** des stratégies de branchement efficaces
- **Utiliser** les fonctionnalités avancées de Git
- **Optimiser** les workflows de développement avec Git
// end::objectifs[]

== Prérequis formateur

// tag::prerequis[]
- Expérience pratique de Git en environnement professionnel
- Maîtrise des concepts avancés de Git
- Connaissance des plateformes Git (GitHub, GitLab, etc.)
- Compréhension de l'intégration de Git dans les pratiques DevOps
// end::prerequis[]
