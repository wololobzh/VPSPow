// tag::intro[]
Exploration des outils et pratiques essentiels du développement frontend moderne. Présentation de Node.js et npm, des techniques de bundling et d'optimisation du code, ainsi que des différences entre environnements de développement et de production. Focus sur les meilleures pratiques de déploiement, incluant les tests unitaires.
// end::intro[]

== Objectifs pédagogiques

// tag::objectifs[]
- **Comprendre** le rôle et le fonctionnement de Node.js et npm dans l'écosystème frontend
- **Maîtriser** l'utilisation de base de npm pour la gestion des dépendances
- **Appliquer** les techniques de bundling et d'optimisation du code frontend
- **Analyser** les différences entre les environnements de développement et de production
- **Évaluer** les stratégies d'optimisation pour le déploiement d'applications frontend
- - **Implémenter** des stratégies de tests unitaires efficaces avant vos builds
// end::objectifs[]

== Prérequis formateur

// tag::prerequis[]
- Expérience pratique avec Node.js et npm dans des projets frontend
- Connaissance approfondie des outils de bundling modernes (ex: Webpack, Rollup, Vite)
- Maîtrise des techniques d'optimisation du code frontend
- Compréhension des enjeux et des différences entre les environnements de développement et de production
- Expérience dans le déploiement d'applications web frontend
- Capacité à expliquer des concepts techniques complexes de manière claire et accessible
// end::prerequis[]
